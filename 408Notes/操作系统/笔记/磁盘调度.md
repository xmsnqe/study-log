# 磁盘调度

## 📍知识定位

### 在 408 体系中的位置

磁盘调度算法是设备管理中提高磁盘 I/O 效率的关键技术。在 408 考试中，磁盘调度算法（尤其是 SSTF、SCAN 和 C-SCAN）的**大题计算**是必考内容，要求考生能够手动模拟磁头移动过程并计算平均寻道时间。

### 学习前置条件

- **磁盘结构**：理解柱面、磁道、扇区、寻道时间、旋转延迟的概念。
- **I/O 控制方式**：了解程序 I/O、中断、DMA、通道等 I/O 方式的背景。

### 学完之后支撑的知识点

- **设备处理程序**：操作系统如何调用调度算法处理 I/O 请求。
- **I/O 软件层次**：用户层、设备独立性、设备驱动程序、中断处理程序的协作。

| 教材 | 视角特点 | 侧重点 |

## 📝核心概念与原理

### 1. 磁盘 I/O 时间组成

磁盘请求的响应时间主要由三部分组成：
1.  **寻道时间（Seek Time）**：磁头移动到指定柱面所需的时间（耗时最长，占大头）。
2.  **旋转延迟（Rotational Latency）**：指定扇区旋转到磁头下方的时间（平均为旋转半周的时间）。
3.  **传输时间（Transfer Time）**：读写数据所需的时间。

> ⭐ **选择题高频考点**：磁盘 I/O 操作中，**寻道时间**通常是最主要的耗时部分，优化调度算法主要针对减少寻道时间。

### 2. 常见调度算法

假设磁头当前位于柱面 100，待访问请求序列为：55, 58, 39, 18, 90, 160, 150, 38, 184（按从小到大排序方便分析）。

#### （1）先来先服务（FCFS）

- **原理**：严格按照请求到达的先后顺序进行服务。
- **特点**：公平，但平均寻道时间可能较长。
- **移动轨迹**：直接按序列移动。

#### （2）最短寻道时间优先（SSTF）

- **原理**：选择与当前磁头位置**最近**的柱面进行服务。
- **特点**：平均寻道时间较短，但可能导致“饥饿”现象（远端请求可能长期得不到满足）。
- **移动轨迹**：每次选距离最近的。
  - 假设当前在 100。
  - 最近的可能是 90（差 10），然后是 58...

#### （3）扫描算法（SCAN / 电梯算法）

- **原理**：磁头沿一个方向移动，处理途中请求，直到到达该方向最外/最内柱面（或到达边界），然后改变方向。
- **特点**：无饥饿现象，性能优于 SSTF。
- **移动轨迹**：
  - 若磁头向外（增大方向）：100 -> 150 -> 160 -> 184 -> 150(折返) -> ...
  - 注意：SCAN 会走到磁盘边界或请求队列的最边缘。

#### （4）循环扫描算法（C-SCAN）

- **原理**：与 SCAN 类似，但磁头单向移动。到达边界后，**立即返回**起点（返回途中不处理请求），然后再次单向扫描。
- **特点**：旋转延迟更均匀，等待时间更稳定。
- **移动轨迹**：
  - 100 -> 150 -> 160 -> 184 -> (直接回到 0 或起始点) -> 38 -> 55 ...

### 3. 算法对比

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **FCFS** | 公平、简单 | 平均寻道时间长 | 请求较少时 |
| **SSTF** | 平均寻道时间短 | 可能导致饥饿 | 对响应时间敏感的系统 |
| **SCAN** | 无饥饿、性能稳定 | 频繁折返（如果请求分布不均） | 通用场景（电梯算法） |
| **C-SCAN** | 等待时间更均匀 | 实现稍复杂 | 对响应时间要求均匀的系统 |

## ⚖️易混淆概念对比

| 对比项 | SCAN 算法 | C-SCAN 算法 |
|--------|-----------|-------------|
| 移动方向 | 双向（到边界折返） | 单向（返回需空跑） |
| 返回处理 | 返回途中处理请求 | 返回途中**不**处理请求 |
| 请求分布适应 | 适合请求在两端和中间都有的情况 | 适合请求在磁头一侧较多的情况 |
| 平均寻道时间 | 通常优于 SSTF | 略逊于 SCAN（因为有空跑回程） |

## ⚠️考试高频坑点

| 坑点 | 错误理解 | 正确理解 |
|------|---------|---------|
| **C-SCAN 的返回** | 认为 C-SCAN 返回时也处理请求 | C-SCAN 返回是“空跑”，不处理请求 |
| **SCAN 的边界** | 认为 SCAN 只到最近请求的边界 | SCAN 必须移动到当前方向的**最外层柱面**（通常题目假设磁头向内，需移到 0） |
| **SSTF 的饥饿** | 认为 SSTF 不会产生饥饿 | SSTF 优先选最近的，如果请求一直出现在磁头附近，远处请求可能永远得不到处理 |
| **平均寻道时间计算** | 平均寻道时间包含旋转延迟 | 题目通常只要求计算“平均寻道长度”（柱面移动距离），除非明确问“平均响应时间” |
