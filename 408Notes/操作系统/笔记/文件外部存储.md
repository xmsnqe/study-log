# 文件外部存储

## 📍知识定位

### 在408体系中的位置

文件外部存储是文件管理的**物理基础**，理解磁盘、磁带的硬件特性与存储层次，是学习文件物理结构（连续分配、链接分配、索引分配）、磁盘分配与回收（空闲空间管理）、磁盘调度（SSTF、SCAN等算法）的前提。在408考试中，外存介质特性常以选择题形式出现。

### 学习前置条件

- **存储器**：理解计算机存储层次结构（寄存器 → Cache → 主存 → 辅存）
- **计算机组成原理**：理解磁盘的几何结构（磁道、扇区、柱面）、存取时间计算
- **IO系统**：理解I/O控制方式与磁盘作为外设的传输特性

### 学完之后支撑的知识点

- **文件物理结构**：文件在磁盘上的存储方式（连续、链接、索引）
- **磁盘分配与回收**：磁盘空闲空间的管理方法（位示图、空闲链表）
- **磁盘调度**：磁盘访问的调度算法（FCFS、SSTF、SCAN、C-SCAN）
- **IO系统**：磁盘作为I/O设备的访问控制方式

## 📝核心概念与原理

### 一、外存储器概述 ⭐

#### 1. 外存（Auxiliary Memory / Secondary Storage）

> **外存储器（外存）**：是计算机存储系统中**容量大、成本低、可长期保存**的存储设备。断电后内容不丢失，因此也叫**非易失性存储器**。外存通过I/O接口与CPU通信，速度远低于主存。

**外存的主要类型**：

| 类型 | 特点 | 典型容量 | 读写速度 | 408考纲要求 |
|------|------|---------|---------|------------|
| **磁盘（Magnetic Disk）** | 传统外存主力，可读写，磁介质存储 | GB ~ TB级 | 中等（~100MB/s） | **重点**：文件管理的主要载体 |
| **光盘（Optical Disk）** | 光介质存储，可只读或可读写 | GB级 | 较低（~20MB/s） | 了解 |
| **闪存/SSD（Flash Memory）** | 电子存储，无机械部件 | GB ~ TB级 | 高（~500MB/s+） | 了解 |
| **磁带（Magnetic Tape）** | 串行访问，适合备份 | TB级 | 很低（~100MB/s持续） | 了解 |

> 从CSAPP视角看，外存在存储层次中处于最底层，是主存的**后备存储（Backing Store）**。虚拟内存机制正是利用外存来实现"比物理内存更大的地址空间"。

```
计算机存储层次结构（由上到下）：
┌─────────────────────┐  最快、最贵、最小
│  寄存器（Register）   │  ~ns级
├─────────────────────┤
│  Cache（L1/L2/L3）   │  ~ns级
├─────────────────────┤
│  主存（Main Memory）  │  ~100ns级
├─────────────────────┤
│  外存（Secondary）   │  ~ms级（磁盘）
│  - 磁盘               │
│  - SSD                │
├─────────────────────┤
│  磁带（Tape）         │  最慢、最便宜、最大
└─────────────────────┘  最慢、最便宜、最大
```

> ⭐ **选择题考点**：
> 1. 外存是**非易失性**存储器（断电不丢失数据）
> 2. 外存速度远低于主存，是存储层次中最底层
> 3. 外存通过**I/O接口**与CPU通信，不是直接通过总线

#### 2. 外存与主存的分工 ⭐

| 对比项 | 主存（内存） | 外存（辅存） |
|--------|------------|------------|
| **挥发性** | 易失性（断电数据丢失） | 非易失性（断电数据保留） |
| **速度** | 快（纳秒级） | 慢（毫秒级） |
| **容量** | 较小（GB级） | 大（TB级） |
| **成本** | 高（每GB价格高） | 低（每GB价格低） |
| **访问方式** | 随机访问 | 部分随机（磁盘），部分顺序（磁带） |
| **CPU直接访问** | 是 | 否（需通过I/O接口和缓冲区） |
| **主要用途** | 存放正在运行的程序和当前数据 | 存放持久化数据、程序、文件 |

```
主存 ↔ 外存 的数据交换：
┌──────────┐    I/O传输    ┌──────────┐
│  主存    │◄──────────────►│  外存    │
│ (RAM)    │  DMA/中断     │ (磁盘)   │
└──────────┘               └──────────┘
   ↑ 程序运行时的数据           ↑ 持久化存储的文件
   ↑ 虚拟内存的页缓存           ↑ 操作系统的页文件
```

> 从CSAPP视角看，主存和外存通过**虚拟内存机制**实现动态链接：当进程访问的页面不在内存时，操作系统从外存（磁盘上的页文件）将页面调入主存，这就是"缺页中断"的底层原理。

### 二、磁盘的结构与工作原理 🔥

> 磁盘（Disk）是408考纲中**外存的核心代表**，文件管理的物理基础主要建立在磁盘之上。

#### 1. 磁盘的物理结构 ⭐

磁盘由**盘片（Platter）**、**磁头（Head）**、**盘臂（Arm）** 和 **主轴（Spindle）** 组成。

```
磁盘物理结构示意图：
                    盘臂（Arm）
                    ┌─────────┐
                    │  磁头   │ ← 读取/写入数据
                    └────┬────┘
                         │ 悬浮在盘片上方
                    ╔════╧════╗
           ════════│ 盘片   │════════
                    ╚════╦════╝
                         │
                    主轴（Spindle）→ 旋转

俯视图（从上方看）：
        ╭───────────────╮
        │  ╭─────────╮  │
        │  │  ○     │  │  ← 盘片（Platter）
        │  │  磁头  │  │  ← 磁头（Head）在磁道上移动
        │  ╰───────╯  │
        ╰───────────────╯
         柱面（Cylinder）→ 垂直对齐的磁道集合
```

**关键物理参数**：

| 参数 | 说明 | 典型值 |
|------|------|--------|
| **盘片（Platter）** | 磁盘的基本存储介质，一个磁盘包含多个盘片 | 2~8片 |
| **磁道（Track）** | 盘片上以同心圆形式划分的磁环 | 每面数百到数千条 |
| **扇区（Sector）** | 磁道上的一段弧，是磁盘的**最小存储单位** | 通常为512字节或4KB |
| **柱面（Cylinder）** | 所有盘面上半径相同的磁道组成的柱面 | 减少磁头移动 |
| **磁头（Head）** | 每个盘面一个，用于读写数据 | 盘片数×2 |
| **转速（RPM）** | 盘片旋转速度 | 5400~15000 RPM |

> ⭐ **选择题高频考点**：
> 1. 扇区是磁盘的**最小物理存储单位**（通常为512字节）
> 2. 柱面是"所有盘面上相同半径的磁道"——保证**无需移动磁头**即可在不同盘面间读写
> 3. 磁盘地址通常由 **柱面号 + 磁头号 + 扇区号** 三元组确定

#### 2. 磁盘的寻址方式

> 磁盘通过**C/H/S（Cylinder/Head/Sector）** 三元组来寻址：

```
磁盘地址 = <C, H, S>
C = 柱面号（Cylinder）  → 决定磁头移动到哪个半径
H = 磁头号（Head）      → 选择哪个盘面的磁头
S = 扇区号（Sector）    → 确定磁道上的具体扇区
```

**现代磁盘的LBA（Logical Block Addressing）**：

```
传统 CHS 寻址 → 现代 LBA 线性寻址
<C, H, S>  →  线性块号（从0开始的连续整数）

逻辑块编号 = C × (每柱面扇区数) + H × (每磁道扇区数) + S

操作系统使用LBA访问磁盘，对外隐藏了物理结构的复杂性。
```

> 从CSAPP视角看，文件系统以"块（Block）"为最小单位管理磁盘，一个块通常等于或大于一个扇区（如4KB = 8 × 512B扇区）。

#### 3. 磁盘的存取时间 🔥

> **磁盘存取时间（Disk Access Time）** 是衡量磁盘性能的核心指标，也是408考试的**大题热点**。

```
磁盘存取时间 = 寻道时间 + 旋转延迟 + 传输时间

┌──────────────────────────────────────────┐
│  磁盘存取时间                              │
│  ┌─────────┐ ┌──────────┐ ┌───────────┐  │
│  │ 寻道时间 │ │ 旋转延迟 │ │ 传输时间  │  │
│  │ Seek    │ │ Rotation │ │ Transfer  │  │
│  └─────────┘ └──────────┘ └───────────┘  │
│                                            │
│  = 磁头移动到目标磁道的时间                  │
│  + 等待目标扇区旋转到磁头下方的时间           │
│  + 实际读取/写入数据的时间                   │
└──────────────────────────────────────────┘
```

**（1）寻道时间（Seek Time）** ⭐

> 磁头从当前磁道移动到目标磁道所需的时间。

```
寻道时间 = f(磁道距离)
通常 1ms ~ 10ms，取决于磁头需要移动的距离

最短寻道时间（同柱面）：~0.5ms
最长寻道时间（最外圈到最内圈）：~10ms
平均寻道时间：通常取 5ms 左右（408计算题默认值）
```

> ⭐ **选择题考点**：寻道时间是磁盘存取时间的**最大组成部分**，磁盘调度算法的核心目标就是**最小化平均寻道时间**。

**（2）旋转延迟（Rotational Latency）** ⭐

> 等待目标扇区旋转到磁头下方所需的时间。

```
旋转延迟 = 磁盘旋转半周所需的时间（平均情况）

平均旋转延迟 = 1 / (2 × RPM) × 60

典型值：
- 7200 RPM：平均旋转延迟 ≈ 6.67ms
- 5400 RPM：平均旋转延迟 ≈ 11.11ms
- 10000 RPM：平均旋转延迟 ≈ 5.0ms
- 15000 RPM：平均旋转延迟 ≈ 3.33ms

注意：最大旋转延迟 = 完整旋转一周的时间 = 60/RPM
```

> ⭐ **计算题必考**：平均旋转延迟 = 1 / (2 × RPM) × 60

**（3）传输时间（Transfer Time）**

> 读/写出一个扇区所需的时间。

```
传输时间 = 1个扇区的大小 / 磁盘数据传输率
        = 扇区大小 / (每磁道扇区数 × 转速)

示例：512字节扇区，7200RPM，每磁道100个扇区
传输时间 = 512B / (100 × 7200/60) B/s
         = 512B / 12000B/s
         ≈ 0.0427ms
```

#### 4. 磁盘存取时间计算示例 🔥

> 这是一道典型的408计算大题。

**例题**：一磁盘转速为7200RPM，每磁道100个扇区，每扇区512字节，磁盘数据传输率为 6.144MB/s。求：
1. 平均旋转延迟
2. 读取一个扇区的传输时间
3. 读取一个磁盘块的总时间（假设平均寻道时间为8ms）

**解答**：

```
（1）平均旋转延迟 = 1 / (2 × 7200/60) s
                 = 1 / 240 s
                 ≈ 4.17ms

（2）传输时间：
    方式一（用数据传输率）：
    传输时间 = 512B / 6.144MB/s = 512B / 6291456B/s ≈ 0.0814ms

    方式二（用转速）：
    传输时间 = 60 / (7200 × 100) s
             = 60 / 720000 s
             ≈ 0.0833ms

（3）读取一个磁盘块总时间：
    总时间 = 寻道时间 + 平均旋转延迟 + 传输时间
           = 8ms + 4.17ms + 0.083ms
           ≈ 12.25ms
```

> ⭐ **计算题模板**：
> - 平均旋转延迟 = 1 / (2 × RPM/60) s = 30/RPM 秒 = 30000/RPM 毫秒
> - 总存取时间 = 寻道时间 + 平均旋转延迟 + 传输时间

### 三、磁盘的结构参数汇总

#### 1. 磁盘容量计算 🔥

```
磁盘总容量 = 盘面数 × 每盘面磁道数 × 每磁道扇区数 × 每扇区字节数

或按柱面计算：
磁盘总容量 = 柱面数 × 磁头数 × 每磁道扇区数 × 每扇区字节数

示例：双盘面、每盘面2000磁道、每磁道100扇区、每扇区512字节
磁盘容量 = 2 × 2000 × 100 × 512 = 204,800,000 字节 ≈ 195.3MB
```

> ⭐ **选择题考点**：磁盘容量 = 柱面数 × 磁头数 × 每磁道扇区数 × 扇区大小。

#### 2. 磁盘数据传输率

```
数据传输率（数据传输速率）= 磁盘每分钟转数 × 每转读写的字节数

每转读写的字节数 = 每磁道扇区数 × 每扇区字节数

示例：7200RPM，每磁道100扇区，每扇区512字节
数据传输率 = 7200 × 60 × 100 × 512
           = 7200/60 × 100 × 512
           = 120 × 51200
           = 6,144,000 B/s ≈ 6.144MB/s
```

### 四、磁带

#### 1. 磁带的特性

> **磁带（Magnetic Tape）** 是另一种外存介质，主要用于**数据备份**和**归档存储**。

| 特性 | 说明 |
|------|------|
| **访问方式** | **串行访问**（顺序访问），不是随机访问 |
| **速度** | 远低于磁盘 |
| **容量** | 很大（TB级） |
| **成本** | 每GB成本最低 |
| **用途** | 备份、归档、大数据长期存储 |

> ⭐ **选择题考点**：磁带是**顺序存取**设备，不是随机存取设备。磁盘是**随机存取**（直接存取）设备。

#### 2. 磁带与磁盘的对比

| 对比项 | 磁盘 | 磁带 |
|--------|------|------|
| **访问方式** | 直接访问（随机） | 顺序访问 |
| **存取时间** | 快（毫秒级） | 慢（秒级） |
| **容量** | TB级 | PB级 |
| **成本** | 每GB ~$0.02 | 每GB ~$0.003 |
| **典型用途** | 文件系统、数据库 | 备份、归档 |
| **408考纲** | **重点** | 了解即可 |

### 五、闪存（SSD）

#### 1. SSD的基本原理

> **固态硬盘（SSD, Solid State Drive）** 基于闪存（Flash Memory）技术，无机械部件，通过电子存储数据。

```
传统HDD vs SSD：
┌──────────────────────┐  ┌──────────────────────┐
│  传统HDD（机械硬盘）    │  │  固态硬盘（SSD）       │
│  ┌────────────────┐   │  │  ┌────────────────┐  │
│  │  盘片 + 磁头    │   │  │  │  NAND Flash    │  │
│  │  (机械运动)     │   │  │  (电子存储)      │  │
│  └────────────────┘   │  │  └────────────────┘  │
│  寻道时间：~5ms        │  │  访问时间：<0.1ms     │
│  传输速率：~150MB/s   │  │  传输速率：~500MB/s+ │
└──────────────────────┘  └──────────────────────┘
```

**SSD的关键特性（408需要了解）**：

| 特性 | 说明 |
|------|------|
| **无机械部件** | 无寻道时间、无旋转延迟 |
| **访问速度** | 比磁盘快一个数量级 |
| **写入限制** | Flash有写入次数限制（约10^5次） |
| **块粒度大** | SSD的写以"块"为单位，擦除以"块"为单位 |
| **TRIM命令** | 用于通知SSD哪些数据块已不再使用 |

> 从CSAPP视角看，SSD通过**控制器（Controller）** 隐藏了Flash的物理特性，对操作系统呈现为标准的块设备。

### 六、外存与文件管理的关联

#### 1. 文件在外存上的分布

> 文件存储在磁盘上，具体通过文件系统的管理来组织：

```
用户文件
    │
    ▼
┌──────────────────────────────────┐
│  文件系统的块（Block）管理          │
│  ┌────┬────┬────┬────┬────┐     │
│  │ B1 │ B2 │ B3 │ B4 │ B5 │ ... │  ← 逻辑块（文件系统分配）
│  └────┴────┴────┴────┴────┘     │
│       ↓ 映射 ↓                    │
│  ┌──────────────────────────┐   │
│  │  磁盘物理块（扇区）          │   │  ← 物理存储
│  │  [连续/链接/索引分配]       │   │
│  └──────────────────────────┘   │
└──────────────────────────────────┘
```

#### 2. 文件存储的基本概念

| 概念 | 说明 | 与外存的关联 |
|------|------|------------|
| **文件块（File Block）** | 文件系统分配给文件的最小逻辑单位 | 通常 = 磁盘块（4KB） |
| **物理块（Disk Block）** | 磁盘上的实际存储单元 | 通常 = 多个扇区 |
| **空闲块** | 未被文件使用的磁盘块 | 磁盘分配与回收管理的对象 |
| **文件分配方式** | 连续、链接、索引 | 取决于外存的物理特性 |

> 从CSAPP视角看，虚拟文件系统的页缓存（Page Cache）将外存中的文件数据缓存到主存中，使得文件I/O看起来像是内存访问。

## ⚖️易混淆概念对比

### 磁盘 vs 磁带（访问方式）

| 对比项 | 磁盘 | 磁带 |
|--------|------|------|
| **访问方式** | 随机访问（直接存取） | 顺序访问（串行存取） |
| **存取时间** | 毫秒级（含寻道+旋转） | 秒级（需倒带/前进） |
| **典型应用** | 文件系统、数据库 | 数据备份、归档 |
| **关联文档** | [[文件物理结构]],[[磁盘调度]] | 了解即可 |

### 扇区 vs 磁盘块

| 对比项 | 扇区（Sector） | 磁盘块（Block） |
|--------|---------------|----------------|
| **定义层级** | 物理层面的最小存储单位 | 逻辑层面的最小分配单位 |
| **大小** | 512B 或 4KB | 通常为4KB（可能 = 1个或多个扇区） |
| **由谁定义** | 磁盘硬件 | 文件系统 |
| **文件系统使用** | 不直接操作扇区，操作块 | 操作的基本单位 |
| **关联文档** | — | [[文件物理结构]] |

### 外存 vs 主存

| 对比项 | 主存（内存） | 外存（辅存） |
|--------|------------|------------|
| **易失性** | 易失性 | 非易失性 |
| **CPU直接访问** | 可以直接访问 | 需通过I/O接口 |
| **速度** | 纳秒级 | 毫秒级 |
| **用途** | 运行程序、存放数据 | 持久化存储 |
| **关联文档** | [[内存管理]],[[虚拟内存]] | [[文件物理结构]],[[磁盘调度]] |

### 寻道时间 vs 旋转延迟

| 对比项 | 寻道时间 | 旋转延迟 |
|--------|---------|---------|
| **含义** | 磁头移动到目标磁道的时间 | 等待目标扇区旋转到磁头下方的时间 |
| **量级** | ~5ms（最大~10ms） | ~4ms（7200RPM） |
| **影响因素** | 磁头当前位置与目标磁道的距离 | 磁盘转速 |
| **优化手段** | 磁盘调度算法（SSTF、SCAN） | 提高转速、调整请求顺序 |

## ⚠️考试高频坑点

### 坑点1：扇区 vs 块的概念混淆 ⭐

> 【考试考法】下列说法正确的是？
> A. 扇区是文件系统的最小分配单位
> B. 块是磁盘的最小物理存储单位
> C. 扇区是磁盘的最小物理存储单位
> D. 扇区和块是同一概念
>
> **答案**：C
>
> 扇区是磁盘的**物理最小单位**（512B），块是文件系统的**逻辑最小分配单位**（4KB）。块由文件系统定义，扇区由磁盘硬件定义。

### 坑点2：磁带的访问方式 ⭐

> 【考试考法】下列哪种外存是顺序存取设备？
> A. 磁盘  B. SSD  C. 磁带  D. U盘
>
> **答案**：C（磁带是顺序存取设备）
>
> 磁盘是随机存取，SSD是随机存取，U盘（闪存）也是随机存取。只有磁带是顺序存取。

### 坑点3：柱面的定义 ⭐

> 【考试考法】柱面（Cylinder）是指什么？
> A. 一个盘面上所有磁道的集合
> B. 所有盘面上半径相同的磁道组成的集合
> C. 磁盘上所有扇区的集合
> D. 一个磁道上所有扇区的集合
>
> **答案**：B
>
> 柱面 = 所有盘面上相同半径的磁道 → 这些磁道在同一半径位置，磁头切换无需移动，只需换磁头。

### 坑点4：存取时间的组成 ⭐

> 【考试考法】磁盘存取时间不包括以下哪项？
> A. 寻道时间  B. 旋转延迟  C. 传输时间  D. 中断处理时间
>
> **答案**：D（中断处理时间不属于磁盘存取时间）
>
> 磁盘存取时间 = 寻道时间 + 旋转延迟 + 传输时间

### 坑点5：平均旋转延迟的计算公式 ⭐

> 【考试考法】磁盘转速为7200RPM，平均旋转延迟是多少？
>
> **答案**：
> 平均旋转延迟 = 1 / (2 × 7200/60) s = 1/240 s ≈ 4.17ms
>
> 公式：**平均旋转延迟 = 30000 / RPM**（单位：ms）
> 或：**平均旋转延迟 = 1 / (2 × 转速/60)**（单位：s）
>
> 易错点：误认为平均旋转延迟是完整旋转一周的时间（那是最大旋转延迟）。

### 坑点6：磁盘容量计算中的"磁头数" ⭐

> 【考试考法】某磁盘有4个盘片，每个盘面1000条磁道，每条磁道50个扇区，每扇区512字节，该磁盘容量为多少？
>
> **答案**：
> 磁盘容量 = 4 × 1000 × 50 × 512 = 102,400,000 字节 ≈ 97.66MB
>
> 易错点：磁头数 = 盘片数（每个盘面一个磁头），不是盘片数×2。
