# 分页存储管理

## 📍知识定位

### 在 408 体系中的位置

分页存储管理（Paging Memory Management）是操作系统的**核心内存管理方式**，它将进程地址空间和物理内存划分为固定大小的页和页框（页帧），实现了**离散分配**，彻底消除了外部碎片。这是 408 考试中**选择题和大题均高频考查**的章节，涉及页表结构、地址转换、页表级数计算等核心内容。

### 学习前置条件

- **内存管理**：理解逻辑地址与物理地址、连续分配与非连续分配的基本概念
- **内存分配与回收**：理解分页的基本思想与连续分配的区别
- **计算机组成原理**：理解存储器的层次结构和地址映射

### 学完之后支撑的知识点

- **虚拟内存**：请求分页是虚拟内存的基础
- **页面置换算法**：缺页中断的处理依赖于分页机制
- **存储保护**：页表结构决定了内存保护的实现
- **内存碎片**：分页消除了外部碎片，但仍有内部碎片

## 📝核心概念与原理

### 1. 分页的基本思想

分页存储管理的核心思想是：**将进程地址空间和物理内存划分为大小相等的页（Page）和页框（Page Frame/页帧）**。

| 概念 | 说明 | 大小 |
|------|------|------|
| **页（Page）** | 进程逻辑地址空间的划分单位 | 固定大小，通常为 4KB、8KB、16KB 等 |
| **页框/页帧（Page Frame）** | 物理内存的划分单位 | 与页大小相同 |
| **页号（Page Number, p）** | 页的编号 | p = ⌊逻辑地址/页大小⌋ |
| **页内偏移（Offset, d）** | 页内的字节偏移 | d = 逻辑地址 mod 页大小 |

> ⭐ **选择题高频考点**：页的大小必须是 2 的幂，且通常与计算机的字长或缓存行对齐。常见的页大小有 4KB（最常用）、8KB、16KB 等。

#### 地址结构

逻辑地址空间被划分为页号和页内偏移两部分：

```
|-------- 页号 p --------|---- 页内偏移 d ----|
|  log(n) 位              |     log(L) 位       |
```

其中 n 是页数，L 是页大小（页框大小）。

> ⭐ 地址转换公式：**物理地址 = 页号 × 页大小 + 页内偏移**。页内偏移在地址转换过程中保持不变，这是分页机制的核心特征。

### 2. 页表（Page Table）

页表是操作系统用来管理进程页表项的数据结构，是地址转换的核心。

#### 页表的结构

每个页表项（Page Table Entry, PTE）包含：

| 字段 | 说明 | 大小 |
|------|------|------|
| **页框号/物理页号** | 页在物理内存中的页框编号 | 取决于物理内存大小 |
| **状态位（Valid/Invalid）** | 页是否在内存中（1=在内存，0=不在内存） | 1 bit |
| **保护位** | 页的访问权限（读/写/执行） | 1~2 bits |
| **修改位（Dirty Bit）** | 页是否被修改过（1=已修改） | 1 bit |
| **访问位（Access Bit）** | 页是否被访问过（用于置换算法） | 1 bit |
| **外存地址** | 页在外存的地址（用于换入） | 取决于外存大小 |

> ⭐ **选择题高频考点**：页表项中**必须包含**的字段是"页框号"和"状态位"。修改位和外存地址在请求分页系统中需要，在简单分页中可省略。

#### 页表的组织

```
进程逻辑地址空间              页表                    物理内存
┌──────────────┐           ┌──────────────┐        ┌──────────────┐
│  页 0        │──────────→│ PTE 0: 页框 3  │────────│  页框 3        │
│  页 1        │──────────→│ PTE 1: 页框 7  │────────│  页框 7        │
│  页 2        │──────────→│ PTE 2: 不在内存 │        │  ...           │
│  ...         │           │  ...           │        └──────────────┘
└──────────────┘           └──────────────┘
```

> ⭐ 页表的**基址寄存器**（页表基址寄存器 PTBR）存储页表的起始地址，**限长寄存器**存储页表长度（即进程页数）。

### 3. 地址变换过程

逻辑地址到物理地址的转换过程：

```
逻辑地址 (p, d)  →  查页表 →  页框号 f  →  物理地址 (f, d)
```

具体步骤：

1. 将逻辑地址拆分为页号 p 和页内偏移 d
2. 检查页号 p 是否越界（p > 页表长度 → 产生地址越界中断）
3. 查页表获得页框号 f
4. 检查状态位：
   - 若状态位 = 1（页在内存）：直接将 f 与 d 拼接得到物理地址
   - 若状态位 = 0（页不在内存）：产生缺页中断，从外存调入

> ⭐ **选择题高频考点**：地址变换过程中，页内偏移 d 保持不变。物理地址 = 页框号 × 页大小 + d。

#### 地址变换的时间消耗

| 项目 | 说明 | 耗时 |
|------|------|------|
| 一次访存（读指令或数据） | 从内存读取指令或数据 | 1 个时钟周期 |
| 地址变换（查页表） | 需要从内存读取页表项 | 额外 1 个访存 |
| **双重访存** | 读指令 + 读页表 = 2 次访存 | 性能下降 2 倍 |

> ⚠️ 分页地址变换引入的"双重访存"问题：每次访存都需要额外访问一次内存（页表），这会使得性能下降一倍。解决此问题的方法是引入 **TLB（快表）** 和 **多级页表**。

### 4. 分页系统的优点与缺点

#### 优点

| 优点 | 说明 |
|------|------|
| **消除外部碎片** | 页大小固定，不会像连续分配那样产生外部碎片 |
| **离散分配** | 进程可以分散存储在物理内存的不同页框中 |
| **实现简单** | 页表结构简单，易于硬件支持 |
| **支持虚拟内存** | 为请求分页和虚拟内存机制奠定基础 |

#### 缺点

| 缺点 | 说明 |
|------|------|
| **内部碎片** | 最后一页可能不满，产生内部碎片（平均 0.5 页） |
| **页表开销** | 大地址空间需要大页表，占用内存 |
| **需要额外访存** | 地址变换需要访问页表，降低性能 |

> ⭐ **选择题高频考点**：分页消除了外部碎片，但会产生内部碎片（平均每进程 0.5 页的内部碎片）。这是分页系统最核心的优缺点。

### 5. 页大小选择

页大小的选择需要权衡多个因素：

| 页大小 | 优点 | 缺点 |
|--------|------|------|
| **小页（如 1KB）** | 内部碎片少，内存利用率高 | 页表项多，地址变换慢，页表占用内存多 |
| **大页（如 64KB）** | 页表项少，地址变换快，页表占用少 | 内部碎片多，内存利用率低 |
| **适中（如 4KB）** | 折中方案 | 兼顾内外碎片和地址变换效率 |

> ⭐ 现代系统中，4KB 是最常用的页大小，ARM/x86 等架构默认使用 4KB 页。某些系统也支持大页（2MB、1GB）。

## ⚖️易混淆概念对比

| 对比项 | 分页存储管理 | 分段存储管理 |
|--------|-------------|-------------|
| 地址空间 | 一维（连续编号） | 二维（段号+段内偏移） |
| 单元大小 | 固定大小（页） | 可变大小（段） |
| 划分依据 | 物理因素（页大小固定） | 逻辑因素（按函数、数据结构分段） |
| 碎片类型 | 内部碎片 | 外部碎片 |
| 页表特点 | 页表项包含页框号 | 段表项包含段起始地址和段长 |
| 地址变换 | 页号→页框号，偏移不变 | 段号→段起始地址，偏移=逻辑地址-段起始 |

| 对比项 | 简单分页 | 请求分页 |
|--------|---------|---------|
| 全部装入内存 | ✅ 是 | ❌ 否（按需调入） |
| 是否需要外存 | ❌ 否 | ✅ 是（虚拟内存） |
| 是否支持虚拟内存 | ❌ 否 | ✅ 是 |
| 缺页中断 | 无 | 有（页面不在内存时） |

## ⚠️考试高频坑点

| 坑点 | 错误理解 | 正确理解 |
|------|---------|---------|
| 分页的碎片类型 | 认为分页产生外部碎片 | 分页消除外部碎片，但产生内部碎片 |
| 页内偏移变化 | 认为页内偏移在地址转换中会变化 | 页内偏移在整个地址转换过程中保持不变 |
| 页表大小 | 认为页表可以存储在寄存器中 | 页表常驻内存，寄存器中只存储页表基址 |
| 页框号计算 | 误认为页框号是逻辑地址 | 页框号是物理页框的编号，需要通过页表获取 |
| 双重访存 | 认为地址变换不消耗额外访存 | 每次访存需要额外访问页表（除非有 TLB） |
