# 04 网络层（Network Layer）

> 📌 网络层是408计算机考研的**核心大题模块**，IP地址计算、路由算法、ICMP协议等是必考内容。

---

| 维度 | 说明 |
|------|------|
| **在408体系中的位置** | 自顶向下五层模型的第3层，承上启下：为上层的传输层提供"主机到主机"的逻辑通信服务 |

## 📝核心概念与原理

### 一、网络层功能概述 🔥

网络层向传输层提供的服务有两种选择：

1. **虚电路服务（Virtual-Circuit Service）**：面向连接，所有分组沿相同路径，按序到达（如X.25、ATM）
2. **数据报服务（Datagram Service）**：无连接，每个分组独立路由，可能失序、丢失、重复（如Internet的IP协议）⭐

> **⭐选择题高频**：Internet网络层核心协议IP提供**不可靠、无连接**的数据报服务。

---

### 二、网络层内部功能：转发与路由 🔥

网络层实现两个核心功能：

| 功能 | 定义 | 类比 |
|------|------|------|
| **转发（Forwarding）** | 路由器收到分组后，将分组从**输入端口**迁移到合适的**输出端口**（本地操作，毫秒级） | 快递员把包裹从卸货区放到指定运输车上 |
| **路由（Routing）** | 通过路由算法确定**源到目的**的端到端路径（全局操作，秒级） | 物流公司规划整条运输线路 |

**⭐ 数据转发表（Forwarding Table）**：路由器中的转发表，用于转发决定。转发表与路由表（Routing Table）不同：
- 路由表：由路由协议（OSPF、RIP等）生成，包含拓扑信息
- 转发表：由路由表衍生，实际用于转发分组，包含 (输出端口, 下一跳) 映射

### 三、网络寻址：IP协议 🌟

#### 3.1 IP地址

**IP地址（IPv4）**：32位，用4个十进制数点分表示，如 `192.168.1.1`

```
32位IP地址格式：
┌─────────────────────┬─────────────────────┐
│     网络号（NetID）   │     主机号（HostID）   │
│  标识所属子网        │  标识该子网中具体主机  │
└─────────────────────┴─────────────────────┘
```

#### 3.2 子网划分（Subnetting）🔥

**目的**：减少路由表条目、提高地址利用率、实现网络隔离

**子网掩码（Subnet Mask）**：与IP地址逐位AND，提取网络/子网号

```
IP地址：    192.168.1.100  = 11000000.10101000.00000001.01100100
子网掩码：  255.255.255.0  = 11111111.11111111.11111111.00000000
AND运算结果（网络地址）：192.168.1.0
```

> **⭐选择题高频考点**：
> - /24掩码 = 255.255.255.0，可容纳2^8 - 2 = 254个主机（减去网络地址和广播地址）
> - CIDR表示法：`192.168.1.0/24` 中 `/24` 表示前24位是网络前缀

#### 3.3 子网划分计算步骤（大题必考）🔥

```
给定IP地址和CIDR前缀，求：网络地址、广播地址、可用主机范围、主机数量

示例：192.168.10.50/26

步骤1：写掩码
  /26 → 255.255.255.192 → 11111111.11111111.11111111.11000000

步骤2：写IP二进制
  192.168.10.50 → 11000000.10101000.00001010.00110010

步骤3：网络地址 = IP AND 掩码
  11000000.10101000.00001010.00110000 → 192.168.10.48

步骤4：广播地址 = 主机位全部置1
  11000000.10101000.00001010.00111111 → 192.168.10.63

步骤5：可用主机范围
  第一个：192.168.10.49
  最后一个：192.168.10.62

步骤6：可用主机数
  2^(32-26) - 2 = 2^6 - 2 = 62
```

#### 3.4 CIDR与路由聚合 🔥

**CIDR（无类别域间路由）**：消除A/B/C类划分，允许任意长度网络前缀

**路由聚合（Route Aggregation / Supernetting）**：将多个连续子网合并为一个聚合路由条目，减少路由器转发表规模。

```
聚合示例：
  172.16.1.0/24  →  00010001 00010000 00000001 .00000000
  172.16.2.0/24  →  00010001 00010000 00000010 .00000000
  172.16.3.0/24  →  00010001 00010000 00000011 .00000000
  172.16.4.0/24  →  00010001 00010000 00000100 .00000000

共同前缀：172.16.0.0/22（前22位相同：00010001 00010000 0000）
  聚合后可减少3条路由表项
```

> **⭐选择题高频考点**：最长前缀匹配（Longest Prefix Match）——路由器转发表匹配时，选择前缀最长（掩码最长）的匹配项。

### 四、NAT（网络地址转换）⭐

**NAT（Network Address Translation）**：在私有网络和公共网络之间进行IP地址转换

**工作场景**：多个内部主机共享一个或多个公共IP地址访问Internet

```
NAT转换过程：
  内部主机：192.168.1.100:5555 发送数据到 外部服务器 8.8.8.8:80
  
  NAT路由器维护转换表：
  内部本地地址:端口  →  内部公共地址:端口  →  外部地址:端口
  
  192.168.1.100:5555  →  203.0.113.5:12345  →  8.8.8.8:80
  
  返回时：
  8.8.8.8:80 → 203.0.113.5:12345 被NAT翻译回 192.168.1.100:5555
```

> **⭐选择题高频考点**：
> - NAT改变了IP分组的**源IP地址**（出方向）或**目的IP地址**（入方向）
> - NAT**不改变传输层的源/目的端口号**（使用NAT映射时，端口也会被重新映射但属于NAT管理的）
> - NAT对**应用层协议有影响**：嵌入在数据中的IP地址/端口号需要ALG（应用层网关）修改
> - NAT破坏了TCP/UDP的端到端语义

### 五、ICMP协议（Internet Control Message Protocol）🌟

**ICMP（互联网控制报文协议）**：为IP层提供差错报告和控制功能

| ICMP报文类型 | 说明 | 典型报文 |
|-------------|------|---------|
| 差错报告 | 报告IP分组无法处理的情况 | 目的地不可达、超时、参数问题、源站抑制 |
| 查询/控制 | 网络诊断和管理 | 回射请求/应答（ping）、时间戳请求/应答 |

> **⚠️重点注意**：ICMP报文**封装在IP数据报中**，IP数据报的协议字段值为1。ICMP报文又作为IP数据报的数据部分。

```
以太网帧
├── 以太网头
├── IP头（协议=1，表示ICMP）
│   ├── IP头
│   └── ICMP报文
│       ├── ICMP头（类型、代码、校验和）
│       └── ICMP数据
└── 以太网FCS
```

**ICMP差错报告规则（大题常考）🔥**：

1. 不对ICMP差错报告报文再发送ICMP差错报告
2. 对以下分组不发送"目的地不可达"：
   - 目的地址为广播或多播的分组
   - 分片的第1个分片（只有第1个分片才含传输层头部，才能确定不可达原因）
   - 源地址为广播、环回地址、多播的分组

**ping与traceroute原理 🔥**：

- **ping**：使用ICMP回射请求（Type 8）和回射应答（Type 0），测量往返时间RTT
- **traceroute**：
  - 发送一系列UDP报文（或ICMP报文），TTL从1开始递增
  - TTL=1时，第一跳路由器丢弃并返回ICMP"超时"报文
  - TTL=2时，第二跳路由器丢弃并返回ICMP"超时"报文
  - 依次递增，直到到达目的主机

### 六、IPv6 🌟

**IPv6目的**：解决IPv4地址耗尽问题，同时改善路由、QoS、安全性

**IPv4 vs IPv6对比：**

| 特性 | IPv4 | IPv6 |
|------|------|------|
| 地址长度 | 32位（4字节） | 128位（16字节） |
| 地址表示 | 点分十进制 | 冒号十六进制，如 `2001:0db8:85a3:0000:0000:8a2e:0370:7334` |
| 首部长度 | 20-60字节（可变） | 固定40字节 |
| 首部字段 | 20+个字段，含校验和 | 简化为8个固定字段，首部校验和取消 |
| 分片 | 路由器可分片 | 仅源主机分片（使用扩展首部） |

> **⭐选择题高频考点**：IPv6简化了路由器处理（无首部校验和、无分片重组），提升转发效率。

**IPv6地址类型**：
- **单播（Unicast）**：一对一
- **多播（Multicast）**：一对多（取代IPv4的广播）
- **任播（Anycast）**：一对一多，发给最近的一个

### 七、路由协议 🔥

#### 7.1 路由算法分类

| 算法类型 | 描述 | 代表协议 |
|---------|------|---------|
| **非自适应（静态路由）** | 路由选择事先确定，不随网络拓扑变化 | 手动配置路由 |
| **自适应（动态路由）** | 路由选择随网络拓扑和通信量变化 | RIP、OSPF、BGP |

#### 7.2 距离向量算法（Distance Vector）🔥

**核心思想**："Bellman-Ford方程"

```
K是节点v到目的节点x的最短路径代价
d(v,x) = min{ c(v,u) + d(u,x) }  对所有邻居u
```

**工作原理**：
1. 每个节点仅与**直接相邻节点**交换信息
2. 每个节点维护一个**距离向量**：到所有目的节点的估计距离
3. 定期（如RIP每30秒）向邻居发送自己的距离向量
4. 收到邻居的距离向量后，更新自己的距离向量

> **⭐选择题高频考点**：距离向量算法的"坏消息传播慢"问题（计数到无穷大问题的根源）。

#### 7.3 链路状态算法（Link State）🔥

**Dijkstra算法流程**：
1. 初始化：确定起点节点，所有节点距离设为∞，起点为0
2. 选择当前距离最小的未访问节点u
3. 松弛：对u的每个邻居v，若d[u]+cost(u,v) < d[v]，则更新d[v]
4. 标记u为已访问
5. 重复2-4直到所有节点都被访问

**工作原理**：
1. 每个节点**广播**链路状态分组（LS）给**所有其他节点**（泛洪）
2. 所有节点收集完整的网络拓扑信息，构建相同的链路状态数据库（LSDB）
3. 在LSDB上运行Dijkstra算法，计算最短路径树（SPT）
4. 从SPT导出路由表

#### 7.4 RIP协议 ⭐

**RIP（Routing Information Protocol）**：基于距离向量算法的内部网关协议

```
RIP关键参数：
- 最大跳数：15跳（16跳为不可达）
- 更新周期：每30秒发送一次完整路由表
- 防环机制：水平分割、毒性逆转、触发更新、 hold-down timers
```

> **⭐选择题高频考点**：RIP使用UDP端口520；最大跳数为15；每30秒更新一次。

#### 7.5 OSPF协议 ⭐

**OSPF（Open Shortest Path First）**：基于链路状态算法的内部网关协议

```
OSPF关键特性：
- 使用Dijkstra算法计算最短路径树
- 按区域（Area）组织：Area 0为核心区域（骨干区域）
- 邻居发现：Hello协议（UDP，非IP，直接封装在OSPF报文中）
- 收敛速度快，无环路
- 度量值：基于链路带宽（cost = 参考带宽/链路带宽）
```

#### 7.6 BGP协议 ⭐

**BGP（Border Gateway Protocol）**：外部网关协议，用于自治系统（AS）之间的路由

```
BGP关键特性：
- 属于路径向量协议（Path Vector）
- 使用TCP连接（端口179）
- 不追求最短路径，而追求"可达且无环路"
- 路由策略：基于策略的路由选择（可考虑AS路径、MED、Local Preference等）
- 4种BGP报文：OPEN、UPDATE、KEEPALIVE、NOTIFICATION
```

> **⭐选择题高频考点**：BGP属于**路径向量路由协议**，使用TCP而非UDP；它是互联网中唯一使用的**外部网关协议**。

### 八、路由器与互联网互连设备 🌟

| 设备 | 工作层次 | 功能 | 是否隔离广播域 |
|------|---------|------|--------------|
| 中继器/集线器 | 物理层 | 信号放大、比特转发 | ❌ 否 |
| 网桥/交换机 | 数据链路层 | MAC地址转发、帧转发 | ❌ 否 |
| 路由器 | 网络层 | IP转发、路由选择、分片重组 | ✅ 是 |
| 网关 | 传输层及以上 | 协议转换 | ✅ 是 |

### 九、NAT与防火墙

**NAT的局限性**：
- 端到端原则被破坏，某些应用层协议需要ALG
- 影响网络监控和安全审计
- 影响多对一映射时的连接管理

**防火墙类型**：
| 类型 | 工作层次 | 能力 |
|------|---------|------|
| 数据包过滤防火墙 | 网络层/传输层 | 基于IP和端口过滤 |
| 状态检测防火墙 | 网络层/传输层 | 维护连接状态表 |
| 应用层网关 | 应用层 | 深度包检测、应用协议理解 |

### 十、虚拟专用网（VPN）与隧道技术 🌟

**隧道技术（Tunneling）**：将一个协议报文封装在另一个协议报文中传输

```
隧道帧格式：
外层以太网帧
├── 外层IP头（隧道端点地址）
│   ├── 外层传输层头（可选）
│   │   ├── 内层IP头（原始目标地址）
│   │   │   ├── 内层传输层头
│   │   │   └── 应用数据
│   │   └── 原始IP报文
│   └── 原始IP报文
└── 外层FCS
```

**主要隧道协议**：
- **IPSec**：网络层安全协议，提供认证和加密
- **GRE**：通用路由封装，简单的隧道协议
- **SSL/TLS隧道**：传输层安全协议隧道

## ⚖️易混淆概念对比

### 转发与路由

| 对比项 | 转发（Forwarding） | 路由（Routing） |
|--------|-------------------|----------------|
| **作用范围** | 局部：路由器内部 | 全局：整个网络 |
| **操作主体** | 路由器 | 路由协议（OSPF/BGP/RIP等） |
| **触发条件** | 每个到达的分组 | 网络拓扑变化或定时更新 |
| **对应表格** | 转发表（转发表） | 路由表（路由表） |
| **速度** | 硬件转发，毫秒级 | 路由计算，秒级 |
| **关联文档** | → | → |

### 距离向量 vs 链路状态

| 对比项 | 距离向量（RIP） | 链路状态（OSPF） |
|--------|---------------|-----------------|
| **算法基础** | Bellman-Ford | Dijkstra |
| **信息交换** | 仅与邻居交换 | 泛洪给全网 |
| **收敛速度** | 慢（计数到无穷大） | 快 |
| **计算位置** | 分布式 | 分布式但每个节点独立计算 |
| **资源消耗** | 低（仅邻居通信） | 高（泛洪+LSDB） |
| **适用规模** | 小型网络 | 大型网络 |

### NAT与代理服务器

| 对比项 | NAT | 代理服务器（Proxy） |
|--------|-----|-------------------|
| **工作层次** | 网络层/传输层 | 应用层 |
| **对应用透明性** | 透明，应用无感知 | 应用需配置或感知 |
| **修改范围** | 仅IP地址/端口 | 可修改应用层内容 |
| **性能** | 高（硬件转发） | 相对较低（应用层处理） |
| **功能** | 地址转换 | 缓存、过滤、日志等 |

## ⚠️考试高频坑点

### 坑点1：子网掩码的计算

> 【考试考法】给出一个IP和掩码，要求计算网络地址、广播地址、主机范围
> 
> ⚠️ 常见错误：直接看最后一个八位组的点分十进制值，忘记做AND运算
> 
> ✅ 正确方法：务必将IP和掩码都转为二进制，逐位AND

### 坑点2：CIDR聚合

> 【考试考法】给定4个子网，求聚合后的网络地址和前缀长度
> 
> ⚠️ 常见错误：盲目地找共同前缀，忽略了子网必须连续
> 
> ✅ 正确方法：写出二进制，找最长共同前缀，验证聚合后的地址范围确实覆盖所有子网

### 坑点3：ICMP与IP的关系

> 【考试考法】"ICMP是传输层协议吗？"
> 
> ⚠️ 常见错误：误认为ICMP是传输层协议（因为它有类型/代码字段，类似传输层头部）
> 
> ✅ 正确理解：ICMP是**网络层协议**，封装在IP数据报中（IP协议号=1）

### 坑点4：最长前缀匹配

> 【考试考法】转发表中有 `/24` 和 `/26` 两条匹配项，选哪个？
> 
> ⚠️ 常见错误：选第一条匹配或选最短前缀
> 
> ✅ 正确理解：**最长前缀匹配（掩码最长）**优先，`/26` > `/24`

### 坑点5：NAT与端到端原则

> 【考试考法】NAT对端到端通信的影响
> 
> ⚠️ 常见错误：认为NAT完全透明，不影响上层协议
> 
> ✅ 正确理解：NAT破坏了端到端原则，影响需要嵌入IP地址的应用层协议（如FTP、SIP）

### 坑点6：RIP的最大跳数

> 【考试考法】RIP最大跳数是多少？16跳表示什么？
> 
> ⚠️ 常见错误：记成32跳或64跳
> 
> ✅ 正确记忆：**最大15跳，16跳为不可达**（16 = ∞）
