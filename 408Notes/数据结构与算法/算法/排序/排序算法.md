## 一、插入排序（Insertion Sort）

插入排序的基本思想是：将待排序元素逐个插入到已经排好序的子序列中，最终使整个序列有序。插入排序可分为直接插入排序、折半插入排序和希尔排序三种。

---

### 1.1 直接插入排序（Straight Insertion Sort）

#### 📍 算法定位

直接插入排序是最基础的排序算法，适用于**小规模数据**或**基本有序**的序列。它是稳定的排序算法，时间复杂度在最好情况下（已有序）为 $O(n)$，最坏情况下为 $O(n^2)$。

#### 📝 算法详解

**核心思想**：

将序列 `r[1..n]` 看作两部分：`r[1..i-1]` 是已排序区间，`r[i..n]` 是未排序区间。从 `i = 2` 开始，将 `r[i]` 与 `r[1..i-1]` 中的元素从后向前逐个比较，找到 `r[i]` 应插入的位置，并将该位置之后的元素统一后移，最后将 `r[i]` 插入。

为简化代码，引入**哨兵** `r[0]`，即 `r[0]` 不存数据元素，仅用作"监控位"和临时存储区。当比较到达 `r[0]` 时，说明已到达有序区的左边界，无需继续比较。

**算法步骤**：

1. 将 `r[1]` 视为已排序区间（单个元素天然有序）。
2. 从 `i = 2` 到 `n`，依次将 `r[i]` 插入有序区。
3. 将 `r[i]` 暂存到 `r[0]`（哨兵），即 `r[0] = r[i]`。
4. 从 `j = i - 1` 开始，从后向前扫描有序区。
5. 若 `r[j].key > r[0].key`，则将 `r[j]` 后移至 `r[j+1]`。
6. 若 `r[j].key ≤ r[0].key` 或 `j = 0`，停止扫描，将 `r[0]` 插入 `r[j+1]`。
7. 重复步骤 2~6，直到 `i > n`。

#### C 代码实现

```c
#include <stdio.h>
#include <stdlib.h>

#define MAXSIZE 10000  /* 最大记录数 */

/* 记录类型定义 */
typedef int KeyType;  /* 关键字类型 */
typedef int InfoType; /* 其他信息类型 */

typedef struct {
    KeyType key;      /* 关键字项 */
    InfoType info;    /* 其他数据项 */
} RedType;

/* 顺序表（静态存储结构，r[0] 为哨兵） */
typedef struct {
    RedType r[MAXSIZE + 1];  /* 存储数组，r[0] 为哨兵 */
    int length;              /* 顺序表长度 */
} SqList;

/**
 * 直接插入排序（Straight Insertion Sort）
 * 采用哨兵 r[0]，将待插入元素暂存于 r[0]
 * 时间复杂度：最好 O(n)，最坏 O(n²)，平均 O(n²)
 * 空间复杂度：O(1)
 * 稳定性：稳定
 *
 * @param L 待排序的顺序表（r[1..length] 为有效数据）
 */
void InsertSort(SqList *L) {
    int i, j;

    for (i = 2; i <= L->length; ++i) {
        /* 若 r[i] 的关键字不小于有序区最后一个元素，则无需插入 */
        if (L->r[i].key < L->r[i - 1].key) {
            /* 将 r[i] 暂存到哨兵 r[0] */
            L->r[0] = L->r[i];

            /* 将 r[i] 插入到有序区 r[1..i-1] 中的正确位置 */
            /* r[0] 既是哨兵（监视循环终止），也是临时存储 */
            j = i - 1;
            while (L->r[0].key < L->r[j].key) {
                L->r[j + 1] = L->r[j];  /* 记录后移 */
                --j;
            }
            /* j 停止处即为插入位置的前一个元素，插入 r[j+1] */
            L->r[j + 1] = L->r[0];
        }
        /* 若 r[i].key >= r[i-1].key，r[i] 已在正确位置，无需操作 */
    }
}

/**
 * 工具函数：输出顺序表各元素的关键字
 */
void PrintList(SqList *L) {
    int i;
    printf("L.r[");
    for (i = 1; i <= L->length; ++i) {
        printf("%d", L->r[i].key);
        if (i < L->length) printf(", ");
    }
    printf("] len=%d\n", L->length);
}

/* 测试 */
int main() {
    SqList L;
    int data[] = {0, 49, 38, 65, 97, 76, 13, 27, 50}; /* r[0] 留作哨兵 */
    L.length = 8;
    for (int i = 0; i <= 8; ++i) {
        L.r[i].key = data[i];
        L.r[i].info = i;
    }

    printf("排序前: ");
    PrintList(&L);

    InsertSort(&L);

    printf("排序后: ");
    PrintList(&L);

    return 0;
}
```

**哨兵 `r[0]` 的双重作用**：

| 作用 | 说明 |
|------|------|
| 临时的数据缓冲区 | 保存待插入元素 `r[i]`，避免在移动过程中丢失 |
| 边界监视哨 | `while` 循环比较 `r[0].key < r[j].key`，当 `j` 递减到 0 时，`r[0].key` 即为自身保存的值，不会触发继续比较，自然终止循环，省去额外边界检查 |

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **时间复杂度——最好情况** | $O(n)$ | 序列已有序，每轮只需比较一次（`r[i] ≥ r[i-1]`），比较次数 $C_{min} = n-1$，移动次数 $M_{min} = 0$ |
| **时间复杂度——最坏情况** | $O(n^2)$ | 序列逆序，第 `i` 轮需比较 `i` 次、移动 `i` 次，总比较次数 $C_{max} = \sum_{i=2}^{n} i = \frac{(n+2)(n-1)}{2}$，总移动次数 $M_{max} = \sum_{i=2}^{n} (i+1) = \frac{(n+4)(n-1)}{2}$ |
| **时间复杂度——平均情况** | $O(n^2)$ | 假设插入位置等概率出现在有序区的各个位置，平均比较和移动次数约为最坏情况的一半，仍为 $O(n^2)$ |
| **空间复杂度** | $O(1)$ | 仅需哨兵 `r[0]` 作为临时存储，不随输入规模变化 |
| **稳定性** | ✅ 稳定 | 仅在 `r[j].key > r[0].key` 时移动元素，相等时不会交换顺序 |

### 1.2 折半插入排序（Binary Insertion Sort）

#### 📝 算法详解

在直接插入排序中，寻找插入位置的过程是从后向前顺序扫描。既然有序区 `r[low..high]` 已经有序，可以利用**二分查找（折半查找）**来确定插入位置，减少比较次数，但元素移动次数不变。

**算法步骤**：

1. 在有序区 `r[1..i-1]` 中，用折半查找确定 `r[i]` 的插入位置 `low`。
2. 将 `r[low..i-1]` 全部后移一位到 `r[low+1..i]`。
3. 将 `r[i]` 存入 `r[low]`。

```c
/**
 * 折半插入排序（Binary Insertion Sort）
 * 用折半查找确定插入位置，减少比较次数，但不减少移动次数
 * 时间复杂度：比较 O(nlogn)，移动 O(n²)，整体仍为 O(n²)
 * 空间复杂度：O(1)
 * 稳定性：稳定
 *
 * @param L 待排序的顺序表
 */
void BinaryInsertionSort(SqList *L) {
    int i, j, low, high, mid;

    for (i = 2; i <= L->length; ++i) {
        /* 将 r[i] 暂存到 r[0] */
        L->r[0] = L->r[i];

        /* 折半查找：在有序区 r[1..i-1] 中查找 r[0] 的插入位置 */
        low = 1;
        high = i - 1;
        while (low <= high) {
            mid = (low + high) / 2;
            if (L->r[mid].key > L->r[0].key) {
                high = mid - 1;  /* 插入点在左半区 */
            } else {
                low = mid + 1;   /* 插入点在右半区 */
            }
        }
        /* 循环结束时，low 即为插入位置 */

        /* 将 r[low..i-1] 全部后移一位 */
        for (j = i - 1; j >= low; --j) {
            L->r[j + 1] = L->r[j];
        }

        /* 插入 r[i] 到 r[low] */
        L->r[low] = L->r[0];
    }
}
```

**复杂度对比**：

| 比较项 | 直接插入排序 | 折半插入排序 |
|--------|-------------|-------------|
| 比较次数 | $O(n^2)$ | $O(n \log n)$（折半查找减少比较） |
| 移动次数 | $O(n^2)$ | $O(n^2)$（移动次数不变） |
| 整体时间复杂度 | $O(n^2)$ | $O(n^2)$ |
| 空间复杂度 | $O(1)$ | $O(1)$ |
| 稳定性 | 稳定 | 稳定 |

> **注意**：折半插入排序虽然减少了比较次数，但由于元素移动次数仍为 $O(n^2)$，整体时间复杂度并未降低。仅当比较操作代价远大于移动操作代价时，折半插入排序才有意义。

### 1.3 希尔排序（Shell Sort）⭐

#### 📍 算法定位

希尔排序是直接插入排序的改进版本，通过**缩小增量**的方式，先对"间隔较远"的元素进行比较和插入，使序列**基本有序**，最后再进行**直接插入排序**。希尔排序是**不稳定**的排序算法。

#### 📝 算法详解

**核心思想——分组插入**：

将相距某个"增量" `d_k` 的记录组成一个子序列，在这个子序列中分别进行直接插入排序。随着增量逐渐减小，子序列包含的记录越来越多，当增量减至 1 时，整个序列恰被分成一组，算法便终止。

**增量序列的选择**（Shell 原始增量）：

$$d_1 = \lfloor n/2 \rfloor, \quad d_{k} = \lfloor d_{k-1} / 2 \rfloor, \quad \text{直到 } d_m = 1$$

即：$n/2, \lfloor n/2 \rfloor / 2, \ldots, 4, 2, 1$

希尔排序的不稳定性来源于**跨组比较**。在增量 $d_k > 1$ 时，相同关键字的记录可能被分到不同组，在不同组中被多次直接插入排序，相对顺序可能改变。

#### C 代码实现

```c
/**
 * 希尔排序（Shell Sort）
 * 缩小增量策略：d1 = n/2, dk = floor(d(k-1)/2)，直至 dk = 1
 * 时间复杂度：依赖于增量序列，Shell 增量为 O(n^1.3) ~ O(n^1.5) 之间
 * 空间复杂度：O(1)
 * 稳定性：不稳定 ⚠️
 *
 * @param L 待排序的顺序表
 */
void ShellInsert(SqList *L, int dk) {
    /* 对顺序表 L 作一趟希尔插入排序，增量为 dk */
    int i, j;

    /* 从第 dk+1 个记录开始，每 dk 个记录为一组进行直接插入排序 */
    for (i = dk + 1; i <= L->length; ++i) {
        /* 若 r[i] 的关键字小于同组前一个记录 r[i-dk] 的关键字，需插入 */
        if (L->r[i].key < L->r[i - dk].key) {
            /* 将 r[i] 暂存到 r[0] */
            L->r[0] = L->r[i];

            /* 在组内进行直接插入，步长为 dk */
            j = i - dk;
            while (j > 0 && L->r[0].key < L->r[j].key) {
                L->r[j + dk] = L->r[j];  /* 记录后移 dk 步 */
                j -= dk;
            }
            /* 将 r[0] 插入到正确位置 */
            L->r[j + dk] = L->r[0];
        }
    }
}

/**
 * 希尔排序主函数
 * 按增量序列 dk[1..t] 依次执行希尔插入排序
 *
 * @param L 待排序的顺序表
 * @param dt 增量序列个数
 * @param dt[] 增量数组，dt[t-1] 必须为 1
 */
void ShellSort(SqList *L, int dt[], int t) {
    /* 按增量序列依次执行各趟希尔插入排序 */
    for (int k = 0; k < t; ++k) {
        ShellInsert(L, dt[k]);
    }
}

/**
 * 测试示例
 */
int main2() {
    SqList L;
    int data[] = {49, 38, 65, 97, 76, 13, 27, 49, 55, 4};
    L.length = 10;
    for (int i = 0; i < 10; ++i) {
        L.r[i + 1].key = data[i];
        L.r[i + 1].info = i + 1;
    }

    /* Shell 原始增量序列 */
    int dt[] = {5, 3, 1};
    int t = 3;

    printf("排序前: ");
    PrintList(&L);

    ShellSort(&L, dt, t);

    printf("排序后: ");
    PrintList(&L);

    return 0;
}
```

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **时间复杂度** | 依赖于增量序列 | Shell 原始增量 $O(n^{1.3})$ 到 $O(n^{1.5})$ 之间；Hibbard 增量 $O(n^{1.5})$；Sedgewick 增量 $O(n^{1.3})$ |
| **空间复杂度** | $O(1)$ | 仅需哨兵 `r[0]` 作为临时存储 |
| **稳定性** | ❌ 不稳定 | 相同关键字的记录在不同增量趟中可能被分到不同组，相对顺序可能改变 |

**不稳定性举例**：序列 `[5a, 5b, 3, ...]`（`5a` 和 `5b` 关键字相同但用 a/b 区分），当增量为 2 时，`5a` 和 `3` 同组，`5b` 单独成组。在第一趟增量 2 排序中，`5b` 可能排到 `5a` 之前，导致相对顺序改变。

## 二、交换排序（Exchange Sort）

交换排序的核心思想是：通过**交换**逆序元素的位置来消除逆序对，使序列逐渐有序。

---

### 2.1 冒泡排序（Bubble Sort）

#### 📍 算法定位

冒泡排序是最直观的排序算法之一。它的优化版本在序列**基本有序**时表现优异，最好情况时间复杂度为 $O(n)$。

#### 📝 算法详解

**基本思想**：

逐趟将最大（或最小）的元素"冒泡"到序列末尾。每一趟从前往后扫描，依次比较相邻两个元素，若逆序则交换。经过 `i` 趟后，末尾 `i` 个元素已有序。

**优化版本——提前终止**：

设置布尔标志 `flag`。若某一趟扫描中**没有发生任何交换**，说明序列已有序，立即终止算法。这一优化使得最好情况（已有序）的时间复杂度降至 $O(n)$。

#### C 代码实现

```c
/**
 * 冒泡排序（Bubble Sort）——优化版
 * 通过 flag 标志判断本趟是否发生交换，若无交换则提前终止
 * 时间复杂度：最好 O(n)，最坏 O(n²)，平均 O(n²)
 * 空间复杂度：O(1)
 * 稳定性：稳定
 *
 * @param L 待排序的顺序表
 */
void BubbleSort(SqList *L) {
    int i, j, n = L->length;
    int flag;  /* 交换标志 */
    RedType temp;  /* 交换临时变量 */

    for (i = 0; i < n - 1; ++i) {
        /* 每趟开始前，flag 置为 0，表示未发生交换 */
        flag = 0;

        /* 从前往后扫描，将最大值"冒泡"到末尾 */
        /* 每趟最多比较 n-1-i 次，因为末尾 i 个元素已有序 */
        for (j = 1; j <= n - 1 - i; ++j) {
            if (L->r[j].key > L->r[j + 1].key) {
                /* 交换 r[j] 和 r[j+1] */
                temp = L->r[j];
                L->r[j] = L->r[j + 1];
                L->r[j + 1] = temp;
                flag = 1;  /* 标记发生了交换 */
            }
        }

        /* 若本趟未发生任何交换，说明已有序，提前退出 */
        if (flag == 0) {
            break;
        }
    }
}

/**
 * 双向冒泡排序（Cocktail Shaker Sort）——鸡尾酒排序
 * 每趟从两个方向扫描：正向冒泡最大值到末尾，反向冒泡最小值到开头
 * 适用于"小元素集中在前端"的序列
 *
 * @param L 待排序的顺序表
 */
void CocktailBubbleSort(SqList *L) {
    int left = 1, right = L->length;
    int flag, lastSwap;
    RedType temp;

    while (left < right) {
        flag = 0;
        lastSwap = left;

        /* 正向扫描：将最大值冒泡到 right */
        for (int i = left; i < right; ++i) {
            if (L->r[i].key > L->r[i + 1].key) {
                temp = L->r[i];
                L->r[i] = L->r[i + 1];
                L->r[i + 1] = temp;
                flag = 1;
                lastSwap = i + 1;
            }
        }
        right = lastSwap;  /* 下一次扫描范围缩小 */

        if (flag == 0) break;  /* 已有序 */

        flag = 0;
        lastSwap = right;

        /* 反向扫描：将最小值冒泡到 left */
        for (int i = right; i > left; --i) {
            if (L->r[i].key < L->r[i - 1].key) {
                temp = L->r[i];
                L->r[i] = L->r[i - 1];
                L->r[i - 1] = temp;
                flag = 1;
                lastSwap = i - 1;
            }
        }
        left = lastSwap;  /* 下一次扫描范围缩小 */
    }
}
```

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **最好情况** | $O(n)$ | 序列已有序，仅需一趟扫描，`flag` 为 0 即终止，比较 $n-1$ 次 |
| **最坏情况** | $O(n^2)$ | 序列逆序，需 $n-1$ 趟，每趟比较次数递减 |
| **平均情况** | $O(n^2)$ |  |
| **空间复杂度** | $O(1)$ | 仅需一个临时交换变量 |
| **稳定性** | ✅ 稳定 | 仅在严格大于时交换，相等元素不交换 |

### 2.2 快速排序（Quick Sort）⭐🔥🔥

#### 📍 算法定位

快速排序是**所有内部排序算法中平均性能最好**的算法。它采用**分治法**（Divide and Conquer），通过 Partition 操作将序列分为两部分，再递归排序。是考研高频重点。

#### 📝 算法详解

**核心思想——分治法**：

1. **分解（Partition）**：从待排序序列中选取一个元素作为**基准（pivot）**，重新排列序列，使得所有比基准小的元素排在其前面，所有比基准大的元素排在其后面。基准元素最终处于其最终位置（称为"枢轴位置"）。
2. **递归求解**：对基准左右两个子序列分别递归执行快速排序。
3. **基线条件**：当子序列长度为 0 或 1 时，递归终止。

**Partition 过程详解（Hoare 双指针法 / 严蔚敏交换法）**：

以 `r[low]` 为基准值（可配合三数取中优化），设置两个指针 `low` 和 `high` 分别从两端向中间扫描：

- `high` 从右向左扫描，找到第一个 `≤` 基准值的元素，将其放到 `low` 位置
- `low` 从左向右扫描，找到第一个 `≥` 基准值的元素，将其放到 `high` 位置
- 交替进行，直到 `low = high`，该位置即为基准的最终位置

#### C 代码实现

```c
/**
 * 三数取中法（Three-way Median）
 * 在 r[low..high] 中选取 low、mid、high 三个位置的中值作为基准
 * 目的：避免最坏情况（已有序/逆序序列选到最小/最大值作为基准）
 *
 * @param L 顺序表
 * @param low 子表左边界
 * @param high 子表右边界
 * @return 基准值
 */
KeyType Pivot3(SqList *L, int low, int high) {
    int mid = (low + high) / 2;  /* 中间位置 */

    /* 将 r[low]、r[mid]、r[high] 三个关键字的中值放到 r[low] */
    /* 若 r[low] 已经是中值，直接返回 */
    /* 否则交换到 r[low] 位置 */

    if (L->r[low].key > L->r[mid].key) {
        /* 交换 r[low] 和 r[mid] */
        RedType temp = L->r[low];
        L->r[low] = L->r[mid];
        L->r[mid] = temp;
    }
    /* 现在 r[low] <= r[mid] */

    if (L->r[low].key > L->r[high].key) {
        /* 交换 r[low] 和 r[high] */
        RedType temp = L->r[low];
        L->r[low] = L->r[high];
        L->r[high] = temp;
    }
    /* 现在 r[low] <= r[high]，且 r[low] 是三者之一 */

    if (L->r[mid].key > L->r[high].key) {
        /* 交换 r[mid] 和 r[high] */
        RedType temp = L->r[mid];
        L->r[mid] = L->r[high];
        L->r[high] = temp;
    }
    /* 现在 r[low] <= r[mid] <= r[high]，中值为 r[mid] */

    /* 将中值 r[mid] 交换到 r[low] 作为基准位置 */
    RedType temp = L->r[mid];
    L->r[mid] = L->r[low];
    L->r[low] = temp;

    return L->r[low].key;
}

/**
 * 交换排序 Partition 函数
 * 以 r[low] 为基准值，将小于基准的元素放左边，大于基准的放右边
 * 返回基准的最终位置
 *
 * @param L 顺序表
 * @param low 子表左边界
 * @param high 子表右边界
 * @return 基准的最终下标
 */
int Partition(SqList *L, int low, int high) {
    /* 可选：使用三数取中优化基准选择 */
    /* Pivot3(L, low, high); */  /* 取消注释启用 */

    KeyType pivotKey = L->r[low].key;  /* 以 r[low] 为基准值 */

    /* 使用 r[0] 作为哨兵（临时存储基准值） */
    L->r[0] = L->r[low];

    while (low < high) {
        /* high 从右向左扫描，找到第一个 ≤ 基准值的元素 */
        while (low < high && L->r[high].key >= pivotKey) {
            --high;
        }
        /* 将 r[high] 放到 low 位置 */
        L->r[low] = L->r[high];

        /* low 从左向右扫描，找到第一个 ≥ 基准值的元素 */
        while (low < high && L->r[low].key <= pivotKey) {
            ++low;
        }
        /* 将 r[low] 放到 high 位置 */
        L->r[high] = L->r[low];
    }

    /* 此时 low == high，该位置即为基准的最终位置 */
    L->r[low] = L->r[0];

    return low;
}

/**
 * 快速排序——递归主函数
 * 时间复杂度：平均 O(nlogn)，最坏 O(n²)
 * 空间复杂度：递归栈深度平均 logn，最坏 n
 * 稳定性：不稳定
 *
 * @param L 顺序表
 * @param low 子表左边界
 * @param high 子表右边界
 */
void QSort(SqList *L, int low, int high) {
    /* 递归基线：子表长度为 1 或 0 时终止 */
    if (low < high) {
        /* Partition 将子表 r[low..high] 划分为两部分 */
        /* r[low..pivot-1] 所有元素 ≤ 基准，r[pivot+1..high] 所有元素 ≥ 基准 */
        int pivot = Partition(L, low, high);

        /* 递归排序左子表 */
        QSort(L, low, pivot - 1);

        /* 递归排序右子表 */
        QSort(L, pivot + 1, high);
    }
}

/**
 * 快速排序主入口
 *
 * @param L 待排序的顺序表
 */
void QuickSort(SqList *L) {
    QSort(L, 1, L->length);
}
```

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **最好情况** | $O(n \log n)$ | 每次 Partition 恰好将序列等分为两半，递归树深度为 $\log_2 n$，每层扫描 $n$ 次 |
| **最坏情况** | $O(n^2)$ | 每次 Partition 将序列分为 0 和 $n-1$（序列已有序且以首元素为基准），递归树深度为 $n$ |
| **平均情况** | $O(n \log n)$ | 数学期望为 $2n \ln n \approx 1.39 n \log_2 n$ |
| **空间复杂度** | 平均 $O(\log n)$，最坏 $O(n)$ | 递归栈空间，平均递归深度 $\approx \log_2 n$ |
| **稳定性** | ❌ 不稳定 | Partition 过程中，基准元素可能与后方相同关键字元素交换 |

**最坏情况触发条件及规避**：

| 触发条件 | 规避策略 |
|----------|----------|
| 序列已有序，以首/尾元素为基准 | 三数取中法、随机选择基准 |
| 序列逆序，以首元素为基准 | 同三数取中/随机基准 |
| 所有元素关键字相同 | 三路划分（Dutch National Flag） |

## 三、选择排序（Selection Sort）

选择排序的核心思想是：每一趟在无序区中**选出**关键字最小（或最大）的元素，将其放到有序区的末尾。

---

### 3.1 简单选择排序（Simple Selection Sort）

#### 📍 算法定位

简单选择排序的逻辑非常直观：每一趟直接选出最小元素。它的突出特点是：**无论输入序列初始状态如何，比较次数固定为 $O(n^2)$**。

#### 📝 算法详解

**算法步骤**：

1. 从 `r[1..n]` 中找出关键字最小的元素，与 `r[1]` 交换。
2. 从 `r[2..n]` 中找出关键字最小的元素，与 `r[2]` 交换。
3. 依此类推，第 `i` 趟从 `r[i..n]` 中找出最小元素与 `r[i]` 交换，共执行 `n-1` 趟。

#### C 代码实现

```c
/**
 * 简单选择排序（Simple Selection Sort）
 * 每趟在无序区 r[i..n] 中选出最小元素，与 r[i] 交换
 * 时间复杂度：O(n²)，与初始状态无关
 * 空间复杂度：O(1)
 * 稳定性：不稳定 ⚠️
 *
 * @param L 待排序的顺序表
 */
void SelectSort(SqList *L) {
    int i, j, min;
    RedType temp;

    for (i = 1; i < L->length; ++i) {
        /* 假设 r[i] 是无序区中最小的 */
        min = i;

        /* 在 r[i+1..n] 中查找最小元素 */
        for (j = i + 1; j <= L->length; ++j) {
            if (L->r[j].key < L->r[min].key) {
                min = j;  /* 更新最小元素位置 */
            }
        }

        /* 若最小元素不是 r[i]，则交换 */
        if (min != i) {
            temp = L->r[i];
            L->r[i] = L->r[min];
            L->r[min] = temp;
        }
    }
}
```

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **时间复杂度** | $O(n^2)$ | 与初始状态无关。比较次数固定为 $\sum_{i=1}^{n-1}(n-i) = \frac{n(n-1)}{2}$，与序列初始排列无关 ⭐ |
| **最好情况移动次数** | 0 | 序列已有序且恰好每趟最小元素就是当前元素（较少见） |
| **最坏情况移动次数** | $3(n-1)$ | 每趟都需要交换，每次交换 3 次移动 |
| **平均移动次数** | $O(n)$ | 平均每趟有约 1/2 概率需要交换 |
| **空间复杂度** | $O(1)$ | 仅需一个临时交换变量 |
| **稳定性** | ❌ 不稳定 | 交换操作可能改变相同关键字的相对顺序 |

**不稳定性举例**：序列 `[5a, 5b, 2]`。第一趟最小元素是 `2`，与 `5a` 交换得到 `[2, 5b, 5a]`，`5a` 和 `5b` 的相对顺序颠倒了。

### 3.2 堆排序（Heap Sort）⭐🔥🔥

#### 📍 算法定位

堆排序利用**完全二叉树**的堆（Heap）结构，能在任何情况下保证 $O(n \log n)$ 的时间复杂度。它是**不稳定的**排序算法。

#### 📝 算法详解

**核心概念**：

- **大根堆（Max Heap）**：对于完全二叉树中任一非叶子节点，其关键字均不小于其左右孩子的关键字。即 `r[i].key ≥ r[2i].key` 且 `r[i].key ≥ r[2i+1].key`。
- **小根堆（Min Heap）**：对于完全完全二叉树中任一非叶子节点，其关键字均不大于其左右孩子的关键字。

堆排序使用**大根堆**。排序过程：

1. **建初始大根堆**（`BuildMaxHeap`）：从最后一个非叶子节点 `⌊n/2⌋` 开始，自下而上对每个节点执行 `SiftDown` 筛选，使整个序列构成大根堆。
2. **排序循环**（`HeapSort`）：将堆顶（最大元素）与堆底元素交换，堆大小减 1，再对新的堆顶执行 `SiftDown` 重新调整为大根堆。重复 `n-1` 次。

**SiftDown（筛选/下沉）过程**：

从节点 `s` 出发，将其与左右孩子中关键字较大者比较。若大于等于较大孩子，则已是堆，无需调整；否则交换 `s` 与较大孩子的位置，继续向下调整，直到 `s` 满足堆性质或到达叶子节点。

#### C 代码实现

```c
/**
 * SiftDown（筛选/下沉）函数
 * 将 r[s] 的关键字沿关键字较大的孩子节点向下调整
 * 使得 r[s..high] 成为一个大根堆
 *
 * @param L 顺序表
 * @param s 需要调整的非叶子节点下标
 * @param high 堆的右边界
 */
void SiftDown(SqList *L, int s, int high) {
    KeyType tempKey = L->r[s].key;  /* 暂存 r[s] 的关键字 */
    InfoType tempInfo = L->r[s].info;  /* 暂存 r[s] 的其他信息 */

    int j;

    /* 从左孩子开始（2*s）向下调整 */
    for (j = 2 * s; j <= high; j *= 2) {
        /* j 指向左右孩子中关键字较大的那个 */
        if (j < high && L->r[j].key < L->r[j + 1].key) {
            ++j;  /* 右孩子较大，j 指向右孩子 */
        }

        /* 若 r[s]（即 tempKey）已经不小于较大孩子，调整结束 */
        if (tempKey >= L->r[j].key) {
            break;
        }

        /* 否则将较大孩子上移到 s 的位置 */
        L->r[s].key = L->r[j].key;
        L->r[s].info = L->r[j].info;
        s = j;  /* s 下移到孩子位置，继续向下调整 */
    }

    /* 将 tempKey 放到最终位置 */
    L->r[s].key = tempKey;
    L->r[s].info = tempInfo;
}

/**
 * 建初始大根堆（Build Max Heap）
 * 自下而上从最后一个非叶子节点 ⌊n/2⌋ 开始，对每个节点执行 SiftDown
 * 时间复杂度：O(n)
 *
 * @param L 顺序表
 * @param n 堆大小
 */
void BuildMaxHeap(SqList *L, int n) {
    /* ⌊n/2⌋ 是最后一个非叶子节点 */
    for (int i = n / 2; i > 0; --i) {
        SiftDown(L, i, n);
    }
}

/**
 * 堆排序（Heap Sort）
 * 1. 建初始大根堆
 * 2. 反复将堆顶与堆底交换，再对新的堆顶筛选
 * 时间复杂度：O(nlogn) 所有情况
 * 空间复杂度：O(1)
 * 稳定性：不稳定
 *
 * @param L 待排序的顺序表
 */
void HeapSort(SqList *L) {
    int n = L->length;

    /* Step 1: 建初始大根堆 */
    BuildMaxHeap(L, n);

    /* Step 2: 逐个将最大元素（堆顶）放到堆底 */
    for (int i = n; i > 1; --i) {
        /* 将堆顶 r[1]（最大值）与堆底 r[i] 交换 */
        RedType temp = L->r[1];
        L->r[1] = L->r[i];
        L->r[i] = temp;

        /* 对新的堆顶 r[1] 执行 SiftDown，调整堆大小减为 i-1 */
        SiftDown(L, 1, i - 1);
    }
}
```

**堆排序的优缺点**：

| 比较次数比快速排序少 | 缓存不友好，随机访问模式导致命中率低 |

## 四、归并排序（Merge Sort）

归并排序基于**合并（Merge）操作**，将两个有序子序列合并为一个有序序列。它是**稳定的**排序算法，且能在所有情况下保证 $O(n \log n)$ 时间复杂度。

---

### 4.1 两路归并 Merge 函数⭐🔥

#### 📝 算法详解

**Merge 过程**：

设有两个相邻的有序子序列 `r[low..mid]` 和 `r[mid+1..high]`，使用一个辅助数组 `T`，设置两个指针分别指向两个子序列的起始位置，每次比较两个指针所指元素，将较小者存入 `T`，直到其中一个子序列遍历完毕，再将另一子序列剩余部分直接复制到 `T`。最后将 `T` 中的结果复制回原数组。

#### C 代码实现

```c
/**
 * 辅助数组（用于归并过程）
 */
RedType *T;  /* 全局辅助数组，空间为 MAXSIZE */

/**
 * 两路归并：将 r[low..mid] 和 r[mid+1..high] 合并为有序序列存入 T[low..high]
 * 时间复杂度：O(high - low + 1)
 * 空间复杂度：O(high - low + 1)（T 数组）
 * 稳定性：稳定
 *
 * @param L 顺序表
 * @param low 左子表起始位置
 * @param mid 左子表结束位置（右子表起始为 mid+1）
 * @param high 右子表结束位置
 */
void Merge(SqList *L, int low, int mid, int high) {
    /* 将 r[low..high] 归并到 T[low..high] */

    int i = low;    /* 左子表指针 */
    int j = mid + 1;  /* 右子表指针 */
    int k = low;    /* 辅助数组指针 */

    /* 两路交替扫描，取较小者放入 T[k] */
    while (i <= mid && j <= high) {
        if (L->r[i].key <= L->r[j].key) {
            /* 取左子表元素（≤ 而非 < 保证稳定性） */
            T[k++] = L->r[i++];
        } else {
            T[k++] = L->r[j++];
        }
    }

    /* 将左子表剩余部分复制到 T */
    while (i <= mid) {
        T[k++] = L->r[i++];
    }

    /* 将右子表剩余部分复制到 T */
    while (j <= high) {
        T[k++] = L->r[j++];
    }

    /* 将 T[low..high] 复制回 L->r[low..high] */
    for (i = low; i <= high; ++i) {
        L->r[i] = T[i];
    }
}
```

---

### 4.2 递归版 MergeSort⭐🔥

#### 📝 算法详解

**自顶向下递归**：

1. 将序列从中间分成两个子序列。
2. 对两个子序列分别递归归并排序。
3. 当子序列长度为 1 时（递归基线），直接返回。
4. 将两个有序子序列合并。

```c
/**
 * 递归归并排序——分治函数
 *
 * @param L 顺序表
 * @param low 左边界
 * @param high 右边界
 */
void MSort(SqList *L, int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;

        /* 分解：递归排序左半部分 */
        MSort(L, low, mid);

        /* 分解：递归排序右半部分 */
        MSort(L, mid + 1, high);

        /* 合并：将两个有序子序列合并 */
        Merge(L, low, mid, high);
    }
}

/**
 * 归并排序主入口
 *
 * @param L 待排序的顺序表
 */
void MergeSort(SqList *L) {
    /* 分配辅助数组空间 */
    T = (RedType *)malloc((L->length + 1) * sizeof(RedType));
    if (T == NULL) {
        return;  /* 内存分配失败 */
    }

    MSort(L, 1, L->length);

    /* 释放辅助数组 */
    free(T);
    T = NULL;
}
```

### 4.3 非递归版 MergeSort

#### 📝 算法详解

**自底向上迭代**：

从长度为 1 的子序列开始，逐步扩大子序列长度（1→2→4→8→...），每次将相邻的两个子序列合并，直到所有元素合并为一个有序序列。

```c
/**
 * 非递归归并排序（Bottom-Up Merge Sort）
 * 从长度为 1 的子序列开始，逐步合并
 * 避免递归开销，适合对递归深度敏感的场合
 *
 * @param L 待排序的顺序表
 */
void MergeSortNonRecursive(SqList *L) {
    int length = 1;  /* 初始子序列长度为 1 */
    int n = L->length;

    /* 分配辅助数组 */
    T = (RedType *)malloc((n + 1) * sizeof(RedType));
    if (T == NULL) return;

    /* 逐步扩大子序列长度：1, 2, 4, 8, ... */
    while (length < n) {
        int i = 1;
        /* 两两合并子序列 */
        while (i <= n - 2 * length + 1) {
            /* 合并相邻的两个长度为 length 的子序列 */
            Merge(L, i, i + length - 1, i + 2 * length - 1);
            i += 2 * length;
        }
        /* 处理剩余部分：若最后只剩一个子序列未配对，与前一个合并 */
        if (i + length - 1 < n) {
            Merge(L, i, i + length - 1, n);
        }

        /* 子序列长度加倍 */
        length *= 2;
    }

    free(T);
    T = NULL;
}
```

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **时间复杂度——所有情况** | $O(n \log n)$ | 归并树深度 $\lceil \log_2 n \rceil$，每层合并 $O(n)$ |
| **空间复杂度** | $O(n)$ | 需要辅助数组 `T`，大小为 $n$；递归版额外 $O(\log n)$ 递归栈 |
| **稳定性** | ✅ 稳定 | `Merge` 中用 `<=` 取左子表元素，相等时不交换 |

**归并排序的优缺点**：

| 优点 | 缺点 |
|------|------|
| 时间复杂度在所有情况下均为 $O(n \log n)$ | 需要额外 $O(n)$ 空间 |
| 稳定排序 | 不适合数据量巨大的场合（空间开销大） |
| 外排序的基础算法 | 合并操作需要大量内存拷贝 |

## 五、基数排序（Radix Sort）

### 5.1 LSD 基数排序（Least Significant Digit First）

#### 📍 算法定位

基数排序是一种**非比较排序**算法，不基于元素之间的比较，而是通过"分配"和"收集"操作，按关键字的每一位进行排序。基数排序适用于**整数**或可转化为整数的关键字。

#### 📝 算法详解

**核心思想——最低位优先（LSD）**：

从最低位（个位）开始，依次对每一位进行桶分配。对每一位：
1. **分配（Distribute）**：将元素按当前位的值放入对应的桶（0~9）。
2. **收集（Collect）**：按桶的顺序将元素收集回原数组。
3. 重复上述过程到最高位。

LSD 基数排序是**稳定**的，因为对每一位的桶内排序必须是稳定的。

#### C 代码实现

```c
#include <math.h>

/* 关键字位数最大值 */
#define MAXD 10

/* 桶的数量（十进制基数） */
#define radix 10

/* 记录节点类型（基数排序专用） */
typedef struct {
    KeyType keys[MAXD];  /* 关键字数组，keys[0] 为最低位 */
    int next;            /* 链表中下一个节点的游标 */
} NodeType;

typedef struct {
    NodeType r[MAXSIZE];  /* 记录数组 */
    int keynum;           /* 关键字位数 */
    int length;           /* 记录数 */
} RadixList;

/**
 * 获取第 k 位关键字
 * 对于整数 x，第 k 位：(x / 10^k) % 10
 *
 * @param kp 关键字值
 * @param k 从低位往高的位数（0=最低位）
 * @return 第 k 位的数字
 */
int GetKey(KeyType kp, int k) {
    KeyType divisor = 1;
    for (int i = 0; i < k; ++i) {
        divisor *= 10;  /* 10^k */
    }
    return (kp / divisor) % 10;
}

/**
 * LSD 基数排序（Least Significant Digit First）
 * 从最低位到最高位，逐位分配+收集
 * 时间复杂度：O(d * (n + r))，其中 d 为位数，r 为基数
 * 空间复杂度：O(n + r)
 * 稳定性：稳定
 *
 * @param L 基数表
 */
void RadixSort(RadixList *L) {
    int k;
    int i, j, p;

    /* 分配数组：10 个桶的头指针 */
    int head[radix];
    /* 分配数组：10 个桶的尾指针 */
    int tail[radix];

    /* 从最低位（k=0）到最高位（k=keynum-1） */
    for (k = 0; k < L->keynum; ++k) {
        /* 初始化桶：head 和 tail 均置为 -1（空桶） */
        for (i = 0; i < radix; ++i) {
            head[i] = -1;
            tail[i] = -1;
        }

        /* 分配：将元素按第 k 位的值放入对应桶 */
        p = 0;  /* p 遍历所有元素（链表头为 0） */
        while (p != -1) {
            j = GetKey(L->r[p].keys[0], k);  /* 获取第 k 位 */
            if (head[j] == -1) {
                head[j] = p;
            } else {
                L->r[tail[j]].next = p;
            }
            tail[j] = p;
            p = L->r[p].next;
        }

        /* 收集：按桶顺序将元素重新链接 */
        p = -1;
        for (i = 0; i < radix; ++i) {
            if (head[i] != -1) {
                if (p == -1) {
                    p = head[i];
                } else {
                    L->r[tail[p]].next = head[i];
                }
                tail[p] = tail[i];
            }
        }

        /* 将收集后的链表重新写回 r[0..length-1] */
        p = 0;
        for (i = 0; i < L->length; ++i) {
            L->r[i].next = L->r[p].next;
            p = L->r[p].next;
        }
    }
}
```

**简化版（以整型数组为例，不使用链表）**：

```c
/**
 * 简化版 LSD 基数排序——以静态数组 + 计数器实现
 * 不使用链表，直接用计数法分配
 *
 * @param r 待排序数组（1-based）
 * @param n 元素个数
 * @param keynum 关键字位数
 */
void RadixSortSimple(int r[], int n, int keynum) {
    int bucket[radix][MAXSIZE];  /* 桶数组 */
    int count[radix];             /* 桶计数器 */
    int k, i, j, p, index, divisor = 1;

    for (k = 0; k < keynum; ++k) {
        /* 初始化桶计数器 */
        for (i = 0; i < radix; ++i) {
            count[i] = 0;
        }

        /* 分配：将元素放入对应桶 */
        for (i = 1; i <= n; ++i) {
            index = (r[i] / divisor) % radix;  /* 获取第 k 位 */
            bucket[index][count[index]] = r[i];
            count[index]++;
        }

        /* 收集：按桶的顺序收集回 r */
        p = 1;
        for (i = 0; i < radix; ++i) {
            for (j = 0; j < count[i]; ++j) {
                r[p++] = bucket[i][j];
            }
        }

        /* 准备下一位 */
        divisor *= radix;
    }
}
```

#### ⚠️ 算法复杂度分析

| 指标 | 值 | 说明 |
|------|-----|------|
| **时间复杂度** | $O(d \cdot (n + r))$ | $d$ 为关键字位数，$n$ 为元素个数，$r$ 为基数（基数=10 时为十进制） |
| **空间复杂度** | $O(n + r)$ | 需要 $n$ 个元素的空间用于收集 + $r$ 个桶的头尾指针（链表版）或 $O(r \cdot n)$（数组版桶） |
| **稳定性** | ✅ 稳定 | 每次分配-收集过程中桶内元素保持原顺序 |
| **是否比较排序** | 否 | 基于分配-收集，不涉及元素比较 |

> **注意**：基数排序的时间复杂度中，$d$ 和 $r$ 通常为常数（如十进制 32 位整数，$d = 10, r = 10$），所以基数排序可以近似看作 $O(n)$，在 $n$ 较大且位数不多时非常高效。

## 七、算法定位总结

### 📍 算法定位

本文档覆盖 408 数据结构排序模块的全部核心算法。各算法的定位可归纳如下：

- **基础保底型**：直接插入、冒泡、简单选择——代码最短、最易实现，适用于小规模数据（$n < 50$）或作为其他算法的子程序。
- **优化改良型**：折半插入（减少比较）、希尔（分组插入）、优化冒泡（提前终止）——在基础算法上改进，提升实际效率。
- **高性能型**：快速排序（平均最优）、归并排序（稳定且保证 $O(n \log n)$）、堆排序（空间最优的保证型）——大规模数据的实用选择。
- **特殊场景型**：基数排序（非比较、适合整数）、Shell 排序（兼顾实现与效率）。

### 📝 算法详解

详见前文各算法的 C 语言完整实现，均遵循严蔚敏《数据结构》教材的编码风格：

- 使用 `typedef` 定义 `RedType` 和 `SqList` 结构体
- 采用静态数组 `r[MAXSIZE + 1]` 的静态存储结构
- `r[0]` 作为哨兵和临时存储区
- 所有排序函数通过指针操作 `SqList *L` 修改原表

### ⚠️ 算法复杂度分析

详见各算法小节内的复杂度表格。核心要点：

- $O(n^2)$ 类（插入、冒泡、选择）仅适用于小规模数据。
- $O(n \log n)$ 类（快速、归并、堆）适用于大规模数据。
- 基数排序 $O(d(n+r))$ 在 $d$ 和 $r$ 为常数时近似线性。

### ⚖️ 易混淆对比

| 易混淆点 | 区分要点 |
|----------|---------|
| 快速排序 vs 堆排序 | 快速排序平均更快但最坏 $O(n^2)$；堆排序最坏也保证 $O(n \log n)$ 且空间 $O(1)$ |
| 直接插入 vs 折半插入 | 折半插入仅减少比较次数，移动次数不变，整体复杂度仍为 $O(n^2)$ |
| 堆排序 vs 简单选择排序 | 两者都不稳定；堆排序 $O(n \log n)$，简单选择 $O(n^2)$ |
| 快速排序的不稳定性 | Partition 过程中相同元素可能被跨基准交换 |
| 希尔排序的不稳定性 | 跨组比较 + 不同增量趟中相对顺序可能改变 |
| 递归归并 vs 非递归归并 | 功能等价；递归版需栈空间，非递归版无递归开销 |
