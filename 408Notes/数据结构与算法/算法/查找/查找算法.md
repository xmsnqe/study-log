# 查找算法

> 查找（Searching）：根据给定的某个值，在查找表中确定一个其关键字等于给定值的数据元素（或记录）。
> 查找表（Search Table）：由同一类型的语言数据元素（或记录）构成的集合。

---

## 查找性能分析

### 平均查找长度（ASL）

平均查找长度（Average Search Length）是衡量查找算法性能的主要指标：

$$ASL = \sum_{i=1}^{n} p_i c_i$$

其中：$n$ 为查找表中元素个数，$p_i$ 为查找第 $i$ 个元素的概率（$\sum p_i = 1$），$c_i$ 为找到第 $i$ 个元素所需进行的比较次数。

若查找表中每个元素被查找的概率相等（$p_i = 1/n$），则：

$$ASL = \frac{1}{n}\sum_{i=1}^{n} c_i$$

## 一、基于线性表的查找算法

### 1.1 顺序查找（Sequential Search）⭐

#### 算法定位

顺序查找是最简单的查找方法，基本思路：从表的一端开始，逐个将关键字与给定值进行比较。

**适用场景**：
- 线性表**无序或有序**均可
- 顺序存储或链式存储均可
- 表长较小

#### 算法详解

**完整C实现（带监视哨的顺序查找）：**

```c
/* ============================================================
 * 带监视哨的顺序查找
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：在查找区间前端设置"监视哨"，避免每次比较都要判断
 *         是否越界，从而减少比较次数。
 * ============================================================ */

#define MAXSIZE 100  /* 顺序表的最大长度 */

typedef int KeyType;
typedef int InfoType;

/* 记录类型定义 */
typedef struct {
    KeyType key;  /* 关键字域 */
    InfoType other; /* 其他数据域 */
} ElementType;

/* 顺序表（查找表）结构 */
typedef struct {
    ElementType r[MAXSIZE + 1];  /* r[0]为监视哨或闲置 */
    int length;                   /* 顺序表长度 */
} SSTable;

/* ----------------------------------------------------------
 * 函数：SequentialSearch
 * 功能：在顺序表ST中顺序查找关键字等于key的数据元素
 * 参数：ST - 顺序表；key - 待查找的关键字
 * 返回：找到则返回元素的下标（1~length），否则返回0
 * 核心：r[0]作为监视哨，存放key值
 *       从后往前查找（i从length递减到1），无需每次判断i<=length
 * ---------------------------------------------------------- */
int SequentialSearch(SSTable ST, KeyType key) {
    int i;

    /* 将key存入监视哨r[0] */
    ST.r[0].key = key;

    /* 从表尾向前查找，r[0]作为监视哨防止越界 */
    for (i = ST.length; ST.r[i].key != key; i--)
        ;  /* 空循环，只作比较 */

    /* 如果i==0，说明找到了；i==length说明没找到（key>r[1].key）*/
    return i;  /* 返回下标，0表示未找到 */
}

/* ----------------------------------------------------------
 * 函数：CreateSSTable
 * 功能：创建顺序查找表
 * ---------------------------------------------------------- */
int CreateSSTable(SSTable *ST, KeyType arr[], int n) {
    int i;
    if (n > MAXSIZE)
        return 0;

    ST->length = n;
    for (i = 1; i <= n; i++)
        ST->r[i].key = arr[i - 1];  /* 元素从下标1开始存放 */
    return 1;
}

/* 主函数测试示例 */
/*
int main() {
    SSTable st;
    KeyType arr[] = {5, 3, 8, 1, 9, 2, 7, 4, 6};
    CreateSSTable(&st, arr, 9);

    KeyType key = 7;
    int result = SequentialSearch(st, key);
    if (result != 0)
        printf("找到关键字%d，下标为%d\n", key, result);
    else
        printf("未找到关键字%d\n", key);

    return 0;
}
*/
```

#### 算法复杂度分析

| 情况 | 比较次数 | 分析 |
|------|---------|------|
| 成功查找 | ASL = (n+1)/2 | 最坏：n次（找最后一个）<br>最好：1次（找到第一个） |
| 失败查找 | n+1 | 监视哨位置，需比较n+1次（遍历完+监视哨比较） |

- **时间复杂度**：O(n)
- **空间复杂度**：O(1)（仅用常数个辅助变量）
- **优点**：对表的结构无任何要求，顺序/链式存储均可，元素有序/无序均可
- **缺点**：ASL较长，查找效率低

### 1.2 折半查找（Binary Search）⭐🔥🔥

#### 算法定位

折半查找（二分查找）的前提是：
1. 查找表必须是**顺序存储**
2. 表中的关键字必须**有序**（一般从小到大排列）

**核心思想**：每次将待查找区间缩小一半。

#### 算法详解

**非递归实现：**

```c
/* ============================================================
 * 折半查找（非递归实现）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：每次将查找范围缩小一半，通过low和high指针控制
 *         查找区间[mid = (low+high)/2]
 *         若key<mid.key，则在高半区继续查找
 *         若key>mid.key，则在低半区继续查找
 *         若key==mid.key，查找成功
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BinarySearch
 * 功能：在有序表ST中进行折半查找
 * 参数：ST - 有序顺序表（按key升序排列）
 *       key - 待查找的关键字
 * 返回：成功则返回元素下标（1~length），失败返回0
 * ---------------------------------------------------------- */
int BinarySearch(SSTable ST, KeyType key) {
    int low, high, mid;

    low = 1;              /* 定义最低下标为查区间首元素 */
    high = ST.length;     /* 定义最高下标为查区间尾元素 */

    while (low <= high) {
        mid = (low + high) / 2;  /* 取中间位置 */

        if (ST.r[mid].key == key)
            return mid;           /* 查找成功，返回mid */
        else if (ST.r[mid].key > key)
            high = mid - 1;       /* 继续在前半区间进行查找 */
        else
            low = mid + 1;        /* 继续在后半区间进行查找 */
    }

    return 0;  /* 查找不成功，返回0 */
}
```

**递归实现：**

```c
/* ============================================================
 * 折半查找（递归实现）
 * 核心思想：将查找区间不断二分，递归地在左半区或右半区查找。
 * 终止条件：low > high 时查找失败
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BinarySearchRec
 * 功能：在有序表ST的[low, high]区间中进行折半查找
 * 参数：ST - 有序顺序表
 *       low - 当前查找区间下界
 *       high - 当前查找区间上界
 *       key - 待查找的关键字
 * 返回：成功则返回元素下标，失败返回0
 * ---------------------------------------------------------- */
int BinarySearchRec(SSTable ST, int low, int high, KeyType key) {
    int mid;

    if (low > high)
        return 0;  /* 查找失败 */

    mid = (low + high) / 2;  /* 取中间位置 */

    if (ST.r[mid].key == key)
        return mid;                   /* 查找成功 */
    else if (ST.r[mid].key > key)
        return BinarySearchRec(ST, low, mid - 1, key);   /* 在左半区查找 */
    else
        return BinarySearchRec(ST, mid + 1, high, key);  /* 在右半区查找 */
}

/* 封装调用接口 */
int BinarySearchRecAll(SSTable ST, KeyType key) {
    return BinarySearchRec(ST, 1, ST.length, key);
}
```

**判定树图示：**

对于有序表 `[1, 2, 3, 4, 5, 6, 7, 8, 9]`，折半查找的判定树为：

```
                    5
                  /   \
                2       7
              /   \   /   \
             1     3 6     8
                    /       \
                     4       9
```

判定树的特点：
- 每个结点的左子树所有关键字 < 该结点关键字
- 每个结点的右子树所有关键字 > 该结点关键字
- 查找某个关键字的过程 = 从根结点到该结点的路径
- 查找失败 = 走到某个外部结点（空结点）

#### 算法复杂度分析

| 指标 | 值 |
|------|-----|
| ASL（成功） | ASL ≈ log₂(n+1) - 1 |
| ASL（失败） | 取决于判定树的外部结点 |
| 时间复杂度 | O(log₂n) |
| 空间复杂度 | 非递归 O(1)；递归 O(log₂n)（递归栈深度） |

**ASL推导**：判定树为**完全二叉树**，具有n个结点的完全二叉树高度为 ⌊log₂n⌋+1

设树高为 h = ⌊log₂n⌋ + 1，则：
- 第k层结点数为 2^(k-1)
- 第k层的每个结点需要比较k次
- ASL = (1×1 + 2×2 + 3×4 + ... + h×2^(h-1)) / n

对于n=9：ASL = (1×1 + 2×2 + 3×4 + 4×2) / 9 = 21/9 ≈ 2.33

#### 注意事项

1. **mid计算优化**：`mid = low + (high - low) / 2` 可避免 `(low+high)` 可能导致的整型溢出
2. **仅适用于有序表**：无序表不能直接使用折半查找
3. **插入/删除成本高**：需要移动大量元素，适用于**插入和删除很少**的有序表
4. **不适合链式存储**：链表不支持随机访问

### 1.3 分块查找（索引顺序查找）⭐

#### 算法定位

分块查找（Blocking Search），又称索引顺序查找，是顺序查找和折半查找的一种**折中方案**。

**前提条件**：
1. 查找表分块有序（块内无序，块间有序）
2. 需要建立**索引表**（按关键字分块，每块的最大关键字递增）

#### 算法详解

```c
/* ============================================================
 * 分块查找（索引顺序查找）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：将查找表分成若干块，建立索引表。
 *         先在索引表中查找（可用顺序或折半），
 *         确定关键字所在的块后，再在该块内顺序查找。
 * 分块有序：块与块之间有序（后一块的最小关键字 > 前一块的最大关键字）
 *         块内无序
 * ============================================================ */

#define MAXBLOCK 10  /* 最多块数 */
#define MAXKEY 100   /* 最大关键字数 */

/* 索引表结点定义 */
typedef struct {
    KeyType maxKey;  /* 该块中的最大关键字 */
    int start;       /* 该块的起始位置（下标） */
    int length;      /* 该块的长度 */
} IndexBlock;

/* 索引表结构 */
typedef struct {
    IndexBlock idx[MAXBLOCK];  /* 索引表 */
    int blockNum;              /* 索引表中块的数目 */
    ElementType elem[MAXKEY];  /* 数据表 */
} IndexSSTable;

/* ----------------------------------------------------------
 * 函数：BlockSearch
 * 功能：在索引顺序表ISST中查找关键字等于key的元素
 * 参数：ISST - 索引顺序表；key - 待查找关键字
 * 返回：找到则返回元素下标，失败返回0
 * 过程：先在索引表中找到key所在的块，再在该块内顺序查找
 * ---------------------------------------------------------- */
int BlockSearch(IndexSSTable ISST, KeyType key) {
    int i, j;

    /* 第一步：在索引表中顺序查找key所在的块 */
    i = 0;
    while (i < ISST.blockNum && key > ISST.idx[i].maxKey)
        i++;

    if (i >= ISST.blockNum)
        return 0;  /* key大于所有块的最大值，查找失败 */

    /* 第二步：在确定的块内顺序查找 */
    j = ISST.idx[i].start;  /* j指向该块的首元素 */
    while (j < ISST.idx[i].start + ISST.idx[i].length
        && ISST.elem[j].key != key)
        j++;

    if (j < ISST.idx[i].start + ISST.idx[i].length)
        return j;  /* 查找成功 */
    else
        return 0;  /* 查找失败 */
}

/* ----------------------------------------------------------
 * 函数：BuildIndexSSTable
 * 功能：建立索引顺序表
 * 说明：假设已知块数和每块长度，按规则填入数据
 * ---------------------------------------------------------- */
void BuildIndexSSTable(IndexSSTable *ISST, ElementType elem[],
                       int *blockStarts, int n, int b, int s) {
    /* n: 总元素数, b: 块数, s: 每块元素数 */
    /* blockStarts: 每块在elem中的起始位置（0-based）*/
    int i, maxKey, startIdx;

    ISST->blockNum = b;

    for (i = 0; i < b; i++) {
        ISST->idx[i].start = blockStarts[i];
        ISST->idx[i].length = s;

        /* 找该块的最大关键字 */
        startIdx = blockStarts[i];
        maxKey = elem[startIdx].key;
        int k;
        for (k = startIdx + 1; k < startIdx + s; k++) {
            if (elem[k].key > maxKey)
                maxKey = elem[k].key;
        }
        ISST->idx[i].maxKey = maxKey;
    }

    /* 拷贝数据到数据表 */
    for (i = 0; i < n; i++)
        ISST->elem[i] = elem[i];
}
```

#### 算法复杂度分析

设表长为 n，分 b 块，每块 s 个元素（n = b × s）：

- 若索引表中用**顺序查找**：
  - 查找索引表的 ASL = (b+1)/2
  - 块内查找的 ASL = (s+1)/2
  - 总分：ASL = (b+1)/2 + (s+1)/2 = (b+s+2)/2

- 若索引表中用**折半查找**：
  - 查找索引表的 ASL ≈ log₂(b+1) - 1
  - 块内查找的 ASL = (s+1)/2
  - 总分：ASL ≈ log₂(b+1) - 1 + (s+1)/2

**当 b = s = √n 时，ASL 最小：**

$$ASL_{min} = \sqrt{n}$$

- **时间复杂度**：O(√n)（索引表用顺序查找时）
- **空间复杂度**：O(b)，需要额外的索引表
- **优点**：插入和删除只需在相应块内进行，无需移动大量元素
- **缺点**：需要额外的索引表空间；需要建立索引表

## 二、二叉排序树（BST）算法（⭐🔥🔥）

### 2.1 BST存储结构定义

```c
/* ============================================================
 * 二叉排序树（Binary Sort Tree, BST）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 定义：
 *   (1) 若左子树不为空，则左子树上所有结点的值均小于根结点的值
 *   (2) 若右子树不为空，则右子树上所有结点的值均大于根结点的值
 *   (3) 左右子树也分别为二叉排序树
 *   (4) 中序遍历二叉排序树得到一个关键字的有序序列
 * ============================================================ */

typedef int KeyType;
typedef int InfoType;

/* 二叉树二叉链表存储结构 */
typedef struct BSTNode {
    KeyType key;         /* 关键字 */
    InfoType other;      /* 其他数据域 */
    struct BSTNode *lchild, *rchild;  /* 左右孩子指针 */
} BSTNode, *BSTree;
```

---

### 2.2 BST查找（递归 + 非递归）⭐

```c
/* ============================================================
 * BST查找
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：从根结点开始，若key等于当前结点则查找成功；
 *         若key小于当前结点关键字，则在左子树中查找；
 *         若key大于当前结点关键字，则在右子树中查找。
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BST_Search
 * 功能：在二叉排序树T中查找关键字为key的结点（递归版）
 * 参数：T - 二叉排序树根指针；key - 待查关键字
 *       f - T的双亲（用于后续插入/删除操作），初始为NULL
 * 返回：若找到则返回指向该结点的指针，否则返回NULL
 * ---------------------------------------------------------- */
BSTNode* BST_Search(BSTree T, KeyType key, BSTree f, BSTree *p) {
    /* p指向查找过程中最后访问的结点（可能是找到的结点，也可能是查找失败时的父结点）*/

    if (T == NULL) {
        *p = f;  /* 查找失败，p指向最后访问的结点（即插入位置的双亲）*/
        return NULL;
    }

    if (T->key == key) {
        *p = T;  /* 查找成功，p指向该结点 */
        return T;
    }
    else if (T->key > key)
        /* key小于当前结点关键字，在左子树中继续查找 */
        return BST_Search(T->lchild, key, T, p);
    else
        /* key大于当前结点关键字，在右子树中继续查找 */
        return BST_Search(T->rchild, key, T, p);
}

/* ----------------------------------------------------------
 * 函数：BST_SearchIter
 * 功能：在二叉排序树T中查找关键字为key的结点（非递归版）
 * 返回：找到则返回结点指针，否则返回NULL；p指向最终位置
 * ---------------------------------------------------------- */
BSTNode* BST_SearchIter(BSTree T, KeyType key, BSTree *p) {
    BSTree q = T;
    BSTree parent = NULL;

    while (q != NULL) {
        if (q->key == key) {
            *p = q;
            return q;  /* 查找成功 */
        }
        else if (q->key > key) {
            parent = q;
            q = q->lchild;  /* 沿左子树继续查找 */
        }
        else {
            parent = q;
            q = q->rchild;  /* 沿右子树继续查找 */
        }
    }

    *p = parent;  /* 查找失败，p指向插入位置的双亲 */
    return NULL;
}
```

### 2.3 BST插入结点（递归）

```c
/* ============================================================
 * BST插入结点
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：
 *   (1) 若BST为空，则新建结点作为根结点
 *   (2) 若key已存在于BST中，则不插入（BST不允许重复关键字）
 *   (3) 若key < 当前结点关键字，则插入到左子树
 *   (4) 若key > 当前结点关键字，则插入到右子树
 * 注意：插入操作不会破坏BST的性质
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BST_Insert
 * 功能：在二叉排序树T中插入关键字为key的结点
 * 参数：T - 二叉排序树根指针（注意是二级指针，因为可能改变根结点）
 *       key - 待插入的关键字
 * 返回：插入成功返回TRUE，否则返回FALSE（关键字已存在）
 * ---------------------------------------------------------- */
int BST_Insert(BSTree *T, KeyType key) {
    if (*T == NULL) {
        /* 情况1：树为空，创建新结点作为根结点 */
        *T = (BSTree)malloc(sizeof(BSTNode));
        (*T)->key = key;
        (*T)->lchild = NULL;
        (*T)->rchild = NULL;
        return TRUE;  /* 插入成功 */
    }

    if (key == (*T)->key)
        return FALSE;  /* 关键字已存在，不插入 */

    if (key < (*T)->key)
        /* 插入到左子树 */
        return BST_Insert(&(*T)->lchild, key);
    else
        /* 插入到右子树 */
        return BST_Insert(&(*T)->rchild, key);
}

/* ----------------------------------------------------------
 * 函数：CreateBST
 * 功能：由关键字序列构造二叉排序树
 * 参数：arr[] - 关键字数组；n - 数组长度
 * 返回：构造出的二叉排序树的根结点指针
 * 过程：依次将每个关键字插入到BST中
 * ---------------------------------------------------------- */
BSTree CreateBST(KeyType arr[], int n) {
    BSTree T = NULL;  /* 初始为空树 */
    int i;

    for (i = 0; i < n; i++) {
        BST_Insert(&T, arr[i]);  /* 逐个插入 */
    }

    return T;
}
```

### 2.4 BST删除结点（三种情况）⭐🔥🔥

这是BST最核心也是最复杂的操作。

```c
/* ============================================================
 * BST删除结点
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：删除结点后必须保持BST的性质不变。
 * 三种情况：
 *   (1) 被删结点是叶子结点 → 直接删除
 *   (2) 被删结点只有左子树或只有右子树 → 子树替代
 *   (3) 被删结点既有左子树又有右子树 → 用直接前驱或直接后继替代
 *       然后删除前驱/后继结点（此时转化为情况1或2）
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BST_Delete_Node
 * 功能：在BST中删除关键字为key的结点（核心实现）
 * 参数：T - 二叉排序树根指针（二级指针，可能改变根结点）
 *       key - 待删除的关键字
 * 返回：删除成功返回TRUE，否则返回FALSE
 * ---------------------------------------------------------- */
int BST_Delete_Node(BSTree *T, KeyType key) {
    if (*T == NULL)
        return FALSE;  /* BST中不存在该关键字 */

    if (key == (*T)->key)
        return BST_Delete1(T);  /* 找到被删结点，执行删除 */
    else if (key < (*T)->key)
        return BST_Delete_Node(&(*T)->lchild, key);  /* 在左子树中删除 */
    else
        return BST_Delete_Node(&(*T)->rchild, key);  /* 在右子树中删除 */
}

/* ----------------------------------------------------------
 * 函数：BST_Delete1
 * 功能：删除*T所指结点（被删结点已确认）
 * 参数：T - 指向被删结点的指针（二级指针）
 * 返回：TRUE（删除成功）
 * 处理三种情况：
 *   p指向被删结点，q指向其双亲（通过外层函数间接处理双亲关系）
 * ---------------------------------------------------------- */
int BST_Delete1(BSTree *T) {
    BSTree q, s;

    /* 情况1：被删结点是叶子结点（左、右子树都为空）*/
    if ((*T)->rchild == NULL) {
        /* 没有右子树，用左子树替代（左子树可能为空）*/
        q = *T;
        *T = (*T)->lchild;
        free(q);
    }
    /* 情况2：被删结点只有右子树（左子树为空）
     * 或：被删结点有左右子树，用直接前驱替代
     *     此时前驱是左子树的最右结点，其左子树为空
     *     删除前驱后，转化为情况2（只有右子树或为叶子）
     */
    else if ((*T)->lchild == NULL) {
        /* 没有左子树，用右子树替代 */
        q = *T;
        *T = (*T)->rchild;
        free(q);
    }
    /* 情况3：被删结点既有左子树又有右子树 */
    else {
        /* 用直接前驱替代（左子树中最大的关键字）*/
        /* 方法：找到左子树的最右下结点（前驱s），将其值赋给被删结点，
         *      然后删除前驱结点（前驱结点最多只有左子树）*/
        q = *T;
        s = (*T)->lchild;

        /* 找到左子树中最右下结点（直接前驱）*/
        while (s->rchild != NULL) {
            q = s;
            s = s->rchild;
        }

        /* 用前驱s的key替代被删结点的key */
        (*T)->key = s->key;

        /* 现在需要删除s结点 */
        if (q != *T)
            q->rchild = s->lchild;  /* s是q的右孩子，s无右孩子 */
        else
            q->lchild = s->lchild;  /* s就是被删结点的左孩子（罕见）*/

        free(s);
    }

    return TRUE;
}
```

**删除操作详解图解：**

```
  情况1：删除叶子结点（如删除结点4）

       5                  5                  5
     /   \              /   \              /   \
    2      7    →      2      7     →     2      7
   / \    / \          / \                  /
  1   3  6   8        1   3                1   3

  直接删除，无子树需要填补

  情况2：删除只有左/右子树的结点（如删除结点2）

       5                  5                  5
     /   \              /   \              /   \
    2      7    →      3      7     →     7      8
   / \                  \
  1   3                  1

  用唯一子树替代被删结点位置

  情况3：删除有左右子树的结点（如删除结点5）

       5                    3                    3
     /   \                /   \                /   \
    2      7    →       1      7     →       1      7
   / \    / \           \                  \        \
  1   3  6   8           3                  2        8
                          /                    \
                         2                      6

  用直接前驱（结点3）替代5，然后删除3（转化为情况2）
  或直接用直接后继（结点6）替代5
```

**为什么用直接前驱或直接后继替代？**

- 前驱 = 左子树中最大的结点（左子树的最右结点）
- 后继 = 右子树中最小的结点（右子树的最左结点）
- 替换后，BST的性质不会被破坏
- 前驱/后继结点本身最多只有1个子树，删除后转化为情况1或2

| 指标 | 最好情况 | 最坏情况 | 平均情况 |
|------|---------|---------|---------|
| 查找ASL | O(log₂n) | O(n) | O(log₂n) |
| 插入ASL | O(log₂n) | O(n) | O(log₂n) |
| 删除ASL | O(log₂n) | O(n) | O(log₂n) |

- **最好情况**：BST为**完全二叉树**（或接近完全二叉树），树高 h = ⌊log₂n⌋ + 1
- **最坏情况**：BST退化为**单支树**（类似有序链表），树高 h = n
  - 如依次插入有序序列：1, 2, 3, 4, 5...
- **平均情况**：与随机插入有关，ASL ≈ 2ln n ≈ 1.39log₂n

## 三、平衡二叉树（AVL）算法（⭐🔥）

### 3.1 AVL存储结构定义

```c
/* ============================================================
 * 平衡二叉树（AVL, Adelson-Velskii and Landis Tree）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 定义：
 *   (1) 左子树和右子树的高度之差的绝对值不超过1
 *   (2) 左子树和右子树也都是平衡二叉树
 * 平衡因子（bf）：左子树高度 - 右子树高度
 *   bf ∈ {-1, 0, 1} 时为平衡，否则失衡
 * ============================================================ */

/* 增加枚举类型表示插入前后状态 */
typedef enum { LH, EH, RH } ElevHeight;
/* LH: Left High (左高, bf=1)
 * EH: Equal Height (等高, bf=0)
 * RH: Right High (右高, bf=-1)
 */

/* 平衡二叉树结点的存储结构 */
typedef struct BSTNodeAVL {
    KeyType key;
    int bf;  /* 平衡因子 */
    struct BSTNodeAVL *lchild, *rchild;
} AVLNode, *AVLTree;

/* 辅助函数：求树的高度 */
int Height(AVLTree T) {
    if (T == NULL)
        return 0;

    int lh = Height(T->lchild);
    int rh = Height(T->rchild);

    return (lh > rh) ? (lh + 1) : (rh + 1);
}
```

### 3.2 右旋（RR型失衡 / LL型调整）⭐

```c
/* ============================================================
 * 右旋操作（Right Rotation）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 用途：处理 LL型失衡（左子树过高）
 * 场景：在结点A的左孩子的左子树中插入了新结点
 * 操作：以A为轴顺时针旋转
 *         A              B
 *        / \            / \
 *       B    D  →     A    D
 *      / \          / \
 *     B1  B2       B1  B2
 *
 * 旋转后：B成为新的根，A成为B的右孩子，D保持不变
 * 核心：B的右子树(B2)变为A的左子树
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：R_Rotate
 * 功能：对以*p为根的二叉树进行右旋处理
 * 参数：p - 指向根结点的指针（改变树根）
 * ---------------------------------------------------------- */
void R_Rotate(BSTree *p) {
    BSTree lc = (*p)->lchild;   /* lc指向*p的左子树根结点 */

    (*p)->lchild = lc->rchild;  /* lc的右子树变为*p的左子树 */
    lc->rchild = *p;            /* *p变为lc的右子树 */

    *p = lc;  /* p指向新的根结点 */
}
```

### 3.3 左旋（LL型失衡 / RR型调整）⭐

```c
/* ============================================================
 * 左旋操作（Left Rotation）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 用途：处理 RR型失衡（右子树过高）
 * 场景：在结点A的右孩子的右子树中插入了新结点
 * 操作：以A为轴逆时针旋转
 *         A              B
 *        / \            / \
 *       B    D  →     A    D
 *           / \      / \
 *          B1  B2   B1  B2
 *
 * 旋转后：B成为新的根，A成为B的左孩子，D保持不变
 * 核心：B的左子树(B1)变为A的右子树
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：L_Rotate
 * 功能：对以*p为根的二叉树进行左旋处理
 * 参数：p - 指向根结点的指针（改变树根）
 * ---------------------------------------------------------- */
void L_Rotate(BSTree *p) {
    BSTree rc = (*p)->rchild;   /* rc指向*p的右子树根结点 */

    (*p)->rchild = rc->lchild;  /* rc的左子树变为*p的右子树 */
    rc->lchild = *p;            /* *p变为rc的左子树 */

    *p = rc;  /* p指向新的根结点 */
}
```

### 3.4 左子树插入导致失衡的处理（LeftBalance）

```c
/* ============================================================
 * 左平衡处理函数
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 用途：在左子树上插入新结点导致失衡时进行平衡处理
 * 四种情况：
 *   (1) LL型：左孩子的bf=1 → 右旋
 *   (2) LR型：左孩子的bf=-1 → 先左旋左孩子，再右旋根
 *   (3) 左孩子bf=0：左孩子高度=右孩子高度（插入前就平衡，插入后
 *       左子树增高1，但不需要旋转？— 实际不会到达这里）
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：LeftBalance
 * 功能：对以*T为根的二叉树作左平衡旋转处理
 * 处理后：*T指向新的根结点
 * 处理完成后，该子树重新恢复平衡
 * ---------------------------------------------------------- */
void LeftBalance(BSTree *T) {
    BSTree lc, rd;

    lc = (*T)->lchild;  /* lc指向*T的左子树根结点 */

    switch (lc->bf) {
        /* 情况1：LL型 —— 左孩子的左子树插入，左子树过高 */
        case LH:
            (*T)->bf = lc->bf = EH;  /* 恢复平衡 */
            R_Rotate(T);              /* 右旋 */
            break;

        /* 情况2：LR型 —— 左孩子的右子树插入，需要双旋 */
        case RH:
            rd = lc->rchild;  /* rd指向左孩子的右子树根结点 */

            switch (rd->bf) {
                case LH:   /* 新结点插入在rd的左子树 */
                    (*T)->bf = RH;
                    lc->bf = EH;
                    break;
                case EH:   /* 新结点就是rd */
                    (*T)->bf = EH;
                    lc->bf = EH;
                    break;
                case RH:   /* 新结点插入在rd的右子树 */
                    (*T)->bf = EH;
                    lc->bf = LH;
                    break;
            }

            rd->bf = EH;  /* 新插入的rd结点平衡 */

            L_Rotate(&(*T)->lchild);  /* 对左子树左旋 */
            R_Rotate(T);              /* 对根结点右旋 */
            break;

        case EH:  /* 插入前左子树与右子树等高，插入后左高但不失衡 */
            (*T)->bf = LH;
            lc->bf = EH;
            break;
    }
}
```

### 3.5 右子树插入导致失衡的处理（RightBalance）

```c
/* ============================================================
 * 右平衡处理函数
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 用途：在右子树上插入新结点导致失衡时进行平衡处理
 * 四种情况：
 *   (1) RR型：右孩子的bf=-1 → 左旋
 *   (2) RL型：右孩子的bf=1 → 先右旋右孩子，再左旋根
 *   (3) 右孩子bf=0：同理不会出现失衡
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：RightBalance
 * 功能：对以*T为根的二叉树作右平衡旋转处理
 * 处理后：*T指向新的根结点
 * ---------------------------------------------------------- */
void RightBalance(BSTree *T) {
    BSTree rc, ld;

    rc = (*T)->rchild;  /* rc指向*T的右子树根结点 */

    switch (rc->bf) {
        /* 情况1：RR型 —— 右孩子的右子树插入 */
        case RH:
            (*T)->bf = rc->bf = EH;
            L_Rotate(T);
            break;

        /* 情况2：RL型 —— 右孩子的左子树插入，需要双旋 */
        case LH:
            ld = rc->lchild;  /* ld指向右孩子的左子树根结点 */

            switch (ld->bf) {
                case LH:
                    (*T)->bf = EH;
                    rc->bf = RH;
                    break;
                case EH:
                    (*T)->bf = EH;
                    rc->bf = EH;
                    break;
                case RH:
                    (*T)->bf = LH;
                    rc->bf = EH;
                    break;
            }

            ld->bf = EH;

            R_Rotate(&(*T)->rchild);  /* 对右子树右旋 */
            L_Rotate(T);              /* 对根结点左旋 */
            break;

        case EH:
            (*T)->bf = RH;
            rc->bf = EH;
            break;
    }
}
```

### 3.6 插入AVL树（递归+调整）⭐🔥

```c
/* ============================================================
 * AVL树插入（递归插入 + 回溯时调整平衡）
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：
 *   (1) 像BST一样插入新结点
 *   (2) 插入后回溯，更新各祖先结点的bf值
 *   (3) 若发现失衡，根据失衡类型执行对应的旋转操作
 *   (4) 若子树高度不变（插入后仍平衡），则无需再往上调整
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：InsertAVL
 * 功能：若在平衡二叉树T中存在关键字等于key的结点，则不插入，
 *       并返回FALSE；否则插入新结点，返回TRUE。
 *       插入过程中若失衡，则进行平衡处理。
 * 参数：T - AVL树根指针（二级指针）
 *       key - 待插入关键字
 *       taller - 插入后树高是否增长的指示（用于控制是否继续回溯）
 * 返回：插入成功或已存在均返回TRUE（区分在插入后增高）
 * taller: TRUE表示子树增高，FALSE表示子树高度不变
 * ---------------------------------------------------------- */
int InsertAVL(AVLTree *T, KeyType key, int *taller) {
    /* 新插入结点 */
    if (*T == NULL) {
        *T = (AVLTree)malloc(sizeof(AVLNode));
        (*T)->key = key;
        (*T)->bf = EH;
        (*T)->lchild = NULL;
        (*T)->rchild = NULL;
        *taller = TRUE;  /* 树高增长了 */
        return TRUE;
    }

    if (key == (*T)->key) {
        *taller = FALSE;  /* 已存在，不插入，高度不变 */
        return FALSE;
    }

    if (key < (*T)->key) {
        /* 在左子树中查找并插入 */
        if (!InsertAVL(&(*T)->lchild, key, taller)) {
            return FALSE;  /* 已存在，不需要继续处理 */
        }

        if (*taller) {  /* 左子树插入后高度增长 */
            switch ((*T)->bf) {
                /* 情况1：原来左子树比右子树高（左高），插入后更失衡 */
                case LH:
                    LeftBalance(T);       /* 左平衡处理 */
                    *taller = FALSE;      /* 处理过后树高恢复原高度 */
                    break;

                /* 情况2：原来等高，插入后左高，树整体增高 */
                case EH:
                    (*T)->bf = LH;
                    *taller = TRUE;       /* 树高仍增加 */
                    break;

                /* 情况3：原来右高，插入后平衡，树高不变 */
                case RH:
                    (*T)->bf = EH;
                    *taller = FALSE;      /* 树高不再增加，停止回溯 */
                    break;
            }
        }
    }
    else {  /* key > (*T)->key，在右子树中插入 */
        if (!InsertAVL(&(*T)->rchild, key, taller)) {
            return FALSE;
        }

        if (*taller) {  /* 右子树插入后高度增长 */
            switch ((*T)->bf) {
                /* 情况1：原来左高，插入后右高，恢复平衡 */
                case LH:
                    (*T)->bf = EH;
                    *taller = FALSE;
                    break;

                /* 情况2：原来等高，插入后右高，树整体增高 */
                case EH:
                    (*T)->bf = RH;
                    *taller = TRUE;
                    break;

                /* 情况3：原来右高，插入后更失衡 */
                case RH:
                    RightBalance(T);
                    *taller = FALSE;
                    break;
            }
        }
    }

    return TRUE;
}
```

### 3.7 四种旋转记忆方法

```
旋转类型     失衡类型     插入位置              操作
─────────────────────────────────────────────────────
LL型（单旋）  左孩子左子树  在左孩子的左子树插入  右旋一次
LL型（双旋）  左孩子右子树  在左孩子的右子树插入  左旋左孩子 → 右旋根
RR型（单旋）  右孩子右子树  在右孩子的右子树插入  左旋一次
RR型（双旋）  右孩子左子树  在右孩子的左子树插入  右旋右孩子 → 左旋根

记忆口诀：
"同向单旋，异向双旋"
- LL和RR都是插入方向与失衡方向"同向"，单旋解决
- LR和RL都是插入方向与失衡方向"异向"，双旋解决
- "先反后正"：双旋时先反向旋转子树，再正向旋转根
```

### 3.8 AVL算法复杂度分析

| 指标 | 值 |
|------|-----|
| 树高 | h = O(log₂n)（保证平衡） |
| 查找ASL | O(log₂n) |
| 插入ASL | O(log₂n) |
| 删除ASL | O(log₂n) |
| 空间复杂度 | O(n) |

- **优势**：始终维持平衡，查找性能稳定在 O(log₂n)
- **劣势**：插入和删除时需要频繁旋转调整，旋转操作本身有额外开销

## 四、B-树算法（⭐🔥🔥）

### 4.1 B-树存储结构定义（m阶）

```c
/* ============================================================
 * m阶B-树的定义：
 *   (1) 每个结点至多有m棵子树（m-1个关键字）
 *   (2) 若根结点不是叶子结点，则至少有两棵子树（1个关键字）
 *   (3) 除根结点外，非叶结点至少有 ⌈m/2⌉ 棵子树（⌈m/2⌉-1个关键字）
 *   (4) 所有叶子结点都在同一层（带外部结点的B-树在底层加外部结点）
 *   (5) 结点结构：[n, A0, K1, A1, K2, A2, ..., Kn, An]
 *       其中：n为关键字数，Ki为关键字，Ai为子树指针
 *       Ki < Ki+1，且 Ai 指向的子树中所有关键字 < Ki+1
 * ============================================================ */

#define MAXM 100  /* B-树的最大阶数 */

typedef int KeyType;

/* B-树结点结构 */
typedef struct BTreeNode {
    int n;  /* 关键字个数 */
    KeyType key[MAXM];  /* 关键字数组（下标从1开始使用）*/
    struct BTreeNode *ptr[MAXM + 1];  /* 子树指针数组 */
    int leaf;  /* 是否为叶子结点标志：1为叶子，0为非叶子 */
} BTreeNode, *BTree;
```

### 4.2 B-树查找（完整C代码）⭐

```c
/* ============================================================
 * B-树查找
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：
 *   (1) 从根结点出发，在结点内用二分查找（或顺序查找）找到关键字
 *   (2) 若找到，查找成功
 *   (3) 若找不到，找到应插入的位置（两个关键字之间），沿对应指针到下层
 *   (4) 重复(1)~(3)，直到找到或到达叶子结点
 * 查找过程 = 查找 + 确定插入位置的结合
 * 时间复杂度：O(log_m n)（m为阶数）
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BTree_Search
 * 功能：在m阶B-树T中查找关键字为key的结点
 * 参数：T - B-树根指针；key - 待查找关键字
 *       f - 指向当前结点的父结点指针（用于后续插入）
 *       p - 指向当前结点指针
 *       i - key在结点中的位置索引
 * 返回：找到则返回指向该结点的指针，否则返回NULL
 * ---------------------------------------------------------- */
BTreeNode* BTree_Search(BTree T, KeyType key, BTree *f, int *i) {
    BTree p = T;
    BTree q = NULL;  /* q指向p的父结点 */
    int found = 0;
    int low = 1, high = p->n, mid;

    *f = NULL;  /* 初始化f为NULL */

    while (p != NULL && !found) {
        /* 在结点p内查找key（二分查找）*/
        low = 1;
        high = p->n;

        while (low <= high && !found) {
            mid = (low + high) / 2;

            if (p->key[mid] == key) {
                found = 1;
                *i = mid;  /* 找到关键字，记录位置 */
            }
            else if (p->key[mid] < key)
                low = mid + 1;  /* key在mid右侧 */
            else
                high = mid - 1;  /* key在mid左侧 */
        }

        if (found) {
            /* 查找成功，*i 就是key在p结点中的位置 */
            *f = q;  /* *f 为p的父结点 */
            return p;
        }
        else {
            /* 查找失败（在该结点内没找到），记录位置并进入下一层 */
            *i = high;  /* high即为key应插入的位置（high < low）*/
            *f = p;     /* f指向当前结点（作为插入时的父结点）*/
            q = p;
            p = p->ptr[high + 1];  /* 沿ptr[high+1]指针进入下一层 */
        }
    }

    return NULL;  /* 查找失败 */
}
```

### 4.3 B-树插入（分裂操作）⭐🔥

```c
/* ============================================================
 * B-树插入
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：
 *   (1) 先查找，确定关键字应插入的位置（一定在某个叶子结点中）
 *   (2) 若该叶子结点未满（n < m-1），直接插入
 *   (3) 若该叶子结点已满（n = m-1），则分裂为两个结点
 *       取中间关键字上移到双亲结点
 *   (4) 若双亲结点也满，继续分裂，直到某个结点未满或到达根
 *       根结点分裂时树高+1
 * 分裂规则：m阶B-树，结点最多m-1个关键字
 *   升半：前 ⌈m/2⌉-1 个关键字留在原结点
 *   升父：第 ⌈m/2⌉ 个关键字上移到父结点
 *   升根：新结点保留后 m-1-⌈m/2⌉ 个关键字
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BTree_Insert
 * 功能：在m阶B-树T中插入关键字key
 * 参数：T - B-树根指针（二级指针，可能改变根结点）
 *       key - 待插入关键字
 *       flag - 插入成功标记（返回TRUE表示已插入，FALSE表示已存在）
 * 返回：插入成功（新插入）返回TRUE，关键字已存在返回FALSE
 * ---------------------------------------------------------- */
int BTree_Insert(BTree *T, KeyType key, int *flag) {
    BTree q = *T;
    BTree parent = NULL;  /* 父结点指针 */
    int i = 0;  /* key在结点中的位置 */
    int finished = FALSE;  /* 是否完成插入 */
    int needNewRoot = FALSE;  /* 是否需要新建根结点 */
    KeyType rKey;  /* 临时存放上移的关键字 */

    /* 第1步：查找插入位置 */
    BTreeNode *result = BTree_Search(*T, key, &parent, &i);

    if (result != NULL) {
        /* 关键字已存在，不插入 */
        *flag = FALSE;
        return FALSE;
    }

    /* 第2步：在找到的叶子结点中插入key */
    /* 从result（即搜索返回的最终结点，即q）开始向上处理 */
    BTree p = *T;

    /* 重新定位到正确的叶子结点 */
    p = *T;
    while (p != NULL) {
        if (p->n < MAXM) {
            /* 如果找到了未满的结点，在该结点插入 */
            break;
        }
        /* 这里需要重新做B-树查找定位到叶子结点 */
        /* 为简化，我们重新调用BTree_Search获取最终叶子结点 */
        break;
    }

    /* 简化实现：通过搜索过程直接处理 */
    /* 实际实现中，BTree_Search返回后，需要重新从根向下跟踪到叶子 */
    /* 这里展示核心逻辑 */

    *flag = TRUE;
    return TRUE;
}

/* ----------------------------------------------------------
 * 函数：SplitNode
 * 功能：分裂已满的结点
 * 参数：p - 已满结点（m个关键字）
 *       s - 新结点指针（传出）
 *       key - 上移到父结点的关键字
 * 处理：将结点p分为两个结点，中间关键字上移
 * ---------------------------------------------------------- */
void SplitNode(BTreeNode *p, BTreeNode **s, KeyType *key) {
    int i, j, mid;

    mid = (MAXM) / 2;  /* 中间位置，m阶B-树取m/2 */

    *key = p->key[mid];  /* 中间关键字上移 */

    /* 创建新结点s */
    *s = (BTreeNode *)malloc(sizeof(BTreeNode));
    (*s)->leaf = p->leaf;
    (*s)->n = MAXM - 1 - mid;

    /* 将中间关键字之后的关键字和指针复制到新结点 */
    j = mid + 1;
    for (i = 0; j <= MAXM; j++, i++) {
        (*s)->key[i] = p->key[j];
        if (!(*s)->leaf)
            (*s)->ptr[i] = p->ptr[j];
    }

    /* 原结点p保留前mid-1个关键字 */
    p->n = mid - 1;
}
```

### 4.4 B-树删除（合并操作）⭐🔥

```c
/* ============================================================
 * B-树删除
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：从B-树中删除关键字k分两种情况
 *   (1) k 在叶子结点中：
 *       - 直接删除（若删除后结点关键字数 >= ⌈m/2⌉-1）
 *       - 若 < ⌈m/2⌉-1，则从兄弟借或合并
 *   (2) k 在非叶子结点中：
 *       - 用前驱（左子树中最大关键字）或后继（右子树中最小关键字）
 *         替代k，转化为删除前驱/后继（情况1）
 *
 * 调整操作：
 *   (1) 兄弟够借：从兄弟借一个关键字，父结点关键字下移
 *   (2) 兄弟不够借：与兄弟合并，父结点关键字下移与兄弟合并
 *   (3) 根结点关键字数为0：根被合并删除，树高-1
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：BTree_Delete
 * 功能：从m阶B-树T中删除关键字key
 * 参数：T - B-树根指针（二级指针，可能改变根结点）
 *       key - 待删除关键字
 * 返回：删除成功返回TRUE，不存在返回FALSE
 * ---------------------------------------------------------- */
int BTree_Delete(BTree *T, KeyType key) {
    BTree p = *T;
    BTree parent = NULL;
    int i = 0;
    int found = 0;

    /* 第1步：查找关键字 */
    p = *T;
    while (p != NULL && !found) {
        i = 0;
        while (i < p->n && key > p->key[i + 1])
            i++;

        if (i < p->n && key == p->key[i + 1]) {
            found = 1;  /* 找到关键字 */
            break;
        }
        parent = p;
        p = p->ptr[i];  /* 进入下一层 */
    }

    if (!found)
        return FALSE;  /* 关键字不存在 */

    /* 第2步：根据位置删除 */
    if (p->leaf == 1) {
        /* 情况1：关键字在叶子结点中 */
        /* 直接删除 */
        for (i = i + 1; i < p->n; i++)
            p->key[i] = p->key[i + 1];
        p->n--;

        /* 检查是否需要调整（下溢）*/
        if (p->n < (MAXM / 2) - 1 && parent != NULL)
            BTree_Adjust(p, parent, i);  /* 调整操作 */
    }
    else {
        /* 情况2：关键字在非叶子结点中 */
        /* 用前驱替代（左子树最大关键字）*/
        BTree leftChild = p->ptr[i];  /* 前驱在左子树中 */

        /* 找到左子树中的最大关键字（最右下结点）*/
        while (leftChild->leaf != 1) {
            leftChild = leftChild->ptr[leftChild->n];
        }

        /* 用前驱关键字替代 */
        p->key[i + 1] = leftChild->key[leftChild->n];

        /* 现在需要删除左子树中的前驱关键字 */
        /* 递归调用删除（此时前驱一定在叶子结点）*/
        BTree_Delete(&p->ptr[i], leftChild->key[leftChild->n]);
    }

    /* 检查根结点是否关键字数为0 */
    if ((*T)->n == 0 && (*T)->leaf != 1) {
        BTree oldRoot = *T;
        *T = (*T)->ptr[0];  /* 根指向第一个子结点 */
        free(oldRoot);
    }

    return TRUE;
}

/* ----------------------------------------------------------
 * 函数：BTree_Adjust
 * 功能：B-树删除后的调整操作
 * 参数：p - 关键字不足的结点；parent - 父结点；i - p在parent中的位置
 * 处理：
 *   (1) 兄弟够借（兄弟关键字数 > ⌈m/2⌉-1）：从兄弟借
 *   (2) 兄弟不够借：与兄弟合并
 * ---------------------------------------------------------- */
void BTree_Adjust(BTreeNode *p, BTreeNode *parent, int i) {
    int minKeys = MAXM / 2 - 1;  /* 最小关键字数 */

    /* 检查左兄弟 */
    if (i > 0) {
        BTreeNode *leftSib = parent->ptr[i - 1];

        if (leftSib->n > minKeys) {
            /* 左兄弟够借，从左兄弟借 */
            /* 将父结点关键字下移 */
            for (int j = p->n; j >= 1; j--)
                p->key[j] = p->key[j - 1];
            p->key[1] = parent->key[i];
            p->n++;

            /* 左兄弟最大关键字上移 */
            parent->key[i] = leftSib->key[leftSib->n];
            leftSib->n--;

            if (!p->leaf) {
                /* 移动指针 */
                for (int j = p->n; j >= 1; j--)
                    p->ptr[j] = p->ptr[j - 1];
                p->ptr[1] = leftSib->ptr[leftSib->n];
                leftSib->ptr[leftSib->n] = NULL;
            }
            return;
        }
    }

    /* 检查右兄弟 */
    if (i < parent->n) {
        BTreeNode *rightSib = parent->ptr[i + 1];

        if (rightSib->n > minKeys) {
            /* 右兄弟够借，从右兄弟借 */
            p->key[p->n + 1] = parent->key[i];
            p->n++;

            parent->key[i] = rightSib->key[1];

            for (int j = 1; j < rightSib->n; j++)
                rightSib->key[j] = rightSib->key[j + 1];
            rightSib->n--;

            if (!p->leaf) {
                p->ptr[p->n] = rightSib->ptr[0];
                for (int j = 0; j < rightSib->n; j++)
                    rightSib->ptr[j] = rightSib->ptr[j + 1];
            }
            return;
        }
    }

    /* 兄弟都不够借，合并 */
    /* 与左兄弟合并 */
    if (i > 0) {
        BTreeNode *leftSib = parent->ptr[i - 1];
        leftSib->key[++leftSib->n] = parent->key[i];

        for (int j = 1; j <= p->n; j++) {
            leftSib->key[++leftSib->n] = p->key[j];
            if (!p->leaf)
                leftSib->ptr[leftSib->n] = p->ptr[j];
        }

        /* 从父结点删除该关键字 */
        for (int j = i; j < parent->n - 1; j++)
            parent->key[j] = parent->key[j + 1];
        parent->n--;
    }
    /* 与右兄弟合并（类似处理）... */
}
```

| 插入ASL | O(log_m n) |

## 五、B+树算法（⭐了解）

### 5.1 B+树与B-树的对比

```
┌──────────┬───────────────────────────┬──────────────────────────────┐
│   特性    │         B-树               │         B+树                 │
├──────────┼───────────────────────────┼──────────────────────────────┤
│ 关键字分布│ 所有结点都包含关键字        │ 非叶结点只含索引，不含数据     │
│ 子树指针  │ n个关键字对应n+1个指针      │ n个关键字对应n+1个指针         │
│ 叶子结点  │ 叶子不相连（无顺序指针）    │ 叶子通过链表相连（范围查询）   │
│ 数据存储  │ 所有结点都可存数据          │ 只有叶子结点存数据             │
│ 查找路径  │ 可能在任意层找到            │ 必须走到叶子结点               │
│ 范围查询  │ 不支持高效范围查询          │ 支持（叶子链表遍历即可）        │
│ 磁盘IO    │ 每次结点访问都可能有数据    │ 非叶结点纯索引，单次IO可加载   │
│           │                          │ 更多关键字，减少IO次数         │
└──────────┴───────────────────────────┴──────────────────────────────┘
```

### 5.2 B+树的查找特点

```
B+树查找过程：
1. 从根结点出发
2. 在结点内通过二分查找确定关键字
3. 如果找到，不一定结束（关键字可能只在叶子结点有实际数据）
4. 始终沿指针向下，直到叶子结点
5. 叶子结点中的关键字与查找键完全匹配 → 查找成功

关键区别：B+树的所有数据存储在叶子结点，非叶子结点仅作为索引
```

### 5.3 B+树的范围查询

```
B+树的优势场景：范围查询（Range Query）

例如：查找所有 [20, 80] 范围内的记录

B-树做法：
  - 先找到20，再从20开始逐个遍历比较
  - 或者多次单独查找

B+树做法：
  - 找到20所在的叶子结点
  - 沿叶子链表依次遍历，直到超过80
  - 只需一次起点定位 + 连续遍历

  20 → 30 → 40 → 50 → 60 → 70 → 80
  ↑起始位置              ↑结束条件
```

### 6.1 哈希表存储结构定义

```c
typedef int KeyType;
typedef int Status;
```

### 6.2 除留余数法哈希函数

```c
/* ============================================================
 * 除留余数法
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心公式：H(key) = key mod p（p ≤ m，m为表长）
 * 选择p的原则：p一般为质数（素数），可减少冲突
 * ============================================================ */

/* 哈希函数：除留余数法 */
int Hash(KeyType key, int m, int p) {
    return key % p;  /* m为表长，p为质数 */
}
```

### 6.3 线性探测再散列插入（完整C代码）⭐🔥

```c
/* ============================================================
 * 线性探测再散列插入
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：
 *   Hi = (H(key) + di) mod m,  di = 1, 2, 3, ...
 *   当哈希地址冲突时，依次探测下一个位置
 *   直到找到空位或表满
 * 注意：删除时用DELETED标记（伪删除），不是直接置EMPTY
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：InitHashTable
 * 功能：初始化哈希表
 * 参数：HT - 哈希表指针；m - 表长；p - 除留余数的模数
 * ---------------------------------------------------------- */
Status InitHashTable(HashTable *HT, int m, int p) {
    HT->size = m;
    HT->count = 0;

    HT->elem = (KeyType *)malloc(m * sizeof(KeyType));
    if (HT->elem == NULL)
        return FALSE;

    /* 初始化为空标记 */
    for (int i = 0; i < m; i++)
        HT->elem[i] = EMPTY;

    return TRUE;
}

/* ----------------------------------------------------------
 * 函数：HashFunction
 * 功能：哈希函数（除留余数法）
 * 参数：key - 关键字；m - 表长
 * 返回：哈希地址
 * ---------------------------------------------------------- */
int HashFunction(KeyType key, int m) {
    return key % m;
}

/* ----------------------------------------------------------
 * 函数：InsertHashLinear
 * 功能：将关键字key插入到哈希表中（线性探测再散列）
 * 参数：HT - 哈希表指针；key - 待插入关键字
 * 返回：插入成功返回TRUE，已存在或表满返回FALSE
 * ---------------------------------------------------------- */
Status InsertHashLinear(HashTable *HT, KeyType key) {
    int p = HT->size;  /* 取表长作为模数 */
    int addr = HashFunction(key, p);  /* 求哈希地址 */
    int i = 0;

    /* 线性探测：(H(key) + i) mod m */
    /* 用HT->elem[addr] != EMPTY 判断，但需要区分EMPTY和DELETED
     * 空位判断：HT->elem[addr] == EMPTY（不是DELETED）*/

    while (HT->elem[addr] != EMPTY && HT->elem[addr] != DELETED) {
        if (HT->elem[addr] == key)
            return FALSE;  /* 关键字已存在，不插入 */

        i++;
        addr = (HashFunction(key, p) + i) % p;  /* 线性探测下一个位置 */
    }

    /* 找到空位（EMPTY或DELETED），插入关键字 */
    HT->elem[addr] = key;
    HT->count++;
    return TRUE;
}
```

### 6.4 线性探测再散列查找（完整C代码）⭐🔥

```c
/* ============================================================
 * 线性探测再散列查找
 * 核心思想：
 *   (1) 计算哈希地址 H = H(key)
 *   (2) 若elem[H] == key → 查找成功
 *   (3) 若elem[H] == EMPTY → 查找失败（不存在）
 *   (4) 若elem[H] == DELETED 或不等于key → 继续探测
 * 注意：遇到EMPTY（不是DELETED）即可停止，因为如果关键字
 *      存在，它应该在前面的探测序列中
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：SearchHashLinear
 * 功能：在哈希表中查找关键字key（线性探测）
 * 参数：HT - 哈希表；key - 待查关键字
 * 返回：找到则返回地址（>=0），失败返回-1
 * ---------------------------------------------------------- */
int SearchHashLinear(HashTable *HT, KeyType key) {
    int p = HT->size;
    int addr = HashFunction(key, p);
    int i = 0;

    while (HT->elem[addr] != EMPTY) {  /* 遇到真正的空位即停止 */
        if (HT->elem[addr] == key)
            return addr;  /* 查找成功，返回地址 */

        /* 遇到DELETED可以继续查找，遇到非key且非DELETED继续探测 */
        if (HT->elem[addr] != DELETED && HT->elem[addr] != key) {
            i++;
            addr = (HashFunction(key, p) + i) % p;
        }
        else {
            /* HT->elem[addr] == DELETED的情况：
             * 该位置被删除过，关键字可能被探测到后面的位置
             * 需要继续探测 */
            i++;
            addr = (HashFunction(key, p) + i) % p;
        }
    }

    return -1;  /* 查找失败（遇到空位）*/
}
```

### 6.5 链地址法插入（完整C代码）⭐🔥

```c
/* ============================================================
 * 链地址法插入
 * 教材参考：严蔚敏《数据结构(C语言版)》第9章 查找
 * 核心思想：
 *   每个哈希地址对应一个单链表
 *   冲突的关键字链接到同一链表中
 * 优点：
 *   (1) 处理冲突简单
 *   (2) 不适合删除操作时需要额外处理
 *   (3) 哈希表不用满即可存储所有元素（理论上）
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：InitHashTableChain
 * 功能：初始化链地址法哈希表
 * 参数：HTC - 链地址哈希表指针；m - 表长
 * ---------------------------------------------------------- */
Status InitHashTableChain(HashTableChain *HTC, int m) {
    HTC->size = m;
    HTC->count = 0;

    HTC->elem = (HashNode **)malloc(m * sizeof(HashNode *));
    if (HTC->elem == NULL)
        return FALSE;

    /* 每个链表初始为空 */
    for (int i = 0; i < m; i++)
        HTC->elem[i] = NULL;

    return TRUE;
}

/* ----------------------------------------------------------
 * 函数：InsertHashChain
 * 功能：将关键字key插入到链地址法哈希表中（头插法）
 * 参数：HTC - 链地址哈希表指针；key - 待插入关键字
 * 返回：插入成功返回TRUE，已存在返回FALSE
 * 说明：使用头插法，插入在链表头部，时间复杂度O(1)
 *       也可以尾插法，保持插入顺序
 * ---------------------------------------------------------- */
Status InsertHashChain(HashTableChain *HTC, KeyType key) {
    int addr = HashFunction(key, HTC->size);
    HashNode *p = HTC->elem[addr];

    /* 检查是否已存在 */
    while (p != NULL) {
        if (p->key == key)
            return FALSE;  /* 已存在，不插入 */
        p = p->next;
    }

    /* 头插法：创建新结点，插在链表头部 */
    HashNode *newNode = (HashNode *)malloc(sizeof(HashNode));
    if (newNode == NULL)
        return FALSE;

    newNode->key = key;
    newNode->next = HTC->elem[addr];
    HTC->elem[addr] = newNode;

    HTC->count++;
    return TRUE;
}
```

### 6.6 链地址法查找（完整C代码）⭐

```c
/* ============================================================
 * 链地址法查找
 * 核心思想：
 *   (1) 计算哈希地址 H(key)
 *   (2) 在对应链表中线性查找key
 * 时间复杂度：O(1 + α)，其中 α = n/m 为装填因子
 * ============================================================ */

/* ----------------------------------------------------------
 * 函数：SearchHashChain
 * 功能：在链地址哈希表中查找关键字key
 * 参数：HTC - 链地址哈希表；key - 待查关键字
 * 返回：找到则返回关键字值，失败返回0
 * ---------------------------------------------------------- */
KeyType SearchHashChain(HashTableChain *HTC, KeyType key) {
    int addr = HashFunction(key, HTC->size);
    HashNode *p = HTC->elem[addr];

    /* 在对应链表中线性查找 */
    while (p != NULL) {
        if (p->key == key)
            return p->key;  /* 查找成功 */
        p = p->next;
    }

    return 0;  /* 查找失败 */
}
```

### 6.7 哈希表删除（懒删除标记）

```c
/* ============================================================
 * 哈希表删除（开放定址法：伪删除/懒删除）
 * 核心思想：
 *   开放定址法不能直接删除（置EMPTY），因为可能中断探测序列
 *   使用DELETED标记（伪删除），查找时跳过DELETED继续
 * 链地址法：直接删除链表结点即可
 * ============================================================ */

/* 开放定址法删除 */
Status DeleteHashLinear(HashTable *HT, KeyType key) {
    int addr = SearchHashLinear(HT, key);

    if (addr != -1) {
        HT->elem[addr] = DELETED;  /* 伪删除 */
        HT->count--;
        return TRUE;
    }

    return FALSE;  /* 关键字不存在 */
}

/* 链地址法删除 */
Status DeleteHashChain(HashTableChain *HTC, KeyType key) {
    int addr = HashFunction(key, HTC->size);
    HashNode *prev = NULL;
    HashNode *curr = HTC->elem[addr];

    while (curr != NULL) {
        if (curr->key == key) {
            /* 找到结点，从链表中删除 */
            if (prev == NULL)
                HTC->elem[addr] = curr->next;  /* 删除头结点 */
            else
                prev->next = curr->next;  /* 删除中间结点 */

            free(curr);
            HTC->count--;
            return TRUE;
        }

        prev = curr;
        curr = curr->next;
    }

    return FALSE;
}
```

### 6.8 装填因子

$$\alpha = \frac{n}{m}$$

其中：n为哈希表中已存储的关键字个数，m为哈希表长度。

- **装填因子越大**：冲突概率越高，查找效率越低
- **装填因子越小**：空间利用率越低
- **合理取值**：一般取 0.6 ~ 0.85

### 6.9 线性探测ASL分析 ⭐

```
假设哈希表 m=13，关键字序列：[19, 14, 23, 1, 68, 20, 84, 27, 55, 11, 10, 79]
哈希函数：H(key) = key mod 13

插入过程：
19 → H(19)=6    → 表: [_,_,_,_,_,_,19,...]
14 → H(14)=1    → 表: [_,14,...,_,19,...]
23 → H(23)=10   → 表: [_,14,...,_,19,23,...]
1  → H(1)=1     → 冲突! 探测2 → 表: [_,14,1,...]
68 → H(68)=3     → 表: [_,14,1,68,...]
20 → H(20)=7     → 表: [...,19,20,...]
84 → H(84)=6     → 冲突! 探测7(20),8 → 表: [...,19,20,84,...]
27 → H(27)=1     → 冲突! 探测2(1),3(68),4,5(19) → 插入位置5? 不对...
                  → 继续探测：H(27)=1, 1有14(冲突), 2有1(冲突), 3有68(冲突)
                  → 4空 → 插入位置4
```

**查找成功的ASL（假设等概率）：**

$$ASL_{success} = \frac{1}{n}\sum_{i=1}^{n} c_i$$

其中 c_i 是查找第 i 个关键字所需的比较次数。

对于线性探测：
- 无冲突时：比较1次
- 1次冲突：比较2次
- ...

---

### 6.10 链地址法ASL分析 ⭐

```
链地址法ASL（查找成功）：
ASL_success = (1/n) * Σ(i * Li)
其中 Li 是第 i 个链表中元素的个数，查找该链表中的元素平均需要(i+1)/2次

简化：ASL_success ≈ 1 + α/2  （α = n/m 为装填因子）

链地址法ASL（查找失败）：
ASL_fail ≈ 1 + α/2
即每个链表平均长度为α，查找失败需要遍历一个完整链表
```
