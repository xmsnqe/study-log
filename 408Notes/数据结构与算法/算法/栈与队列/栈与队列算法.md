# 栈与队列算法详解

> **本章定位**：栈（Stack）与队列（Queue）是线性表的特殊形式，分别遵循"后进先出"（LIFO）与"先进先出"（FIFO）原则。它们在函数调用、表达式求值、层次遍历、广度优先搜索等场景中具有不可替代的作用，是 408 数据结构科目中高频考点。

---

## 📍算法定位

栈与队列是线性结构的两种重要变体，其核心特征在于**操作受限**——线性表允许在任意位置插入和删除，而栈与队列分别将操作限制在表的一端（栈顶 / 队首与队尾）。

| 结构 | 访问原则 | 典型应用场景 | 408 考查权重 |
|------|----------|-------------|-------------|
| **顺序栈** | 后进先出（LIFO） | 函数调用栈、括号匹配、表达式求值、递归转换 | ⭐⭐⭐⭐⭐ |
| **链栈** | 后进先出（LIFO） | 栈长度不确定的场景 | ⭐⭐⭐ |
| **循环队列** | 先进先出（FIFO） | 缓冲区管理、BFS、任务调度 | ⭐⭐⭐⭐⭐ |
| **链队列** | 先进先出（FIFO） | 队列长度动态变化 | ⭐⭐⭐ |
| **表达式求值** | 双栈协同 | 四则运算计算器 | ⭐⭐⭐⭐⭐ |
| **递归算法** | 隐含栈机制 | 斐波那契、汉诺塔、树遍历 | ⭐⭐⭐⭐ |

## 📝算法详解

### 一、栈的基本操作

#### 1.1 顺序栈的定义

```c
/* ==================== 顺序栈的定义 ==================== */
#define MAXSIZE 100           /* 栈存储空间的初始分配量 */
#define OK 1
#define ERROR 0
#define TRUE 1
#define FALSE 0

typedef int Status;
typedef int SElemType;          /* 可根据需要修改元素类型 */

/* 顺序栈结构 */
typedef struct {
    SElemType *base;              /* 栈底指针，栈创建时动态分配 */
    SElemType *top;               /* 栈顶指针 */
    int stacksize;                /* 当前已分配的存储空间，以元素为单位 */
} SqStack;
```

**要点说明**：

- `base` 为栈底指针，在栈生命周期中不变；`top` 为栈顶指针，初始时 `top == base` 表示空栈。
- 约定 `top` 指向**栈顶元素的上一个位置**（即入栈时先移动 `top`，再存入元素），也可约定 `top` 直接指向栈顶元素，两种约定等价，但实现有差异。本文采用前者。

---

#### 1.2 初始化栈 `InitStack`

```c
/* ==================== 初始化顺序栈 ==================== */
Status InitStack(SqStack &S) {
    /* 为栈底分配最大容量的存储空间 */
    S.base = (SElemType *)malloc(MAXSIZE * sizeof(SElemType));
    if (!S.base) return ERROR;          /* 存储分配失败 */
    S.top = S.base;                      /* 栈顶等于栈底，空栈 */
    S.stacksize = MAXSIZE;               /* 初始容量 */
    return OK;
}
```

**时间复杂度**：$O(1)$ — 仅一次内存分配和赋值操作。

---

#### 1.3 入栈 `Push`

##### （A）顺序栈入栈

```c
/* ==================== 顺序栈入栈 ==================== */
Status Push(SqStack &S, SElemType e) {
    /* 栈满则追加存储空间 */
    if (S.top - S.base >= S.stacksize) {
        SElemType *newbase = (SElemType *)realloc(S.base,
                           (S.stacksize + MAXSIZE) * sizeof(SElemType));
        if (!newbase) return ERROR;          /* 存储分配失败 */
        S.base = newbase;                    /* 更新栈底指针 */
        S.top = S.base + S.stacksize;        /* 更新栈顶指针 */
        S.stacksize += MAXSIZE;              /* 更新容量 */
    }
    *(S.top++) = e;                          /* 先存值，再移动栈顶指针 */
    return OK;
}
```

**要点**：

- 采用 `realloc` 进行动态扩容，每次扩展 `MAXSIZE` 个单位。
- 若将 `realloc` 返回值直接赋给 `base` 时出错，原空间不会被释放，此处 `newbase` 作为临时指针规避了该风险。

##### （B）链栈入栈

```c
/* ==================== 链栈结点定义 ==================== */
typedef struct StackNode {
    SElemType data;                        /* 数据域 */
    struct StackNode *next;                /* 指针域 */
} StackNode, *LinkStack;

/* ==================== 初始化链栈 ==================== */
Status InitStack(LinkStack &S) {
    S = NULL;                              /* 空链栈，栈顶指针为空 */
    return OK;
}

/* ==================== 链栈入栈 ==================== */
Status Push(LinkStack &S, SElemType e) {
    StackNode *p = (StackNode *)malloc(sizeof(StackNode));
    if (!p) return ERROR;                  /* 存储分配失败 */
    p->data = e;                           /* 存入元素 */
    p->next = S;                           /* 新结点指向原栈顶 */
    S = p;                                 /* 栈顶指针指向新结点 */
    return OK;
}
```

**要点**：

- 链栈在栈顶插入，无需遍历，时间复杂度为 $O(1)$。
- 链栈不存在"满"的问题，除非系统内存耗尽。

---

#### 1.4 出栈 `Pop`

##### （A）顺序栈出栈

```c
/* ==================== 顺序栈出栈 ==================== */
Status Pop(SqStack &S, SElemType &e) {
    if (S.top == S.base) return ERROR;     /* 栈空 */
    e = *--S.top;                          /* 先移动栈顶指针，再取元素 */
    return OK;
}
```

##### （B）链栈出栈

```c
/* ==================== 链栈出栈 ==================== */
Status Pop(LinkStack &S, SElemType &e) {
    if (S == NULL) return ERROR;           /* 栈空 */
    StackNode *p = S;                      /* p 指向栈顶结点 */
    e = p->data;                           /* 取栈顶元素 */
    S = S->next;                           /* 栈顶指针后移 */
    free(p);                               /* 释放原栈顶结点 */
    return OK;
}
```

---

#### 1.5 取栈顶元素 `GetTop`

```c
/* ==================== 顺序栈取栈顶元素 ==================== */
SElemType GetTop(SqStack S) {
    if (S.top == S.base) return '\0';      /* 栈空，返回空字符作为错误标志 */
    return *(S.top - 1);                   /* 不移动 top，返回栈顶元素 */
}

/* ==================== 链栈取栈顶元素 ==================== */
SElemType GetTop(LinkStack S) {
    if (S == NULL) return '\0';            /* 栈空 */
    return S->data;                        /* 返回栈顶结点数据 */
}
```

#### 2.1 括号匹配算法（🔥重点）

**问题描述**：假设一个表达式或程序代码中包含圆括号 `()`、方括号 `[]` 和花括号 `{}`，判断括号是否正确配对。

**算法思想**：

1. 从左到右扫描字符串。
2. 遇到左括号 `(`、`[`、`{` 时，**入栈**。
3. 遇到右括号 `)`、`]`、`}` 时：
   - 若栈空，说明**右括号多余**，匹配失败。
   - 否则出栈，检查出栈的左括号是否与当前右括号**配对**。若不配对，匹配失败。
4. 扫描结束后，若**栈空**，说明所有括号均正确匹配。

```c
/* ==================== 括号匹配算法 ==================== */
/* 判断表达式中括号是否配对，配对返回 TRUE，否则返回 FALSE */
Status BracketsMatch(char *expr) {
    SqStack S;
    InitStack(S);                          /* 初始化栈 */
    char *p = expr;                        /* 指针遍历表达式 */
    SElemType e;

    while (*p != '\0') {
        /* 遇到左括号，入栈 */
        if (*p == '(' || *p == '[' || *p == '{') {
            Push(S, *p);
        }
        /* 遇到右括号，检查匹配 */
        else if (*p == ')' || *p == ']' || *p == '}') {
            if (S.top == S.base) {
                /* 栈空，右括号多余 */
                return FALSE;
            }
            Pop(S, e);                     /* 弹出栈顶元素 */
            /* 检查括号是否配对 */
            if (*p == ')' && e != '(') return FALSE;
            if (*p == ']' && e != '[') return FALSE;
            if (*p == '}' && e != '{') return FALSE;
        }
        /* 忽略非括号字符 */
        p++;
    }

    /* 扫描完毕，栈空则全部匹配 */
    if (S.top == S.base) return TRUE;
    else return FALSE;                     /* 栈不空，左括号多余 */
}
```

**示例**：

| 表达式 | 匹配过程 | 结果 |
|--------|---------|------|
| `(a+b)*[c-{d*e}]` | `(` → `[` → `{` → 遇 `}` 弹出 `{` 匹配 → 遇 `]` 弹出 `[` 匹配 → 遇 `)` 弹出 `(` 匹配 → 栈空 | ✅ TRUE |
| `((a+b])` | `(` → `(` → 遇 `]` 弹出 `(` 不匹配 | ❌ FALSE |
| `((a+b)` | 栈中剩余一个 `(` | ❌ FALSE |

**时间复杂度**：$O(n)$，$n$ 为表达式长度。**空间复杂度**：$O(n)$，最坏情况所有字符均为左括号。

#### 2.2 表达式求值 — 双栈法（⭐🔥核心重点）

**问题描述**：给定一个不含括号的简化表达式或含括号的完整算术表达式，求其值。本题需实现含优先级、括号的四则运算计算器。

**算法核心思想（严蔚敏教材双栈法）**：

使用两个栈协同工作：

- **OPTR**（Operator Stack，运算符栈）：存放运算符和运算优先级标识。
- **OPND**（Operand Stack，操作数栈）：存放操作数（计算结果）。

##### 优先关系表

| 运算符关系 | + | - | * | / | ( | ) | # |
|-----------|---|---|---|---|---|---|---|
| **+**     | > | > | < | < | < | > | > |
| **-**     | > | > | < | < | < | > | > |
| **\***    | > | > | > | > | < | > | > |
| **/**     | > | > | > | > | < | > | > |
| **(**     | < | < | < | < | < | = | ? |
| **)**     | > | > | > | > | ? | > | > |
| **#**     | < | < | < | < | < | = | = |

> 表中 `>` 表示栈顶运算符优先级**高于**当前运算符，`<` 表示**低于**，`=` 表示**相等**（仅 `( )` 和 `# #` ），`?` 表示非法组合。

**算法流程**：

```
1. 初始化：OPTR 栈压入表达式的结束符 '#'；OPND 栈清空。
2. 逐个读入字符，构造操作数。
3. 比较 OPTR 栈顶运算符 theta1 与当前字符 c 的优先级：
   - 若 theta1 < c：c 入 OPTR 栈。
   - 若 theta1 = c：脱括号（OPTR 弹栈，读入下一个字符），继续。
   - 若 theta1 > c：OPTR 弹栈得到运算符 θ，OPND 弹出两个操作数 b 和 a，
     计算 a θ b，结果压入 OPND 栈，**不读入新字符**，回到步骤 3 重新比较。
4. 当 OPTR 栈顶为 '#' 且当前字符也为 '#' 时，算法结束，OPND 栈顶即为结果。
```

```c
#include <math.h>

/* ==================== 表达式求值 — 双栈法（含括号完整实现）==================== */

/* 运算符优先级关系：'>' 优先, '<' 低, '=' 相等 */
char Prior[7][7] = {
    /*   +    -    *    /    (    )    #  */
    /* + */  '>',  '>',  '<',  '<',  '<',  '>',  '>',
    /* - */  '>',  '>',  '<',  '<',  '<',  '>',  '>',
    /* * */  '>',  '>',  '>',  '>',  '<',  '>',  '>',
    /* / */  '>',  '>',  '>',  '>',  '<',  '>',  '>',
    /* ( */  '<',  '<',  '<',  '<',  '<',  '=',  ' ',
    /* ) */  '>',  '>',  '>',  '>',  ' ',  '>',  '>',
    /* # */  '<',  '<',  '<',  '<',  '<',  '=',  '='
};

/* 运算符与 Prior 数组行/列的映射 */
int InOper(char c) {
    switch (c) {
        case '+': return 0;
        case '-': return 1;
        case '*': return 2;
        case '/': return 3;
        case '(': return 4;
        case ')': return 5;
        case '#': return 6;
        default:  return -1;                 /* 非法运算符 */
    }
}

/* 判断是否为数字 */
int IsDigit(char c) {
    return (c >= '0' && c <= '9');
}

/* 运算函数 */
SElemType Operate(SElemType a, char theta, SElemType b) {
    switch (theta) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        case '/': return a / b;           /* 整除，需事先判断 b != 0 */
        default: return 0;
    }
}

/* 求 Prior 中优先级关系 */
char GetPrior(SElemType theta1, char theta2) {
    int r = InOper(theta1);
    int c = InOper(theta2);
    if (r < 0 || c < 0) return ' ';       /* 非法运算符 */
    return Prior[r][c];
}

/* 主函数：求表达式求值 */
SElemType EvaluateExpression(char *expr) {
    SqStack OPND, OPTR;                   /* OPND: 操作数栈, OPTR: 运算符栈 */
    InitStack(OPND);
    InitStack(OPTR);
    Push(OPTR, '#');                       /* 压入表达式起始/结束符 */

    char theta, c, x, a, b;
    SElemType d;
    int i = 0;

    while (expr[i] != '\0' || GetTop(OPTR) != '#') {
        c = expr[i];

        if (IsDigit(c)) {                  /* 构造操作数 */
            d = c - '0';                   /* 简化：仅处理单个数字 */
            Push(OPND, d);                 /* 操作数入栈 */
            i++;
        }
        else {
            /* 处理运算符 */
            switch (c) {
                case ' ': i++; break;      /* 跳过空格 */
                default:                  /* 非数字非空格，需识别为运算符 */
                    /* 若当前字符不是已知的运算符字符，尝试将其作为多位数解析 */
                    if (InOper(c) < 0) {  /* 非运算符字符 */
                        /* 简单处理：跳过或报错 */
                        i++;
                        break;
                    }
                    x = GetTop(OPTR);      /* 取 OPTR 栈顶运算符 */
                    theta = GetPrior(x, c); /* 比较优先级 */

                    if (theta == '<') {    /* 栈顶运算符优先级低，当前运算符入栈 */
                        Push(OPTR, c);
                        i++;
                    }
                    else if (theta == '=') { /* 脱括号 */
                        Pop(OPTR, theta);   /* 弹出 '(' */
                        i++;
                    }
                    else if (theta == '>') { /* 栈顶优先级高，退栈计算 */
                        Pop(OPTR, theta);   /* 弹出运算符 */
                        Pop(OPND, b);       /* 弹出操作数 b */
                        Pop(OPND, a);       /* 弹出操作数 a */
                        Push(OPND, Operate(a, theta, b)); /* 结果入栈 */
                        /* 不移动 i，重新比较 */
                    }
                    else {                 /* 非法组合 */
                        return 0;
                    }
                    break;
            }
        }
    }

    return GetTop(OPND);                   /* 栈顶即为最终结果 */
}
```

**示例计算过程**：求表达式 `3*(7-2)` 的值

| 步骤 | 当前字符 | OPTR 栈（底→顶） | OPND 栈（底→顶） | 动作 |
|------|---------|-------------------|-------------------|------|
| 1 | 3 | `#` | 空 | 数字入 OPND |
| 2 | `*` | `#` | `3` | `# < *`，`*` 入 OPTR |
| 3 | `(` | `# *` | `3` | `* < (`，`(` 入 OPTR |
| 4 | 7 | `# * (` | `3` | 数字入 OPND |
| 5 | `-` | `# * (` | `3 7` | `(< -`，`-` 入 OPTR |
| 6 | 2 | `# * ( -` | `3 7` | 数字入 OPND |
| 7 | `)` | `# * ( -` | `3 7 2` | `- )` 为 `>`，计算 7-2=5，OPND: 3 5；`(-)` 为 `=`，脱括号 |
| 8 | `)` 处理完 | `# *` | `3 5` | `* )` 为 `>`，但 `)` 不是运算符字符，实际由脱括号后继续比较 |
| 9 | `#` | `# *` | `3 5` | `* #` 为 `>`，计算 3×5=15，OPND: 15 |
| 10 | `#` | `#` | `15` | `# #` 为 `=`，算法结束 |

**结果**：`3 * (7 - 2) = 15` ✅

> **注意**：上述代码为简化实现，操作数仅支持单数字。完整实现需要处理多位数和负数。

### 三、队列的基本操作

#### 3.1 循环队列的定义

```c
/* ==================== 循环队列的定义 ==================== */
#define MAXQSIZE 100          /* 最大队列长度 */

typedef int QElemType;         /* 队列元素类型 */

/* 循环队列结构 */
typedef struct {
    QElemType *base;             /* 初始化的动态分配存储空间 */
    int front;                   /* 头指针，若队列不空，指向队头元素 */
    int rear;                    /* 尾指针，若队列不空，指向队尾元素的下一个位置 */
} SqQueue;
```

**核心概念**：

- 利用**模运算**（`%`）实现逻辑上的"循环"效果。
- 为区分队空和队满，通常**牺牲一个存储单元**，即：队空条件为 `front == rear`，队满条件为 `(rear + 1) % MAXQSIZE == front`。

---

#### 3.2 初始化队列 `InitQueue`

```c
/* ==================== 初始化循环队列 ==================== */
Status InitQueue(SqQueue &Q) {
    Q.base = (QElemType *)malloc(MAXQSIZE * sizeof(QElemType));
    if (!Q.base) return ERROR;           /* 存储分配失败 */
    Q.front = 0;                         /* 头指针 */
    Q.rear = 0;                          /* 尾指针 */
    return OK;
}
```

---

#### 3.3 入队 `EnQueue`

```c
/* ==================== 循环队列入队 ==================== */
Status EnQueue(SqQueue &Q, QElemType e) {
    /* 判断队列是否已满 */
    if ((Q.rear + 1) % MAXQSIZE == Q.front)
        return ERROR;                    /* 队列满 */
    Q.base[Q.rear] = e;                  /* 新元素插入队尾 */
    Q.rear = (Q.rear + 1) % MAXQSIZE;    /* 队尾指针后移 */
    return OK;
}
```

---

#### 3.4 出队 `DeQueue`

```c
/* ==================== 循环队列出队 ==================== */
Status DeQueue(SqQueue &Q, QElemType &e) {
    if (Q.front == Q.rear) return ERROR; /* 队列空 */
    e = Q.base[Q.front];                 /* 取队头元素 */
    Q.front = (Q.front + 1) % MAXQSIZE;  /* 头指针后移 */
    return OK;
}
```

---

#### 3.5 取队头元素 `GetHead`

```c
/* ==================== 取循环队列队头元素 ==================== */
QElemType GetHead(SqQueue Q) {
    if (Q.front != Q.rear)             /* 队列不空 */
        return Q.base[Q.front];
    return '\0';                         /* 返回错误标志 */
}
```

---

#### 3.6 队列遍历

```c
/* ==================== 遍历循环队列 ==================== */
Status QueueTraverse(SqQueue Q) {
    if (Q.front == Q.rear) return ERROR; /* 队列空 */
    int i = Q.front;
    printf("队列元素（队头→队尾）：");
    while (i != Q.rear) {
        printf("%d ", Q.base[i]);
        i = (i + 1) % MAXQSIZE;
    }
    printf("\n");
    return OK;
}
```

### 四、链队列

#### 4.1 链队列的定义

```c
/* ==================== 链队列结点定义 ==================== */
typedef struct QNode {
    QElemType data;
    struct QNode *next;
} QNode, *QueuePtr;

/* ==================== 链队列结构 ==================== */
typedef struct {
    QueuePtr front;                    /* 队头指针 */
    QueuePtr rear;                     /* 队尾指针 */
} LinkQueue;
```

> 链队列通常设置**头指针 `front` 和尾指针 `rear`**，`front` 指向队头结点（或头结点），`rear` 指向队尾结点。

---

#### 4.2 链队列初始化

```c
/* ==================== 初始化链队列 ==================== */
Status InitQueue(LinkQueue &Q) {
    /* 构造一个带头结点的空队列，头结点既作为队头也作为队尾 */
    Q.front = Q.rear = (QueuePtr)malloc(sizeof(QNode));
    if (!Q.front) return ERROR;
    Q.front->next = NULL;
    return OK;
}
```

---

#### 4.3 链队列入队

```c
/* ==================== 链队列入队 ==================== */
Status EnQueue(LinkQueue &Q, QElemType e) {
    QueuePtr p = (QueuePtr)malloc(sizeof(QNode));
    if (!p) return ERROR;
    p->data = e;
    p->next = NULL;
    Q.rear->next = p;                  /* 新结点接入队尾 */
    Q.rear = p;                        /* 队尾指针指向新结点 */
    return OK;
}
```

---

#### 4.4 链队列出队

```c
/* ==================== 链队列出队 ==================== */
Status DeQueue(LinkQueue &Q, QElemType &e) {
    if (Q.front == Q.rear) return ERROR; /* 队列空 */
    QueuePtr p = Q.front->next;        /* p 指向队头结点 */
    e = p->data;                       /* 取队头元素 */
    Q.front->next = p->next;           /* 队头结点出链 */
    if (Q.rear == p) {                 /* 队列只有一个结点时 */
        Q.rear = Q.front;              /* 队尾指针回到头结点 */
    }
    free(p);                           /* 释放原队头结点 */
    return OK;
}
```

### 五、循环队列判空 / 判满详解 ⚠️

这是 408 考试中极其经典的辨析题。

#### 5.1 两种判空判满方式对比

| 方式 | 判空条件 | 判满条件 | 可用存储单元数 | 优缺点 |
|------|---------|---------|--------------|--------|
| **牺牲一个单元** | `front == rear` | `(rear + 1) % M == front` | M-1 | 简单，不需要计数器 |
| **增加计数变量** | `front == rear` && `count == 0` | `count == M` | M | 空间利用率高 |
| **增加标志位** | `front == rear` && `tag == 0` | `front == rear` && `tag == 1` | M | 需额外 flag 变量 |

#### 5.2 方式一：牺牲一个单元（最常用）

```c
/* 牺牲一个存储单元的方式 */
#define M MAXQSIZE

/* 队空 */
#define QueueEmpty(Q) ((Q).front == (Q).rear)

/* 队满 */
#define QueueFull(Q) (((Q).rear + 1) % M == (Q).front)

/* 队列长度 */
#define QueueLength(Q) ((Q).rear - (Q).front + M) % M
```

**为什么 `rear == front` 不能直接区分队空和队满？**

入队时 `rear` 递增，出队时 `front` 递增。在循环结构中，当 `rear` 绕一圈追上 `front` 时，既可能是队空（所有元素都已出队），也可能是队满（`rear` 多绕了一圈追上 `front`）。因此需要额外手段区分。

#### 5.3 方式二：增加计数器

```c
typedef struct {
    QElemType *base;
    int front;
    int rear;
    int count;                         /* 增加计数器 */
    int size;                          /* 队列总容量 */
} SqQueue2;

/* 队空：front == rear 且 count == 0 */
/* 队满：count == size */
```

#### 5.4 方式三：增加标志位

```c
typedef struct {
    QElemType *base;
    int front;
    int rear;
    int tag;                           /* 入队成功 tag=1，出队成功 tag=0 */
} SqQueue3;

/* 队空：front == rear 且 tag == 0 */
/* 队满：front == rear 且 tag == 1 */
```

## ⚖️易混淆对比

### 6.1 顺序栈 vs 链栈

| 对比项 | 顺序栈 | 链栈 |
|--------|--------|------|
| 存储方式 | 连续内存（数组） | 离散内存（链表） |
| 判满 | `top - base >= stacksize` | 内存耗尽为止 |
| 判空 | `top == base` | `top == NULL` |
| 扩容 | `realloc`，有开销 | 自然扩展 |
| 存取速度 | 支持随机访问 | 仅可顺序访问 |
| 适用场景 | 栈大小可预估 | 栈大小不可预估 |
| 空间效率 | 有闲置空间 | 有结点指针开销 |

### 6.2 顺序队列 vs 循环队列 vs 链队列

| 对比项 | 顺序队列 | 循环队列 | 链队列 |
|--------|---------|---------|--------|
| 判空 | `front == rear` | `front == rear` | `front == rear` |
| 判满 | `rear == MAXSIZE` | `(rear+1)%M == front` | 内存耗尽 |
| 空间利用 | 队头元素出队后空间无法再利用 | 环形利用，效率高 | 动态分配 |
| 入队 | 尾插，可能越界 | 尾插，取模循环 | 尾部插入，无越界 |
| 出队 | 头删，O(n)（数组前移） | 头删，取模 O(1) | 头删，O(1) |
| 空间浪费 | 严重（假溢出） | 牺牲一个单元 | 几乎无浪费 |

### 6.3 递归 vs 非递归（以斐波那契为例）

```c
/* ==================== 递归版斐波那契（低效） ==================== */
/* F(0) = 0, F(1) = 1, F(n) = F(n-1) + F(n-2) */
int Fibonacci_Recursive(int n) {
    if (n <= 0) return 0;
    if (n == 1) return 1;
    return Fibonacci_Recursive(n - 1) + Fibonacci_Recursive(n - 2);
}

/* ==================== 非递归版斐波那契（高效） ==================== */
int Fibonacci_Iterative(int n) {
    if (n <= 0) return 0;
    if (n == 1) return 1;
    int a = 0, b = 1, c;
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return b;
}
```

| 对比项 | 递归版 | 非递归版 |
|--------|--------|---------|
| 时间复杂度 | $O(2^n)$ | $O(n)$ |
| 空间复杂度 | $O(n)$ 递归栈 | $O(1)$ |
| 可读性 | 简洁直观 | 需手动维护状态 |
| 栈溢出风险 | 存在 | 无 |

## 🔗知识链路总结

```
线性表（顺序表 / 链表）
       ↓  操作受限 → 栈
       ├─ 顺序栈：数组 + 指针操作
       ├─ 链栈：链表头插/头删
       ├─ 应用：括号匹配、表达式求值、递归实现、逆序输出
       ↓
       ├─ 操作受限 → 队列
       ├─ 循环队列：模运算实现环形存储
       ├─ 链队列：带头结点的单链表
       ├─ 应用：BFS、缓冲区、时间片轮转调度
       ↓
       └─ 树与二叉树（递归天然依赖调用栈）
```

**核心记忆口诀**：

- **栈**："后进先出"，像弹夹装子弹——最后装的先打出；括号匹配、表达式求值、递归实现。
- **队列**："先进先出"，像排队买票——先来先服务；BFS 搜索、消息队列。
- **循环队列**：牺牲一个单元区分满空，模运算实现环形，"绕圈圈"。
- **递归与栈**：递归的本质就是系统隐式维护一个调用栈，每层递归调用压栈，返回时弹栈。
