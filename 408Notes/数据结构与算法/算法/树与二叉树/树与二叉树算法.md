## 一、二叉树基本算法

### 1.1 二叉树存储结构定义

```c
/* ===== 二叉树的二叉链表存储结构 ===== */
typedef struct BiTNode {
    ElemType data;                    /* 结点数据域 */
    struct BiTNode *lchild, *rchild;  /* 左、右孩子指针 */
} BiTNode, *BiTree;

/* ===== 线索二叉树的存储结构（含线索标志） ===== */
typedef enum { Link, Thread } PointerTag;
/* Link = 0：指向孩子；Thread = 1：指向前驱或后继 */

typedef struct ThBiTNode {
    ElemType data;
    struct ThBiTNode *lchild, *rchild;
    PointerTag LTag;      /* 左标志：Link 或 Thread */
    PointerTag RTag;      /* 右标志：Link 或 Thread */
} ThBiTNode, *ThBiTree;
```

**💡 要点提示**：`BiTNode` 是二叉链表结点，`BiTree` 是指向该结点的指针（即二叉树的根指针）。线索化时需额外增设 `LTag`、`RTag` 两个标志域，以区分指针是指向孩子还是线索。

### 1.2 CreateBiTree — 按前序序列创建二叉树（递归）⭐🔥

> **算法思想**：从键盘按前序序列输入结点值。若输入为 `#`（表示空树），则令相应指针为空；否则，生成根结点，递归创建左子树，再递归创建右子树。

```c
/* 全局变量：输入字符缓冲区 */
char Ch;

/* 按前序序列创建二叉树（递归） */
/* 输入规则：若结点不存在，输入 '#' */
Status CreateBiTree(BiTree *T) {
    scanf("%c", &Ch);
    if (Ch == '#') {
        *T = NULL;
    } else {
        *T = (BiTree)malloc(sizeof(BiTNode));
        if (!*T) exit(OVERFLOW);
        (*T)->data = Ch;                          /* 生成根结点 */
        CreateBiTree(&(*T)->lchild);              /* 递归创建左子树 */
        CreateBiTree(&(*T)->rchild);              /* 递归创建右子树 */
    }
    return OK;
}
```

**📌 示例**：对于下图二叉树，前序序列为 `ABD##E##CF###`

```
        A
       / \
      B   C
     / \   \
    D   E   F
```

### 1.3 DestroyBiTree — 销毁二叉树

```c
/* 销毁二叉树 */
void DestroyBiTree(BiTree *T) {
    if (*T == NULL) return;
    else {
        DestroyBiTree(&(*T)->lchild);   /* 递归销毁左子树 */
        DestroyBiTree(&(*T)->rchild);   /* 递归销毁右子树 */
        free(*T);                       /* 释放根结点 */
        *T = NULL;                      /* 空指针赋 0 */
    }
}
```

**⚠️ 注意**：销毁二叉树必须采用**后序**遍历的思想——先销毁左右子树，再销毁根结点。若先释放根结点，将无法访问其子树。

### 1.4 遍历算法（递归 + 非递归）⭐🔥

> 遍历是二叉树最核心的算法操作。**递归遍历**代码简洁，**非递归遍历**借助 `[[数据结构与算法/笔记/栈和队列|栈/队列]]` 实现，是面试高频考点。

#### （1）前序遍历 PreOrderTraverse — 递归

```c
/* 前序遍历二叉树的递归算法 */
Status (*VisitFunc)(ElemType e);  /* 函数变量：访问结点的函数 */

void PreOrderTraverse(BiTree T, Status (*Visit)(ElemType e)) {
    if (T == NULL) return;
    Visit(T->data);                          /* 访问根结点 */
    PreOrderTraverse(T->lchild, Visit);      /* 前序遍历左子树 */
    PreOrderTraverse(T->rchild, Visit);      /* 前序遍历右子树 */
}
```

#### （2）前序遍历 PreOrderTraverse — 非递归（栈实现）⭐🔥

```c
/* 前序遍历二叉树的非递归算法（使用栈） */
void PreOrderTraverse_NonRecursive(BiTree T, Status (*Visit)(ElemType e)) {
    InitStack(S);                            /* 初始化栈 */
    Push(S, T);                              /* 根结点入栈 */
    while (!StackEmpty(S)) {
        while (GetTop(S, p) && p) {          /* 沿左子树一路入栈并访问 */
            Visit(p->data);
            Push(S, p->lchild);
        }
        Pop(S, p);                           /* 空指针出栈 */
        if (!StackEmpty(S)) {
            Pop(S, p);                       /* 弹出当前结点 */
            Push(S, p->rchild);              /* 右子树入栈，下次循环处理 */
        }
    }
}
```

**🔥 更简洁的写法（推荐，考试常用）**：

```c
/* 前序遍历二叉树的非递归算法——简洁写法 */
void PreOrder_NonRecur(BiTree T, Status (*Visit)(ElemType e)) {
    InitStack(S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            Visit(p->data);                  /* 访问结点 */
            Push(S, p);                      /* 入栈 */
            p = p->lchild;                   /* 深入左子树 */
        } else {
            Pop(S, p);                       /* 弹出栈顶 */
            p = p->rchild;                   /* 转向右子树 */
        }
    }
}
```

**📌 非递归遍历核心思路总结**：

| 遍历顺序 | 访问时机 | 入栈时机 |
|---------|---------|---------|
| 前序 | 节点进栈时访问 | 向左深入时进栈 |
| 中序 | 节点回退（出栈）时访问 | 向左深入时进栈 |
| 后序 | 节点第二次弹出时访问 | 需要标记是否已访问 |

#### （3）中序遍历 InOrderTraverse — 递归

```c
/* 中序遍历二叉树的递归算法 */
void InOrderTraverse(BiTree T, Status (*Visit)(ElemType e)) {
    if (T == NULL) return;
    InOrderTraverse(T->lchild, Visit);       /* 中序遍历左子树 */
    Visit(T->data);                          /* 访问根结点 */
    InOrderTraverse(T->rchild, Visit);       /* 中序遍历右子树 */
}
```

#### （4）中序遍历非递归 InOrderTraverse_NonRecursive — 栈实现 ⭐🔥

```c
/* 中序遍历二叉树的非递归算法（栈实现）——最经典考题之一 */
void InOrderTraverse_NonRecursive(BiTree T, Status (*Visit)(ElemType e)) {
    InitStack(S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            Push(S, p);                      /* 当前结点入栈 */
            p = p->lchild;                   /* 深入左子树 */
        } else {
            Pop(S, p);                       /* 弹出栈顶 */
            Visit(p->data);                  /* 访问该结点 */
            p = p->rchild;                   /* 转向右子树 */
        }
    }
}
```

**🔥 记忆口诀**：**"一路左，弹出访，再右走"**

#### （5）后序遍历 PostOrderTraverse — 递归

```c
/* 后序遍历二叉树的递归算法 */
void PostOrderTraverse(BiTree T, Status (*Visit)(ElemType e)) {
    if (T == NULL) return;
    PostOrderTraverse(T->lchild, Visit);     /* 后序遍历左子树 */
    PostOrderTraverse(T->rchild, Visit);     /* 后序遍历右子树 */
    Visit(T->data);                          /* 访问根结点 */
}
```

#### （6）后序遍历非递归（双栈法 / 单栈+标记法）

```c
/* 后序遍历非递归算法——单栈+标记法（考试推荐） */
/* 需要一个标志位来标记结点是否已被访问过 */
typedef struct {
    BiTree ptr;
    int flag;    /* 0: 左子树未访问, 1: 右子树未访问, 2: 已访问 */
} SElemType;

void PostOrder_NonRecur(BiTree T, Status (*Visit)(ElemType e)) {
    InitStack(S);
    BiTree p = T;
    SElemType se;
    while (p || !StackEmpty(S)) {
        if (p) {
            se.ptr = p;
            se.flag = 0;
            Push(S, se);
            p = p->lchild;
        } else {
            Pop(S, se);
            p = se.ptr;
            if (se.flag == 0) {
                se.flag = 1;
                Push(S, se);
                p = p->rchild;
            } else {
                Visit(p->data);
                p = NULL;    /* 置空，避免重新入栈 */
            }
        }
    }
}
```

### 1.5 层序遍历 LevelOrderTraverse（队列实现）⭐

> 层序遍历需要借助 `[[数据结构与算法/笔记/栈和队列|队列]]`。从根结点开始，依次将左右孩子入队，出队时访问。

```c
/* 层序遍历二叉树（队列实现）*/
void LevelOrderTraverse(BiTree T, Status (*Visit)(ElemType e)) {
    InitQueue(Q);                            /* 初始化队列 */
    if (T) EnQueue(Q, T);                    /* 根结点入队 */
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);                       /* 队头元素出队 */
        Visit(p->data);                      /* 访问该结点 */
        if (p->lchild != NULL)
            EnQueue(Q, p->lchild);           /* 左孩子入队 */
        if (p->rchild != NULL)
            EnQueue(Q, p->rchild);           /* 右孩子入队 */
    }
}
```

**📌 示例**：对于下面这棵二叉树，层序序列为 `ABDECF`

```
        A          →  第1层: A
       / \          →  第2层: B  C
      B   C         →  第3层: D  E    F
     / \   \
    D   E   F
```

## 二、二叉树性质相关算法

### 2.1 TreeDepth — 求二叉树深度（递归）⭐

> **递归定义**：二叉树的深度 = max(左子树深度, 右子树深度) + 1

```c
/* 求二叉树的深度（递归）*/
int TreeDepth(BiTree T) {
    if (T == NULL) return 0;                /* 空树深度为 0 */
    else {
        int hl = TreeDepth(T->lchild);      /* 求左子树深度 */
        int hr = TreeDepth(T->rchild);      /* 求右子树深度 */
        return (hl > hr ? hl : hr) + 1;     /* 取较大者 + 1 */
    }
}
```

---

### 2.2 CountLeaf — 统计叶子结点数

> **递归定义**：叶子结点 = 左孩子为空且右孩子为空的结点

```c
/* 统计二叉树中叶子结点的个数 */
int CountLeaf(BiTree T) {
    if (T == NULL) return 0;
    if (T->lchild == NULL && T->rchild == NULL)
        return 1;                            /* 叶子结点 */
    return CountLeaf(T->lchild) + CountLeaf(T->rchild);  /* 累加左右子树的叶子数 */
}
```

---

### 2.3 CountNode — 统计总结点数

```c
/* 统计二叉树中结点的总数 */
int CountNode(BiTree T) {
    if (T == NULL) return 0;
    return 1 + CountNode(T->lchild) + CountNode(T->rchild);
}
```

**💡 等价写法**：总结点数 = 前序遍历中访问的结点数。也可以在中序/后序遍历中设置全局计数器实现。

---

### 2.4 CountDegree1 — 统计度为 1 的结点数

```c
/* 统计二叉树中度为 1 的结点个数 */
int CountDegree1(BiTree T) {
    if (T == NULL) return 0;
    /* 度为1: 只有左孩子 或 只有右孩子 */
    if ((T->lchild == NULL && T->rchild != NULL) ||
        (T->lchild != NULL && T->rchild == NULL))
        return 1 + CountDegree1(T->lchild) + CountDegree1(T->rchild);
    return CountDegree1(T->lchild) + CountDegree1(T->rchild);
}
```

## 三、已知遍历序列构建二叉树

### 3.1 由前序和中序构建二叉树 ⭐🔥

> **核心原理**：
> - **前序序列**的第一个元素是根结点
> - 在中序序列中找到根结点，其左侧为左子树的中序序列，右侧为右子树的中序序列
> - 根据左右子树的结点个数，在前序序列中划分出左右子树的前序序列
> - 递归地对左右子树执行相同操作

```c
/* 全局变量：前序序列数组 */
ElemType PreOrderArr[];

/* 在 inorder[low..high] 中查找元素 e 的位置 */
int Find(ElemType e, ElemType inorder[], int low, int high) {
    for (int i = low; i <= high; i++) {
        if (inorder[i] == e) return i;
    }
    return -1;                             /* 未找到 */
}

/* 由前序序列 pre[pre_low..pre_high] 和中序序列 in[in_low..in_high] 构建二叉树 */
BiTree PreInBuild(ElemType pre[], int pre_low, int pre_high,
                  ElemType in[], int in_low, int in_high) {
    if (pre_low > pre_high) return NULL;    /* 递归终止条件 */

    BiTree T = (BiTree)malloc(sizeof(BiTNode));
    if (!T) exit(OVERFLOW);
    T->data = pre[pre_low];                /* 前序第一个元素是根结点 */

    /* 在中序序列中查找根结点位置 */
    int k = Find(pre[pre_low], in, in_low, in_high);
    if (k == -1) return NULL;              /* 非法输入 */

    /* 左子树结点个数 */
    int leftLen = k - in_low;

    /* 递归构建左子树：
     * 前序区间: [pre_low+1, pre_low+leftLen]
     * 中序区间: [in_low, k-1]
     */
    T->lchild = PreInBuild(pre, pre_low + 1, pre_low + leftLen,
                           in, in_low, k - 1);

    /* 递归构建右子树：
     * 前序区间: [pre_low+leftLen+1, pre_high]
     * 中序区间: [k+1, in_high]
     */
    T->rchild = PreInBuild(pre, pre_low + leftLen + 1, pre_high,
                           in, k + 1, in_high);

    return T;
}

/* 主调用接口 */
BiTree CreateBiTree_ByPreIn(ElemType pre[], ElemType in[], int n) {
    if (n <= 0) return NULL;
    return PreInBuild(pre, 0, n - 1, in, 0, n - 1);
}
```

**📌 示例**：

```
前序: A B D E C F
中序: D B E A C F

步骤：
1) 前序首元素 'A' 为根，在中序中找到 A，左侧 D B E 为左子树，右侧 C F 为右子树
2) 左子树：前序[B D E]，中序[D B E] → 根为 B，左侧 D 为左子，右侧 E 为右子
3) 右子树：前序[C F]，中序[C F] → 根为 C，无左子，F 为右子
```

**🔥 考点提示**：只有 **前序+中序** 或 **后序+中序** 可以唯一确定一棵二叉树。仅有前序+后序不能唯一确定（除非二叉树中每个结点度数都是 0 或 2）。

### 3.2 由后序和中序构建二叉树（递归）⭐

> **核心原理**：
> - **后序序列**的最后一个元素是根结点
> - 在中序序列中找到根结点，其左侧为左子树的中序序列，右侧为右子树的中序序列

```c
/* 全局变量：后序序列数组 */
ElemType PostOrderArr[];

/* 由后序序列 post[post_low..post_high] 和中序序列 in[in_low..in_high] 构建二叉树 */
BiTree PostInBuild(ElemType post[], int post_low, int post_high,
                   ElemType in[], int in_low, int in_high) {
    if (post_low > post_high) return NULL;   /* 递归终止条件 */

    BiTree T = (BiTree)malloc(sizeof(BiTNode));
    if (!T) exit(OVERFLOW);
    T->data = post[post_high];              /* 后序最后一个元素是根结点 */

    /* 在中序序列中查找根结点位置 */
    int k = Find(post[post_high], in, in_low, in_high);
    if (k == -1) return NULL;

    /* 左子树结点个数 */
    int leftLen = k - in_low;

    /* 递归构建左子树：
     * 后序区间: [post_low, post_low + leftLen - 1]
     * 中序区间: [in_low, k-1]
     */
    T->lchild = PostInBuild(post, post_low, post_low + leftLen - 1,
                            in, in_low, k - 1);

    /* 递归构建右子树：
     * 后序区间: [post_low + leftLen, post_high - 1]
     * 中序区间: [k+1, in_high]
     */
    T->rchild = PostInBuild(post, post_low + leftLen, post_high - 1,
                            in, k + 1, in_high);

    return T;
}

/* 主调用接口 */
BiTree CreateBiTree_ByPostIn(ElemType post[], ElemType in[], int n) {
    if (n <= 0) return NULL;
    return PostInBuild(post, 0, n - 1, in, 0, n - 1);
}
```

## 四、线索二叉树算法

### 4.1 中序线索化 InThreading ⭐

> **线索化思想**：遍历二叉树，将结点的前驱和后继信息存入左、右指针域。若左孩子为空，则 `lchild` 指向前驱；若右孩子为空，则 `rchild` 指向后继。需要增设全局变量 `pre` 来记录当前访问结点的前驱。

```c
/* 全局变量：指向当前结点前驱的指针 */
ThBiTree pre;

/* 中序线索化（递归）：对以 T 为根的二叉树进行中序线索化 */
void InThreading(ThBiTree T) {
    if (T != NULL) {
        InThreading(T->lchild);            /* 左子树线索化 */

        /* 处理当前结点：建立前驱线索 */
        if (T->lchild == NULL) {
            T->lchild = pre;               /* 左孩子为空，指向前驱 */
            T->LTag = Thread;
        }
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = T;               /* 前驱的右孩子为空，指向后继 */
            pre->RTag = Thread;
        }
        pre = T;                            /* 更新 pre 为当前结点 */

        InThreading(T->rchild);            /* 右子树线索化 */
    }
}
```

### 4.2 InOrderThreading — 中序线索化主算法

```c
/* 中序线索化主算法 */
Status InOrderThreading(ThBiTree *Thrt, ThBiTree T) {
    /* Thrt 为头结点（线索二叉树的哨兵） */
    *Thrt = (ThBiTree)malloc(sizeof(ThBiTNode));
    if (!*Thrt) exit(OVERFLOW);

    (*Thrt)->LTag = Link;
    (*Thrt)->RTag = Thread;
    (*Thrt)->rchild = *Thrt;              /* 右指针回指自己（空树时） */

    if (T == NULL) {
        (*Thrt)->lchild = *Thrt;          /* 空树，左指针也回指自己 */
    } else {
        (*Thrt)->lchild = T;
        pre = *Thrt;
        InThreading(T);                    /* 调用线索化递归函数 */
        pre->rchild = *Thrt;              /* 处理最后一个结点：指向头结点 */
        pre->RTag = Thread;
        (*Thrt)->rchild = pre;            /* 头结点的 rchild 指向中序最后一个结点 */
    }
    return OK;
}
```

### 4.3 NextInThread — 在中序线索二叉树中找结点后继

```c
/* 在中序线索二叉树中，找结点 p 的中序后继 */
ThBiTree NextInThread(ThBiTree p) {
    if (p->RTag == Thread)
        return p->rchild;                  /* 右标志为 Thread，直接返回右线索 */
    else {
        /* 右标志为 Link，则后继 = 右子树中第一个中序遍历的结点（最左下结点）*/
        ThBiTree q = p->rchild;
        while (q->LTag == Link)
            q = q->lchild;
        return q;
    }
}
```

### 4.4 PreInThread — 在中序线索二叉树中找结点前驱

```c
/* 在中序线索二叉树中，找结点 p 的中序前驱 */
ThBiTree PrevInThread(ThBiTree p) {
    if (p->LTag == Thread)
        return p->lchild;                  /* 左标志为 Thread，直接返回左线索 */
    else {
        /* 左标志为 Link，则前驱 = 左子树中最后一个中序遍历的结点（最右下结点）*/
        ThBiTree q = p->lchild;
        while (q->RTag == Link)
            q = q->rchild;
        return q;
    }
}
```

### 4.5 遍历中序线索二叉树（非递归，无需栈）⭐

```c
/* 遍历中序线索二叉树（从第一个结点开始，依次遍历至头结点） */
void InOrder_Traverse_ThTree(ThBiTree Thrt) {
    if (Thrt == NULL) return;

    ThBiTree p = Thrt->lchild;            /* p 指向根结点 */
    while (p != Thrt) {                   /* 循环条件：p 不回到头结点 */
        while (p->LTag == Link)           /* 找到中序第一个结点（最左下）*/
            p = p->lchild;

        Visit(p->data);                   /* 访问该结点 */

        /* 通过后继线索继续遍历 */
        while (p->RTag == Thread && p->rchild != Thrt) {
            p = p->rchild;
            Visit(p->data);
        }
        p = p->rchild;                    /* 转向右子树 */
    }
}
```

**💡 线索二叉树的核心优势**：遍历操作无需栈（空间 O(1)），利用已有空指针域存储前驱/后继信息。

## 五、树与森林相关算法

### 5.1 孩子兄弟表示法的树结构定义

> 树采用"**左孩子·右兄弟**"表示法，将任意一棵树转换为二叉树：每个结点的第一个孩子作为左孩子，下一个兄弟作为右孩子。

### 5.2 树的孩子兄弟表示创建

```c

    scanf("%c", &Ch);
    if (Ch == '#') {
        *T = NULL;
    } else {
        *T = (CSTree)malloc(sizeof(CSNode));
        if (!*T) exit(OVERFLOW);
        (*T)->data = Ch;
        CreateCSTree(&(*T)->firstchild);  /* 创建第一个孩子 */
        CreateCSTree(&(*T)->nextsibling); /* 创建下一个兄弟 */
    }
    return OK;
}
```

### 5.3 树的先根遍历与后根遍历

```c
/* ===== 树的先根遍历（递归）======
 * 先访问根结点，再依次先根遍历每棵子树
 * 转换为二叉树后 = 先序遍历
 */
void PreOrder_Tree(CSTree T) {
    if (T == NULL) return;
    Visit(T->data);                       /* 访问根结点 */
    if (T->firstchild != NULL)
        PreOrder_Tree(T->firstchild);     /* 先根遍历第一棵子树 */

    /* 注意：这里不能直接遍历右子树（兄弟），因为先根遍历只涉及根+子树 */
    /* 实际上，先根遍历在二叉树等价形式中就是先序遍历，需要递归所有子树 */
    CSTree p = T->firstchild;
    while (p != NULL) {
        CSTree next = p->nextsibling;     /* 保存下一个兄弟 */
        PreOrder_Tree(p);                 /* 先根遍历该子树 */
        p = next;
    }
}

/* ===== 树的后根遍历（递归）======
 * 先依次后根遍历每棵子树，再访问根结点
 * 转换为二叉树后 = 中序遍历
 */
void PostOrder_Tree(CSTree T) {
    if (T == NULL) return;
    CSTree p = T->firstchild;
    while (p != NULL) {
        CSTree next = p->nextsibling;
        PostOrder_Tree(p);                /* 后根遍历该子树 */
        p = next;
    }
    Visit(T->data);                       /* 访问根结点 */
}
```

**📌 树 ↔ 二叉树的遍历对应关系**：

| 操作 | 树的遍历 | 对应二叉树遍历 |
|-----|---------|--------------|
| 先根遍历 | 先访问根，再子树 | 先序遍历 |
| 后根遍历 | 先子树，再访问根 | 中序遍历 |

## 六、哈夫曼树与哈夫曼编码算法 ⭐🔥🔥

### 6.1 哈夫曼树存储结构

```c
/* ===== 哈夫曼树存储结构 ===== */
typedef struct {
    int weight;             /* 权值 */
    int parent, lchild, rchild; /* 双亲、左孩子、右孩子下标 */
} HTNode, *HuffmanTree;

typedef char **HuffmanCode;   /* 动态分配数组，存储哈夫曼编码 */
```

### 6.2 Select — 从数组中选择两个最小权值的结点

> **核心作用**：在构造哈夫曼树的过程中，每次从未选中的结点中选出权值最小的两个结点合并。

```c
/* 在 HT[1..end] 中选取 parent 为 0 且 weight 最小的两个结点，
 * 其下标存入 s1（最小）和 s2（次小） */
void Select(HuffmanTree HT, int end, int *s1, int *s2) {
    int min1 = MAXINT, min2 = MAXINT;   /* MAXINT 为 32767 或 INT_MAX */
    *s1 = 0;
    *s2 = 0;

    for (int i = 1; i <= end; i++) {
        if (HT[i].parent == 0) {         /* 只考虑未选中的结点 */
            if (HT[i].weight < min1) {
                min2 = min1;             /* 原最小值变为次小值 */
                *s2 = *s1;
                min1 = HT[i].weight;     /* 更新最小值 */
                *s1 = i;
            } else if (HT[i].weight < min2) {
                min2 = HT[i].weight;
                *s2 = i;
            }
        }
    }
}
```

**💡 优化说明**：上述线性扫描法每次 Select 的时间为 O(n)，构造整棵哈夫曼树的时间为 O(n²)。若使用**最小堆**维护，则每次 Select 降为 O(log n)，总时间降为 O(n log n)。

### 6.3 CreateHuffmanTree — 构造哈夫曼树 ⭐🔥

```c
/* 构造哈夫曼树 HT[n]，w[] 存放 n 个权值 */
/* n 个叶子结点最终哈夫曼树共有 2n-1 个结点 */
Status CreateHuffmanTree(HuffmanTree *HT, int n) {
    if (n <= 0) return ERROR;
    int m = 2 * n - 1;                  /* 总结点数 */
    *HT = (HuffmanTree)malloc((m + 1) * sizeof(HTNode));  /* 0 号单元不用 */

    /* 1. 初始化 n 个叶子结点 */
    for (int i = 1; i <= n; i++) {
        (*HT)[i].weight = /* 从 w 数组读取 */;
        (*HT)[i].parent = 0;
        (*HT)[i].lchild = 0;
        (*HT)[i].rchild = 0;
    }

    /* 2. 初始化其余 m-n 个非叶子结点 */
    for (int i = n + 1; i <= m; i++) {
        (*HT)[i].weight = 0;
        (*HT)[i].parent = 0;
        (*HT)[i].lchild = 0;
        (*HT)[i].rchild = 0;
    }

    /* 3. 构建哈夫曼树的核心循环 */
    for (int i = n + 1; i <= m; i++) {
        int s1, s2;
        Select(*HT, i - 1, &s1, &s2);   /* 在 [1..i-1] 中选两个最小 */
        (*HT)[i].weight = (*HT)[s1].weight + (*HT)[s2].weight;  /* 新结点权值 */
        (*HT)[i].lchild = s1;            /* 左孩子为较小权值 */
        (*HT)[i].rchild = s2;            /* 右孩子为较大权值 */
        (*HT)[s1].parent = i;            /* 更新双亲 */
        (*HT)[s2].parent = i;
    }
    return OK;
}
```

**🔥 构造过程示例**：

```
权值集合: {5, 7, 2, 13}

第1步：选 {2, 5} → 合并为 7，集合变为 {7, 7, 13}
第2步：选 {7, 7} → 合并为 14，集合变为 {13, 14}
第3步：选 {13, 14} → 合并为 27，得到哈夫曼树

        27
       /  \
     13    14
         /  \
        7    14(由{7,5}合并)
            /  \
           7    5

带权路径长度 WPL = 13×1 + 7×2 + 5×3 + 7×3 = 13+14+15+21 = 63
```

### 6.4 CreateHuffmanCode — 构造哈夫曼编码 ⭐🔥

```c
/* 从叶子结点到根结点逆向求每个叶子结点的哈夫曼编码 */
Status CreateHuffmanCode(HuffmanCode *HC, HuffmanTree HT, int n) {
    *HC = (HuffmanCode)malloc((n + 1) * sizeof(char *));
    char *cd = (char *)malloc(n * sizeof(char));    /* 工作空间，存放编码 */
    cd[n - 1] = '\0';                               /* 编码结束符 */

    for (int i = 1; i <= n; i++) {
        int start = n - 1;                          /* 从编码末尾开始 */
        int c = i;
        int f = HT[i].parent;

        /* 从叶子向上回溯到根 */
        while (f != 0) {
            --start;
            if (HT[f].lchild == c)
                cd[start] = '0';                    /* 左分支编码为 0 */
            else
                cd[start] = '1';                    /* 右分支编码为 1 */
            c = f;
            f = HT[f].parent;
        }

        /* 将编码复制到 HC 中 */
        (*HC)[i] = (char *)malloc((n - start) * sizeof(char));
        strcpy((*HC)[i], &cd[start]);
    }

    free(cd);
    return OK;
}
```

**📌 编码规则**：左分支 = `0`，右分支 = `1`。从叶子结点向上回溯到根，依次记录路径上的 `0/1`，最后反转即为哈夫曼编码。


## 七、算法复杂度对比总结

### 7.1 遍历算法复杂度总表

| 算法 | 时间复杂度 | 空间复杂度 | 说明 |
|-----|-----------|-----------|------|
| 递归前序/中序/后序遍历 | O(n) | O(h)，h 为树深（栈帧） | 最坏 O(n)（单支树），最好 O(log n)（满二叉树） |
| 非递归前序/中序遍历 | O(n) | O(h)（栈大小） | h = 树高 |
| 非递归后序遍历 | O(n) | O(h) | 双栈法 O(h)，标记法 O(h) |
| 层序遍历 | O(n) | O(w)，w 为最大层宽 | 队列中最多存 w 个结点 |
| 求树深度 | O(n) | O(h) | 递归后序思想 |
| 统计结点数/叶子数 | O(n) | O(h) | 递归遍历一次 |

**📌 关键关系式**：
- 对任意二叉树：`n₀ = n₂ + 1`（叶子数 = 度为 2 的结点数 + 1）
- 满二叉树：`h = log₂(n+1)`
- 完全二叉树：`h = ⌊log₂n⌋ + 1`

### 7.2 哈夫曼树构造复杂度

| 操作 | 不用堆 | 用最小堆 |
|-----|--------|---------|
| 每次 Select | O(n) 线性扫描 | O(log n) 堆顶弹出 |
| 总构造时间 | **O(n²)** | **O(n log n)** |
| 构造编码 | O(n²)（每结点回溯 O(n)，共 n 个） | O(n log n)（编码长度 O(log n)） |

**🔥 考试重点**：不使用堆的哈夫曼树构造时间复杂度为 **O(n²)**；若用最小堆优化 Select 操作，则降为 **O(n log n)**。

### 7.3 已知两种序列建树的复杂度

| 构建方式 | 时间复杂度 | 说明 |
|---------|-----------|------|
| 前序+中序建树 | **O(n²)** | 每层需 O(n) 在中序中查找 |
| 后序+中序建树 | **O(n²)** | 同上 |
| 前序+后序建树 | ❌ 无法唯一确定 | 除非是严格二叉树 |

**💡 优化思路**：如果预处理中序序列建立 hash 映射（位置数组），可以将每次查找降为 O(1)，总时间复杂度降为 **O(n)**。但在 408 考试中，默认实现为 O(n²)。

## 八、易混淆对比

### 8.1 递归 vs 非递归遍历

| 对比项 | 递归实现 | 非递归实现 |
|--------|---------|-----------|
| 代码复杂度 | 简洁直观 | 较复杂，需显式管理栈/队列 |
| 空间开销 | 函数调用栈 | 显式栈/队列，开销相当 |
| 深度过大 | 栈溢出风险 | 可控（但同样占栈空间） |
| 面试要求 | 需掌握 | **必须掌握**（高频手撕代码题） |

### 8.2 线索二叉树 vs 普通二叉树

| 特性 | 普通二叉树 | 线索二叉树 |
|-----|-----------|-----------|
| 空间利用率 | 50% 指针域为空 | 利用空指针存储线索 |
| 遍历方式 | 递归/非递归均需栈 | 非递归、无需栈 |
| 修改 | 修改后线索失效 | 插入/删除需重新线索化 |
| 适用场景 | 通用 | 频繁遍历、不需要修改的场景 |

### 8.3 哈夫曼编码 vs 等长编码

| 特性 | 等长编码 | 哈夫曼编码 |
|-----|---------|-----------|
| 编码长度 | 固定 | 变长（频繁字符短编码） |
| 前缀性 | 可能冲突 | 前缀编码（唯一可译码） |
| 压缩率 | 无压缩 | 最佳压缩（最优前缀码） |
| 构造 | — | 贪心算法（从小到大合并） |
