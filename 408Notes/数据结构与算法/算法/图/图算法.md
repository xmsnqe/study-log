# 图算法

> 图（Graph）是数据结构中**最复杂、考查最全面**的章节。其算法涵盖存储结构、遍历、生成树、排序、最短路径与关键路径，是 408 统考的核心考点。本文系统梳理图的六大类算法，涵盖所有考研必考内容。

---

## 📍算法定位

图算法是数据结构课程的综合性内容，涉及以下知识链条：

| 算法大类 | 核心思想 | 关联知识点 | 考查频率 |
|---------|---------|-----------|---------|
| 存储结构 | 邻接矩阵 / 邻接表的定义与创建 | 数组、链表 | ★★ |
| 遍历算法 | DFS（深度优先）/ BFS（广度优先） | 栈、队列 | ⭐⭐⭐ |
| 最小生成树 | Prim / Kruskal | 贪心算法 | ⭐⭐⭐ |
| 拓扑排序 | 入度 + 栈/队列 | DAG、AOV网 | ⭐⭐⭐ |
| 最短路径 | Dijkstra / Floyd | 贪心/DP | ⭐⭐⭐ |
| 关键路径 | ve/vl/e/l 计算 | AOE网、关键路径法 | ★★ |

**考查定位**：图算法通常以选择题（概念与复杂度）和综合应用题（算法实现与分析）形式出现，是整份数据结构试卷中计算量最大的部分。

## 📝算法详解

### 一、图的存储结构

#### 1.1 邻接矩阵（Adjacency Matrix）

**核心思想**：用二维数组 `Arcs[MAX][MAX]` 存储顶点之间的边关系，`Arcs[i][j] = 1` 表示顶点 $V_i$ 到 $V_j$ 有边，`∞` 表示无边。

```
图示（无向图）：

       顶点:  A    B    C    D
       A  [  0 ,  1 ,  1 ,  0  ]
       B  [  1 ,  0 ,  0 ,  1  ]
       C  [  1 ,  0 ,  0 ,  1  ]
       D  [  0 ,  1 ,  1 ,  0  ]

       无向图邻接矩阵一定是对称矩阵！
       有向图则不一定对称。
```

**存储特点**：
- 适合**稠密图**（边数 $e \approx n^2$）
- 空间复杂度：$O(n^2)$，与边数无关
- 判断两顶点是否有边：$O(1)$
- 查找某顶点所有邻接点：$O(n)$

#### 1.2 邻接表（Adjacency List）

**核心思想**：对每个顶点建立一个单链表，链表中存储该顶点的所有邻接点。

```
图示：

       A ─→ B ─→ C ─→ ^
       B ─→ A ─→ D ─→ ^
       C ─→ A ─→ D ─→ ^
       D ─→ B ─→ C ─→ ^

       顶点表（顺序存储）     边表（链式存储）
```

### 算法 1：邻接表定义

```c
#define MAX_VERTEX_NUM 20   /* 最大顶点数 */

typedef char InfoType;

/* ==================== 邻接表定义 ==================== */

/* 边结点（链域） */
typedef struct ArcNode {
    int adjvex;               /* 该边所指向的顶点位置 */
    struct ArcNode *next;     /* 指向下一条边的指针 */
    InfoType *info;           /* 该边相关信息（如权值）的指针 */
} ArcNode;

/* 顶点结点（头结点） */
typedef struct VNode {
    VertexType data;          /* 顶点信息 */
    ArcNode *first;           /* 指向第一条依附该顶点的边 */
} VNode, AdjList[MAX_VERTEX_NUM];

/* 邻接表 */
typedef struct {
    AdjList vertices;         /* 邻接表头数组 */
    int vexnum, arcnum;       /* 图的当前顶点数和边数 */
    Kind kind;                /* 图的种类标志 */
} ALGraph;
```

### 算法 2：邻接表的创建（以无向图为例）

```c
/* 在邻接表中查找值为 v 的顶点在数组中的位置 */
int LocateVex(ALGraph *G, VertexType v) {
    for (int i = 0; i < G->vexnum; i++) {
        if (G->vertices[i].data == v) {
            return i;
        }
    }
    return -1;
}

/* ==================== 创建无向图邻接表 ==================== */
/* 思路：
 * 1. 输入顶点数和边数
 * 2. 依次输入顶点信息，初始化顶点表
 * 3. 依次输入边 (vi, vj)，在 vi 和 vj 的边表中各插入一个结点
 *    （无向图每条边对应两个边结点，互为逆序）
 */
void CreateALGraph(ALGraph *G) {
    int i, j, k;
    VertexType v1, v2;

    /* 第一步：读入顶点数和边数 */
    printf("请输入顶点数和边数（以空格分隔）：");
    scanf("%d %d", &G->vexnum, &G->arcnum);

    /* 第二步：读入顶点信息，初始化顶点表 */
    printf("请输入 %d 个顶点信息：", G->vexnum);
    for (i = 0; i < G->vexnum; i++) {
        scanf(" %c", &G->vertices[i].data);
        G->vertices[i].first = NULL;  /* 初始化边表头指针 */
    }

    /* 第三步：读入各边，建立邻接表 */
    printf("请依次输入 %d 条边（顶点v1 v2，以空格分隔）：", G->arcnum);
    for (k = 0; k < G->arcnum; k++) {
        scanf(" %c %c", &v1, &v2);

        /* 查找两个顶点的位置 */
        i = LocateVex(G, v1);
        j = LocateVex(G, v2);

        /* ① 在 v1 的边表中插入指向 v2 的新结点 */
        ArcNode *arc1 = (ArcNode *)malloc(sizeof(ArcNode));
        arc1->adjvex = j;               /* 指向 v2 的编号 */
        arc1->info = NULL;              /* 无额外信息 */
        arc1->next = G->vertices[i].first;  /* 头插法 */
        G->vertices[i].first = arc1;

        /* ② 在 v2 的边表中插入指向 v1 的新结点（无向图，互为逆序） */
        ArcNode *arc2 = (ArcNode *)malloc(sizeof(ArcNode));
        arc2->adjvex = i;               /* 指向 v1 的编号 */
        arc2->info = NULL;
        arc2->next = G->vertices[j].first;  /* 头插法 */
        G->vertices[j].first = arc2;
    }
}
```

> **⭐ 关键细节**：
> - **头插法 vs 尾插法**：头插法代码简洁但链表逆序，不影响算法正确性。
> - **无向图每条边创建两个边结点**：因为边 `(u,v)` 和 `(v,u)` 是等价的。
> - **有向图（十字链表）**：每条边只创建**一个**边结点。

### 二、图的遍历

图的遍历有两种基本策略：**深度优先搜索（DFS）** 和 **广度优先搜索（BFS）**。

#### 2.1 深度优先搜索 DFS（递归版 — 邻接表）

**核心思想**：从某顶点出发，沿一条路径尽可能深地访问，到达死胡同时**回溯**，继续探索其他路径。递归实现天然契合 DFS。

```
图示（以 A 出发）：

       A ─→ B ─→ D
       │    │
       └──→ C ─→ D

       访问序列：A → B → D → C（回溯）
       递归过程：
       DFS(A): 访问A, 递归DFS(B)
       DFS(B): 访问B, 递归DFS(D)
       DFS(D): 访问D, 无未访问邻接点, 回溯
       回到B, B的邻接点已全部访问
       回到A, 访问C, 递归DFS(C)
       DFS(C): 访问C, D已访问, 回溯
```

```c
/* ==================== 邻接表 DFS（递归版） ==================== */

/* 访问数组 */
static int visited[MAX_VERTEX_NUM];

/* DFS辅助函数：访问顶点 v */
void VisitFunc(ALGraph *G, int v) {
    printf("%c ", G->vertices[v].data);
}

/* DFS核心递归函数 */
void DFSTraverse_AL(ALGraph *G, int v) {
    /* 访问当前顶点 */
    VisitFunc(G, v);
    visited[v] = 1;  /* 标记为已访问 */

    /* 递归访问 v 的所有未访问邻接点 */
    ArcNode *p = G->vertices[v].first;
    while (p != NULL) {
        if (!visited[p->adjvex]) {
            DFSTraverse_AL(G, p->adjvex);  /* 递归调用 */
        }
        p = p->next;  /* 指向下一个邻接点 */
    }
}

/* DFS遍历入口（对非连通图需要遍历所有顶点） */
void DFS_AL(ALGraph *G) {
    /* 初始化访问标记 */
    for (int i = 0; i < G->vexnum; i++) {
        visited[i] = 0;
    }

    /* 对每个未访问顶点调用DFS（处理非连通图） */
    for (int i = 0; i < G->vexnum; i++) {
        if (!visited[i]) {
            DFSTraverse_AL(G, i);
        }
    }
    printf("\n");
}
```

#### 2.2 深度优先搜索 DFS（递归版 — 邻接矩阵）

```c
/* ==================== 邻接矩阵 DFS（递归版） ==================== */

static int visited_m[MAX_VERTEX_NUM];  /* 邻接矩阵版访问标记 */

/* DFS核心递归函数（邻接矩阵） */
void DFS_Matrix(ALGraph *G, int v) {
    /* 访问当前顶点 */
    printf("%c ", G->vertices[v].data);
    visited_m[v] = 1;  /* 标记已访问 */

    /* 扫描整行，寻找邻接点 */
    for (int w = 0; w < G->vexnum; w++) {
        /* 判断 w 是否为 v 的邻接点：有边且未访问 */
        if (G->kind == DG  ||  G->kind == UDG) {
            /* 简单判断：在边表中查找或矩阵中有边 */
            /* 邻接矩阵版本用二维数组判断 */
        }
        /* 在矩阵中判断边 (v,w) 是否存在 */
        if (!visited_m[w] && HasEdge(G, v, w)) {
            DFS_Matrix(G, w);  /* 递归访问 */
        }
    }
}

/* 判断图中顶点 i 和 j 之间是否有边 */
int HasEdge(ALGraph *G, int i, int j) {
    ArcNode *p = G->vertices[i].first;
    while (p != NULL) {
        if (p->adjvex == j) {
            return 1;
        }
        p = p->next;
    }
    return 0;
}

/* DFS入口 */
void DFS_Matrix_ALL(ALGraph *G) {
    for (int i = 0; i < G->vexnum; i++) {
        visited_m[i] = 0;
    }
    for (int i = 0; i < G->vexnum; i++) {
        if (!visited_m[i]) {
            DFS_Matrix(G, i);
        }
    }
    printf("\n");
}
```

#### 2.3 ⭐🔥 DFS 非递归（栈实现）

**核心思想**：用**显式栈**代替系统递归栈。关键是要处理"访问时机"——第一次遇到顶点就访问并压栈，后续回溯时从栈中弹出。

```c
/* ==================== DFS 非递归（栈实现）⭐ ==================== */
/*
 * 核心思路：
 * 1. 从起始顶点出发，将其标记并压栈
 * 2. 弹出栈顶，寻找其未访问的第一个邻接点
 * 3. 若有未访问邻接点，先"退回"到栈顶再将其邻接点压栈
 * 4. 若无未访问邻接点，继续弹出（回溯）
 * 5. 重复直到栈空
 *
 * 注意：DFS非递归必须模拟递归的"回溯"行为
 * 使用"退回"策略：先将当前结点放回栈，再处理新结点
 */

void DFS_Iterative(ALGraph *G) {
    int stack[MAX_VERTEX_NUM];  /* 显式栈 */
    int top = -1;                /* 栈顶指针 */
    int i;

    /* 初始化访问标记 */
    for (i = 0; i < G->vexnum; i++) {
        visited[i] = 0;
    }

    /* 遍历所有顶点（处理非连通图） */
    for (i = 0; i < G->vexnum; i++) {
        if (!visited[i]) {
            /* 访问起始顶点 */
            printf("%c ", G->vertices[i].data);
            visited[i] = 1;
            stack[++top] = i;  /* 压栈 */

            /* 开始模拟DFS过程 */
            while (top != -1) {
                int v = stack[top];  /* 查看栈顶元素（不弹出） */

                /* 寻找 v 的第一个未访问邻接点 */
                ArcNode *p = G->vertices[v].first;
                while (p != NULL && visited[p->adjvex]) {
                    p = p->next;
                }

                if (p != NULL) {
                    /* 找到了未访问邻接点：
                     * 先将v"退回"到栈（已在栈中），再处理新邻接点 */
                    int w = p->adjvex;  /* 新邻接点 */
                    /* 访问并压栈 */
                    printf("%c ", G->vertices[w].data);
                    visited[w] = 1;
                    stack[++top] = w;
                } else {
                    /* v 无未访问邻接点，弹出（回溯） */
                    top--;  /* 出栈 */
                }
            }
        }
    }
    printf("\n");
}
```

> **⭐ DFS 非递归的核心难点**：
> 1. 需要维护一个栈来模拟递归的调用栈
> 2. 每次找到未访问邻接点时，当前顶点**不能弹出栈**（因为回溯后还要继续访问其他邻接点）
> 3. 只有确认某顶点的所有邻接点都已访问，才能弹出它

#### 2.4 ⭐🔥 BFS（队列实现）

**核心思想**：从某顶点出发，先访问其**所有**直接邻接点，再依次访问邻接点的邻接点。类似于树的层次遍历，用**队列**实现。

```
图示（以 A 出发）：

       A ─→ B ─→ D
       │    │    │
       └──→ C ─→ D

       层次0：A        ← 第一层（起始顶点）
       层次1：B, C     ← A 的直接邻接点
       层次2：D        ← B、C 的邻接点

       访问序列：A → B → C → D
       队列过程：
       初始: [A]
       A出队，B、C入队: [B, C]
       B出队，D入队:   [C, D]
       C出队:         [D]
       D出队:         [] 空
```

```c
/* ==================== BFS（队列实现）⭐ ==================== */
/*
 * 核心思路：
 * 1. 从起始顶点入队
 * 2. 循环：出队 → 访问所有未访问邻接点 → 邻接点入队
 * 3. 直到队空
 *
 * 与树的层次遍历高度相似，但需要 visited[] 防止回路
 */

/* 假设为简单队列实现 */
typedef struct {
    int data[MAX_VERTEX_NUM];
    int front, rear;
} Queue;

void InitQueue(Queue *Q) {
    Q->front = Q->rear = 0;
}

int QueueEmpty(Queue *Q) {
    return Q->front == Q->rear;
}

void EnQueue(Queue *Q, int v) {
    Q->data[Q->rear++] = v;
}

int DeQueue(Queue *Q) {
    return Q->data[Q->front++];
}

/* BFS核心函数 */
void BFS_AL(ALGraph *G, int v) {
    Queue Q;
    int w;

    InitQueue(&Q);

    /* 访问起始顶点 */
    printf("%c ", G->vertices[v].data);
    visited[v] = 1;
    EnQueue(&Q, v);  /* 起始顶点入队 */

    /* 层序遍历：每次处理一层的所有顶点 */
    while (!QueueEmpty(&Q)) {
        int u = DeQueue(&Q);  /* 出队 */

        /* 遍历 u 的所有邻接点 */
        ArcNode *p = G->vertices[u].first;
        while (p != NULL) {
            w = p->adjvex;  /* 邻接点编号 */
            if (!visited[w]) {  /* 未访问 */
                printf("%c ", G->vertices[w].data);
                visited[w] = 1;  /* 标记已访问 */
                EnQueue(&Q, w);  /* 邻接点入队 */
            }
            p = p->next;  /* 下一条边 */
        }
    }
    printf("\n");
}

/* BFS完整入口 */
void BFS_AL_ALL(ALGraph *G) {
    for (int i = 0; i < G->vexnum; i++) {
        visited[i] = 0;
    }
    /* 对每个连通分量调用BFS */
    for (int i = 0; i < G->vexnum; i++) {
        if (!visited[i]) {
            BFS_AL(G, i);
        }
    }
}
```

> **⭐ BFS 与 DFS 对比记忆**：
> | | DFS | BFS |
> |---|---|---|
> | 数据结构 | **栈**（递归或显式） | **队列** |
> | 搜索策略 | 一条路走到黑，回头再走别的 | 逐层扩展 |
> | 遍历序列 | 不唯一，取决于邻接点顺序 | 不唯一，取决于邻接点顺序 |
> | 空间复杂度 | O(h)，h为最大深度 | O(n)，最坏需存储所有顶点 |

### 三、最小生成树

**问题**：给一个连通带权图 $G=(V, E)$，用 $n-1$ 条边连接所有 $n$ 个顶点，且边的**总权值最小**。

---

#### 3.1 Prim 算法（邻接矩阵，O(n²)）

**核心思想（贪心）**：从任意顶点出发，每次选择**与当前生成树连接代价最小的边**，逐步扩展生成树。

```
图示（从顶点 0 出发）：

       当前生成树顶点集合：U = {0}
       候选边（U到V-U的边）：
       (0,1)=6  (0,2)=1  (0,3)=5

       选最小边：(0,2)=1 → U = {0, 2}
       候选边：(0,1)=6  (0,3)=5  (2,3)=5  (2,4)=6  (2,5)=6

       选最小边：(0,3)=5 → U = {0, 2, 3}
       ... 重复直到 |U| = n
```

```c
/* ==================== Prim 算法（邻接矩阵版） ==================== */
/*
 * 时间复杂度：O(n²) —— 与边数e无关，适合稠密图
 * 空间复杂度：O(n) —— 辅助数组 closedge
 *
 * 算法步骤：
 * 1. 从起始顶点 u 开始，U = {u}
 * 2. 对每个不在 U 中的顶点 v，记录到 U 的最小代价 adjvex[v]/lowcost[v]
 * 3. 重复 n-1 次：
 *    ① 选出 lowcost 最小的顶点 k（加入 U）
 *    ② 用 k 更新其余顶点到 U 的最小代价
 */

#define INF 0x3f3f3f3f  /* 无穷大 */
#define MAX_V 100

typedef struct {
    int adj[MAX_V][MAX_V];  /* 邻接矩阵，adj[i][j]=边(i,j)权值 */
    int n;                   /* 顶点数 */
} MGraph;

typedef struct {
    VertexType adjvex;     /* 最小代价边连接的U中顶点 */
    int lowcost;           /* 最小代价 */
} CloseEdge[MAX_V];

/* Prim算法实现 */
void MiniSpanTree_Prim(MGraph G, VertexType u) {
    int i, j, k;

    /* 找到起始顶点 u 的位置 */
    for (k = 0; k < G.n; k++) {
        if (G.adj[k][k] == 0 && /* 简化：实际应通过顶点数组查找 */
            /* 假设u已在G中 */
            break;
        }
    }

    /* 实际上需要顶点数组，简化为从顶点0开始 */
    /* 初始化：所有顶点到顶点0的边 */
    CloseEdge closedge;
    for (j = 0; j < G.n; j++) {
        if (j != 0) {
            closedge[j].adjvex = 0;
            closedge[j].lowcost = G.adj[0][j];
        }
    }
    closedge[0].lowcost = 0;  /* 0已加入U */

    /* 输出初始边（调试用） */
    /* printf("边 (%d, %d) = %d\n", 0, 1, closedge[1].lowcost); */

    /* 循环 n-1 次，每次添加一个顶点到U */
    for (i = 1; i < G.n; i++) {
        /* ① 选择 lowcost 最小的顶点 k */
        int min = INF;
        k = -1;
        for (j = 0; j < G.n; j++) {
            if (closedge[j].lowcost != 0 && closedge[j].lowcost < min) {
                min = closedge[j].lowcost;
                k = j;
            }
        }

        if (k == -1) {
            printf("图不连通，无法生成最小生成树\n");
            return;
        }

        /* 输出边 (closedge[k].adjvex, k) = closedge[k].lowcost */
        printf("添加边：(%d -> %d)，权值：%d\n",
               closedge[k].adjvex, k, closedge[k].lowcost);

        /* 将 k 加入U：lowcost设为0 */
        closedge[k].lowcost = 0;

        /* ② 以 k 为新的参考顶点，更新其余顶点到U的最小代价 */
        for (j = 0; j < G.n; j++) {
            if (closedge[j].lowcost != 0  /* j不在U中 */
                && G.adj[k][j] < closedge[j].lowcost) {
                closedge[j].adjvex = k;
                closedge[j].lowcost = G.adj[k][j];
            }
        }
    }
}
```

> **⭐ Prim 算法记忆口诀**：
> "加点不加点边，找最近、换参考"
> - 每次选最近点加入集合
> - 加入后以它为参考重新评估所有边
> - 适合稠密图（邻接矩阵实现，$O(n^2)$ 与 $e$ 无关）

#### 3.2 Kruskal 算法（边排序 + 并查集，O(e log e)）

**核心思想（贪心）**：将所有边按权值**从小到大**排序，依次检查每条边，若加入后**不形成环**则加入生成树。

```
图示：

       边集（按权值排序）：
       (1,3)=1  (4,6)=2  (2,5)=3  (3,4)=4  (3,5)=5  (1,2)=6  (5,6)=7

       过程：
       选(1,3)=1  →  {1,3}    ✓ (不形成环)
       选(4,6)=2  →  {4,6}    ✓ (不形成环)
       选(2,5)=3  →  {2,5}    ✓ (不形成环)
       选(3,4)=4  →  {1,3,4,6,2,5}  ✓ (连接两个集合)
       选(3,5)=5  →  {1,3,4,6,2,5}  ✗ (3和5已连通，形成环)
       选(1,2)=6  →  已全连通  ✗
       选(5,6)=7  →  已全连通  ✗

       结果：4条边 = {1,3}, {4,6}, {2,5}, {3,4}，总权值=11
```

**并查集（Disjoint Set）辅助结构**：

```c
/* ==================== 并查集（Kruskal 的核心辅助） ==================== */

typedef struct {
    int parent;  /* 父节点索引，parent[i]=i 表示i是根 */
} Parent;

/* 初始化并查集 */
void MakeSet(Parent *parent, int n) {
    for (int i = 0; i < n; i++) {
        parent[i].parent = i;
    }
}

/* 查找根结点（路径压缩） */
int Find(Parent *parent, int x) {
    if (parent[x].parent == x) {
        return x;
    }
    /* 路径压缩：将x直接连到根 */
    parent[x].parent = Find(parent, parent[x].parent);
    return parent[x].parent;
}

/* 判断两个元素是否属于同一集合 */
int SameSet(Parent *parent, int x, int y) {
    return Find(parent, x) == Find(parent, y);
}

/* 合并两个集合 */
void Union(Parent *parent, int x, int y) {
    int rootX = Find(parent, x);
    int rootY = Find(parent, y);
    if (rootX != rootY) {
        parent[rootX].parent = rootY;  /* 将X挂到Y下 */
    }
}
```

**边结构体与快速排序**：

```c
/* 边结构体 */
typedef struct {
    int from;   /* 起点 */
    int to;     /* 终点 */
    int weight; /* 权值 */
} Edge;

/* 快速排序：按权值从小到大排序边 */
int compare_edges(const void *a, const void *b) {
    Edge ea = *(const Edge *)a;
    Edge eb = *(const Edge *)b;
    return ea.weight - eb.weight;
}
```

```c
/* ==================== Kruskal 算法 ==================== */
/*
 * 时间复杂度：O(e log e)，主要花在排序上
 * 空间复杂度：O(e + n)
 *
 * 适用场景：稀疏图（边数远少于n²时优于Prim）
 */

/* Kruskal核心实现 */
void MiniSpanTree_Kruskal(Edge edges[], int e, int n) {
    Parent parent[MAX_V];  /* 并查集 */

    /* ① 将边按权值从小到大排序 */
    qsort(edges, e, sizeof(Edge), compare_edges);

    /* ② 初始化并查集 */
    MakeSet(parent, n);

    int count = 0;  /* 已选边数 */

    /* ③ 依次检查每条边 */
    for (int i = 0; i < e && count < n - 1; i++) {
        /* 判断边两端的顶点是否在同一集合 */
        if (!SameSet(parent, edges[i].from, edges[i].to)) {
            /* 不在同一集合 → 不形成环 → 加入 */
            printf("添加边：(%d -> %d)，权值：%d\n",
                   edges[i].from, edges[i].to, edges[i].weight);
            Union(parent, edges[i].from, edges[i].to);
            count++;
        }
        /* 已在同一集合 → 会形成环 → 舍弃 */
    }

    if (count < n - 1) {
        printf("图不连通，无法生成最小生成树\n");
    }
}
```

> **⭐ Prim vs Kruskal 记忆对比**：
> | | Prim | Kruskal |
> |---|---|---|
> | 核心操作 | **加点** | **加边** |
> | 数据结构 | closedge[] 数组 | 边集 + 并查集 |
> | 复杂度 | O(n²) | O(e log e) |
> | 适用 | 稠密图（$e \approx n^2$） | 稀疏图（$e \ll n^2$） |
> | 思想 | 贪心：每次选最近点 | 贪心：每次选最小边 |

### 四、拓扑排序

**AOV 网**：用顶点表示活动，边表示活动先后关系的有向图。若无环，称为 DAG（有向无环图）。

**核心思想**：不断选择**入度为 0** 的顶点输出，并删除该顶点及其出边，重复此过程。

```
图示：

       v1 → v2
       ↓    ↓
       v3 → v4 → v5
       ↓         ↑
       └──→ v6 ←─┘

       入度：v1=0, v2=1, v3=2, v4=2, v5=1, v6=1

       步骤：
       ① 选v1(入度0) → 输出v1, 删除v1的边 → v2入度=0
       ② 选v2(入度0) → 输出v2, 删除v2的边 → v3入度=1
       ③ 选v6(入度0) → 输出v6, 删除v6的边 → v5入度=0
       ④ 选v5(入度0) → 输出v5
       ⑤ 选v3(入度0) → 输出v3, 删除v3的边 → v4入度=1
       ⑥ 选v4(入度0) → 输出v4

       结果：v1, v6, v2, v5, v3, v4（拓扑序列之一）
```

```c
/* ==================== 拓扑排序（栈实现）⭐ ==================== */
/*
 * 时间复杂度：O(n + e) —— 每个顶点和每条边各访问一次
 * 空间复杂度：O(n)
 *
 * 算法步骤：
 * ① 计算每个顶点的入度
 * ② 将所有入度为0的顶点压栈
 * ③ 循环：弹出栈顶 → 输出 → 将其邻接点入度减1 → 为0则压栈
 * ④ 若输出顶点数 < n，说明有环
 */

/* 邻接表版拓扑排序 */
int TopologicalSort(ALGraph *G) {
    int indegree[MAX_VERTEX_NUM];  /* 入度数组 */
    int stack[MAX_VERTEX_NUM];     /* 入度为0的顶点栈 */
    int top = -1;                   /* 栈顶指针 */
    int count = 0;                  /* 已输出顶点数 */
    int i, k, w;
    ArcNode *p;

    /* ① 初始化入度数组 */
    for (i = 0; i < G->vexnum; i++) {
        indegree[i] = 0;
    }

    /* ② 计算所有顶点的入度 */
    for (i = 0; i < G->vexnum; i++) {
        p = G->vertices[i].first;
        while (p != NULL) {
            indegree[p->adjvex]++;  /* 每条边使终点入度+1 */
            p = p->next;
        }
    }

    /* ③ 将所有入度为0的顶点压栈 */
    for (i = 0; i < G->vexnum; i++) {
        if (indegree[i] == 0) {
            stack[++top] = i;
        }
    }

    /* ④ 开始拓扑排序 */
    printf("拓扑排序结果：");
    while (top != -1) {
        /* 弹出栈顶 */
        w = stack[top--];
        printf("%c ", G->vertices[w].data);
        count++;

        /* 遍历w的所有邻接点，将它们的入度减1 */
        p = G->vertices[w].first;
        while (p != NULL) {
            k = p->adjvex;  /* 邻接点 */
            indegree[k]--;
            if (indegree[k] == 0) {
                /* 入度变为0，压栈 */
                stack[++top] = k;
            }
            p = p->next;
        }
    }

    /* ⑤ 判断是否有环 */
    if (count < G->vexnum) {
        printf("\n图中存在环！拓扑排序失败\n");
        return 0;  /* 失败 */
    } else {
        printf("\n（无环，拓扑排序成功）\n");
        return 1;  /* 成功 */
    }
}
```

> **⭐ 关键记忆**：
> - 拓扑排序的前提：**有向无环图（DAG）**
> - 使用**入度数组**维护每个顶点的入度
> - 使用**栈/队列**存储入度为 0 的顶点
> - 输出顶点数 < n 说明有环

### 五、最短路径

#### 5.1 Dijkstra 算法（单源最短路径，O(n²)）

**核心思想（贪心）**：从源点 $v_0$ 出发，维护一个集合 $S$（已确定最短路径的顶点），每次从 $V-S$ 中选出**到 $v_0$ 距离最短**的顶点 $u$，将 $u$ 加入 $S$，然后用 $u$ 更新其余顶点的距离。

```
图示（从顶点 0 出发）：

       初始状态：
       dist[] = [0, 10, ∞, 30, 100]
       S = {0}

       第1轮：u=1 (dist=10)，S={0,1}
       更新：dist[2] = min(∞, 10+50)=60
              dist[3] = min(30, 10+60)=30 (不变)
              dist[4] = min(100, 10+60)=70

       第2轮：u=3 (dist=30)，S={0,1,3}
       更新：dist[2] = min(60, 30+10)=40

       第3轮：u=2 (dist=40)，S={0,1,3,2}
       更新：dist[4] = min(70, 40+10)=50

       第4轮：u=4 (dist=50)

       最终结果：dist = [0, 10, 40, 30, 50]
```

```c
/* ==================== Dijkstra 算法（邻接矩阵版） ==================== */
/*
 * 时间复杂度：O(n²) —— 适合稠密图
 * 空间复杂度：O(n)
 *
 * 核心数组：
 * - dist[]  : 从源点到各顶点的最短距离
 * - path[]  : 最短路径的前驱顶点
 * - final[] : 标记顶点是否已确定最短路径 (0=未确定, 1=已确定)
 *
 * 算法步骤：
 * ① 初始化：dist[v0]=0，其余dist[·]=∞
 * ② 循环 n-1 次：
 *    a) 选未确定顶点中dist最小的顶点u
 *    b) 标记u为已确定 (final[u]=1)
 *    c) 用u更新其余顶点的dist（松弛操作）
 */

void ShortestPath_Dijkstra(MGraph G, int v0, int dist[], int path[]) {
    int final[MAX_V];  /* final[w]=1表示v0到w的最短路径已确定 */
    int i, j, k, min;

    /* ① 初始化 */
    for (i = 0; i < G.n; i++) {
        dist[i] = G.adj[v0][i];  /* 源点到各顶点的直接距离 */
        final[i] = 0;             /* 初始未确定 */
        path[i] = -1;             /* 路径初始为空 */
        if (G.adj[v0][i] < INF && i != v0) {
            path[i] = v0;         /* 有直接边则记录前驱 */
        }
    }
    final[v0] = 1;    /* 源点已确定 */
    dist[v0] = 0;

    /* ② 循环 n-1 次，每次确定一个顶点的最短路径 */
    for (int count = 1; count < G.n; count++) {
        /* a) 选择 dist 最小的未确定顶点 */
        min = INF;
        k = -1;
        for (j = 0; j < G.n; j++) {
            if (!final[j] && dist[j] < min) {
                min = dist[j];
                k = j;
            }
        }

        if (k == -1) {
            break;  /* 剩余顶点不可达 */
        }

        /* b) 标记为已确定 */
        final[k] = 1;

        /* c) 松弛操作：用顶点k更新其余顶点 */
        for (j = 0; j < G.n; j++) {
            if (!final[j] && G.adj[k][j] < INF
                && dist[k] + G.adj[k][j] < dist[j]) {
                /* 通过k到达j比直接到达更近，更新dist和path */
                dist[j] = dist[k] + G.adj[k][j];
                path[j] = k;
            }
        }
    }

    /* 输出最短路径结果 */
    printf("从顶点 %d 出发的最短路径：\n", v0);
    for (i = 0; i < G.n; i++) {
        if (i != v0 && dist[i] < INF) {
            printf("顶点%d的最短距离 = %d\n", i, dist[i]);
            /* 可通过path[]回溯打印完整路径 */
        }
    }
}
```

> **⭐ Dijkstra 算法记忆口诀**：
> "选最近的点，用它更新别人"
> - 每次找未确定中距离源点最近的
> - 用它作为"中转站"看看能不能让其他人走得更近
> - 已确定的点不会再改变（贪心的正确性）
> - **不适用于负权边**

#### 5.2 Floyd 算法（多源最短路径，O(n³)）

**核心思想（动态规划）**：$A^{(k)}[i][j]$ 表示"只允许经过前 $k$ 个顶点"时 $i$ 到 $j$ 的最短距离。递推公式：

$$A^{(k)}[i][j] = \min(A^{(k-1)}[i][j],\ A^{(k-1)}[i][k] + A^{(k-1)}[k][j])$$

```
图示（逐步扩展允许的中转点）：

       初始A⁽⁰⁾：直接边
       ┌──────────────────────────────┐
       │  0  5  ∞  10  │
       │  3  0  2  ∞   │
       │  ∞  ∞  0  3   │
       │  4  ∞  ∞  0   │
       └──────────────────────────────┘

       k=0（允许经过顶点0）：
       A[1][2] = min(2, 5+∞) = 2   （不变）
       A[3][1] = min(∞, 4+5) = 9   （通过0中转！）
       ...

       k=1,2,3 继续扩展...
       最终得到所有顶点间的最短距离
```

```c
/* ==================== Floyd 算法（邻接矩阵版） ==================== */
/*
 * 时间复杂度：O(n³) —— 三层循环
 * 空间复杂度：O(n²)
 *
 * 核心数组：
 * - A[n][n]  : A[i][j] 存储 i 到 j 的最短距离
 * - Path[n][n]: Path[i][j] 存储 i 到 j 的中间顶点
 *
 * 算法步骤：
 * ① 初始化 A 和 Path
 * ② 对每个可能的中转点 k（0..n-1）
 * ③ 对每个起点 i
 * ④ 对每个终点 j
 *  如果 A[i][k] + A[k][j] < A[i][j]，则更新
 */

void ShortestPath_Floyd(MGraph G, int A[MAX_V][MAX_V], int Path[MAX_V][MAX_V]) {
    int i, j, k;

    /* ① 初始化 */
    for (i = 0; i < G.n; i++) {
        for (j = 0; j < G.n; j++) {
            A[i][j] = G.adj[i][j];  /* 直接用邻接矩阵初始化 */
            if (i != j && A[i][j] < INF) {
                Path[i][j] = i;     /* i到j有边，中间点记为i */
            } else {
                Path[i][j] = -1;    /* 无直接边 */
            }
        }
    }

    /* ②③④ 三重循环：枚举中转点k、起点i、终点j */
    for (k = 0; k < G.n; k++) {
        for (i = 0; i < G.n; i++) {
            for (j = 0; j < G.n; j++) {
                /* 如果经过k中转更近，则更新 */
                if (A[i][k] + A[k][j] < A[i][j]) {
                    A[i][j] = A[i][k] + A[k][j];
                    Path[i][j] = k;  /* 记录经过k中转 */
                }
            }
        }
    }

    /* 输出结果 */
    printf("Floyd算法得到的最短路径矩阵：\n");
    for (i = 0; i < G.n; i++) {
        for (j = 0; j < G.n; j++) {
            if (i == j) {
                printf("  0   ");
            } else if (A[i][j] >= INF) {
                printf("  ∞   ");
            } else {
                printf("%3d  ", A[i][j]);
            }
        }
        printf("\n");
    }

    /* 打印完整路径 */
    for (i = 0; i < G.n; i++) {
        for (j = 0; j < G.n; j++) {
            if (i != j && Path[i][j] >= 0) {
                printf("\n顶点%d -> 顶点%d 的最短距离 = %d, 路径: %d",
                       i, j, A[i][j], i);
                /* 通过Path[]回溯输出完整路径 */
                int p = j;
                while (p != i) {
                    printf(" -> %d", p);
                    p = Path[i][p];  /* 递归回溯 */
                }
                printf("\n");
            }
        }
    }
}
```

> **⭐ Floyd 算法核心记忆**：
> - **三层循环顺序**：k 在最外层（中转点），i 和 j 在内层
> - **转移方程**：$A[i][j] = \min(A[i][j], A[i][k] + A[k][j])$
> - **可以处理负权边**（但不能有负权回路）
> - **多源最短路径**：一次计算出所有顶点对之间的距离

### 六、关键路径（AOE 网）

**AOE 网**：用边表示活动、顶点表示事件的网络。关键路径是**从源点到汇点的最长路径**。

**四个核心参数**：

| 参数 | 含义 | 计算方式 |
|------|------|---------|
| $ve[k]$ | 事件 $k$ 的**最早**发生时间 | 从源点出发的最长路径长度 |
| $vl[k]$ | 事件 $k$ 的**最迟**发生时间 | 从汇点回溯的最晚允许时间 |
| $e[i]$ | 活动 $i$ 的**最早**开始时间 | 活动起始事件的 $ve$ 值 |
| $l[i]$ | 活动 $i$ 的**最迟**开始时间 | 活动终止事件的 $vl$ 减去活动持续时间 |

**关键活动**：满足 $e[i] = l[i]$ 的活动，即**没有机动时间**的活动。

```
图示（简化 AOE 网）：

       v0(源点) →→ v1 →→ v2(汇点)
         │        ↑      ↑
         │        │      │
         ↓        │      │
       v3 →→ v4 ←─┴──────┘

       ve 计算（从前往后，取max）：
       ve[0] = 0
       ve[1] = ve[0] + 6 = 6
       ve[3] = ve[0] + 4 = 4
       ve[4] = max(ve[1]+1, ve[3]+5) = max(7, 9) = 9
       ve[2] = max(ve[1]+5, ve[4]+2) = max(11, 11) = 11

       vl 计算（从后往前，取min）：
       vl[2] = ve[2] = 11
       vl[4] = vl[2] - 2 = 9
       vl[1] = min(vl[2]-5, vl[4]-1) = min(6, 8) = 6
       vl[3] = vl[4] - 5 = 4

       活动最早开始e与最迟开始l：
       a0: v0→v1,  e=ve[0]=0,   l=vl[1]-6=0,    l-e=0 → 关键活动 ✓
       a1: v0→v3,  e=ve[0]=0,   l=vl[3]-4=0,    l-e=0 → 关键活动 ✓
       a2: v1→v2,  e=ve[1]=6,   l=vl[2]-5=6,    l-e=0 → 关键活动 ✓
       a3: v3→v4,  e=ve[3]=4,   l=vl[4]-5=4,    l-e=0 → 关键活动 ✓
       a4: v1→v4,  e=ve[1]=6,   l=vl[4]-1=8,    l-e=2 → 非关键活动
       a5: v4→v2,  e=ve[4]=9,   l=vl[2]-2=9,    l-e=0 → 关键活动 ✓

       关键路径：v0 → v1 → v2（或 v0→v3→v4→v2）
```

```c
/* ==================== 关键路径算法（AOE网） ==================== */
/*
 * 注意：此算法为了解而了解，非必考重点
 * 核心依赖：先做拓扑排序（求ve[]），再逆序求vl[]
 *
 * 步骤：
 * ① 求各事件最早发生时间 ve[]（基于拓扑序列）
 * ② 求各事件最迟发生时间 vl[]（从汇点逆推）
 * ③ 对每个活动 a_k=<i, j>，计算 e(k) 和 l(k)
 * ④ 找出 e(k) = l(k) 的关键活动
 */

/* 假设已有拓扑排序结果 */
int TopoOrder[MAX_VERTEX_NUM];  /* 拓扑序 */
int vl[MAX_VERTEX_NUM];         /* 最迟发生时间 */
int ve[MAX_VERTEX_NUM];         /* 最早发生时间 */

void CriticalPath(ALGraph *G) {
    int stack[MAX_VERTEX_NUM];
    int top = -1;
    int count = 0;
    int i, k, j, w;
    int ee, el;  /* 活动最早/最迟开始时间 */
    ArcNode *p;

    /* ① 拓扑排序 + 计算 ve[] */
    int indegree[MAX_VERTEX_NUM];
    for (i = 0; i < G->vexnum; i++) indegree[i] = 0;

    /* 计算入度 */
    for (i = 0; i < G->vexnum; i++) {
        p = G->vertices[i].first;
        while (p) { indegree[p->adjvex]++; p = p->next; }
    }

    /* 入度为0入栈 */
    for (i = 0; i < G->vexnum; i++)
        if (indegree[i] == 0) stack[++top] = i;

    /* 初始化 ve */
    for (i = 0; i < G->vexnum; i++) ve[i] = 0;

    /* 拓扑排序 */
    while (top != -1) {
        i = stack[top--];
        TopoOrder[count++] = i;

        p = G->vertices[i].first;
        while (p) {
            k = p->adjvex;
            indegree[k]--;
            /* ve[k] = max(ve[k], ve[i] + weight(i,k)) */
            /* 此处假设权值存储在 info 中 */
            int weight = p->info ? *(int*)p->info : 1;
            if (ve[i] + weight > ve[k])
                ve[k] = ve[i] + weight;
            p = p->next;
        }
    }

    if (count < G->vexnum) {
        printf("图中有环，无关键路径\n");
        return;
    }

    /* ② 计算 vl[]：初始化 vl[汇点] = ve[汇点] */
    for (i = 0; i < G->vexnum; i++) vl[i] = ve[G->vexnum - 1];

    /* ③ 逆拓扑序求 vl */
    for (i = count - 1; i >= 0; i--) {
        j = TopoOrder[i];
        p = G->vertices[j].first;
        while (p) {
            k = p->adjvex;
            int weight = p->info ? *(int*)p->info : 1;
            if (vl[k] - weight < vl[j])
                vl[j] = vl[k] - weight;
            p = p->next;
        }
    }

    /* ④ 求关键活动 */
    printf("关键活动：\n");
    for (i = 0; i < G->vexnum; i++) {
        p = G->vertices[i].first;
        while (p) {
            k = p->adjvex;
            int weight = p->info ? *(int*)p->info : 1;
            ee = ve[i];           /* 活动最早开始 */
            el = vl[k] - weight;  /* 活动最迟开始 */
            if (ee == el) {
                printf("活动 <%c -> %c> 是关键活动\n",
                       G->vertices[i].data, G->vertices[k].data);
            }
            p = p->next;
        }
    }
}
```

> **⭐ 关键路径记忆要点**：
> - 关键路径是**最长路径**，不是最短路径
> - ve[] 从前往后取 max，vl[] 从后往前取 min
> - 关键活动满足 $e = l$，即**没有机动时间**
> - 关键路径可能**不唯一**

## ⚠️算法复杂度分析

### 完整复杂度汇总表

| 算法 | 存储结构 | 时间复杂度 | 空间复杂度 | 适用场景 |
|------|---------|-----------|-----------|---------|
| DFS（递归） | 邻接表 | $O(n+e)$ | $O(n)$ | 通用 |
| DFS（递归） | 邻接矩阵 | $O(n^2)$ | $O(n)$ | 稠密图 |
| DFS（非递归） | 邻接表 | $O(n+e)$ | $O(n)$ | 通用 |
| BFS | 邻接表 | $O(n+e)$ | $O(n)$ | 通用 |
| BFS | 邻接矩阵 | $O(n^2)$ | $O(n)$ | 稠密图 |
| Prim | 邻接矩阵 | $O(n^2)$ | $O(n)$ | **稠密图** |
| Prim | 邻接表+堆 | $O(e \log n)$ | $O(n)$ | 稀疏图 |
| Kruskal | 边集+并查集 | $O(e \log e)$ | $O(e+n)$ | **稀疏图** |
| 拓扑排序 | 邻接表 | $O(n+e)$ | $O(n)$ | DAG |
| Dijkstra | 邻接矩阵 | $O(n^2)$ | $O(n)$ | 稠密图 |
| Dijkstra | 邻接表+堆 | $O(e \log n)$ | $O(n)$ | 稀疏图 |
| Floyd | 邻接矩阵 | $O(n^3)$ | $O(n^2)$ | 中小规模 |
| 关键路径 | 邻接表 | $O(n+e)$ | $O(n)$ | AOE网 |

### 关键结论

1. **遍历算法**：邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$
2. **最小生成树**：Prim 适合稠密图，Kruskal 适合稀疏图
3. **最短路径**：
   - 单源：Dijkstra（非负权）
   - 多源：Floyd
   - 有负权：Bellman-Ford（不在本题范围内）
4. **拓扑排序**：仅适用于 DAG，$O(n+e)$

## ⚖️易混淆对比

### 对比 1：Prim vs Kruskal

| | Prim | Kruskal |
|---|---|---|
| **搜索起点** | 从顶点出发 | 从边出发 |
| **核心操作** | 选最小边加入生成树 | 选最小边加入生成树 |
| **数据结构** | closedge[] 数组 | 并查集 |
| **复杂度** | $O(n^2)$ | $O(e \log e)$ |
| **何时选** | 边多（稠密图） | 边少（稀疏图） |

### 对比 2：DFS vs BFS

| | DFS | BFS |
|---|---|---|
| **数据结构** | 栈（递归栈） | 队列 |
| **搜索顺序** | 纵向深入 | 横向层展 |
| **空间复杂度** | $O(n)$（最坏） | $O(n)$ |
| **适合场景** | 判断连通性、找路径 | 最短路（无权图） |
| **遍历序列** | 不唯一 | 不唯一 |

### 对比 3：Dijkstra vs Floyd

| | Dijkstra | Floyd |
|---|---|---|
| **问题类型** | 单源最短路 | 多源最短路 |
| **思想** | 贪心 | 动态规划 |
| **复杂度** | $O(n^2)$ | $O(n^3)$ |
| **负权** | ❌ 不支持 | ✅ 支持（无负环） |
| **输出** | 源点到各点距离 | 所有点对距离 |

### 对比 4：AOV 网 vs AOE 网

| | AOV 网 | AOE 网 |
|---|--------|--------|
| **含义** | 活动 = 顶点 | 活动 = 边 |
| **算法** | 拓扑排序 | 关键路径 |
| **求什么** | 活动先后关系 | 关键活动 |
| **路径性质** | 任意路径 | **最长路径** |
