# 算法可视化清单

> 本文档是 408 考研数据结构课程的**算法可视化参考清单**，按知识点分类列出所有适合可视化的核心算法，标注每个算法应展示的关键动态步骤，方便制作动画、交互式演示或手绘理解。

---

## 📍知识定位

可视化是理解算法执行过程的最有效手段之一。对于 408 数据结构而言，**排序算法、查找算法、图遍历算法、树结构算法**是可视化价值最高的四类。

本文档服务于：
- **学习者**：通过可视化理解算法的**逐步执行过程**，而非仅背代码
- **复习者**：通过可视化回顾算法核心操作（分区、筛选、合并、遍历）
- **教师/内容创作者**：作为制作算法动画的参考清单

所有可视化目标均对应到 [[数据结构与算法/算法/算法]] 总纲中的分类体系，以及各具体算法实现文档。

## 📊第一部分：排序算法可视化（8 大排序）

排序算法是 408 大题最高频内容，每个排序算法的可视化都应包含：**初始状态 → 逐步执行过程 → 最终结果**。

### 1. 直接插入排序（Insertion Sort）

| 项目 | 内容 |
|------|------|
| 可视化核心 | **牌面插入**效果——每次将新元素插入到已有序序列的正确位置 |
| 关键帧 | ① 初始序列 ② 第 i 趟：从 r[i] 开始 ③ 折半比较（高亮比较过程）④ 后移元素（用箭头表示位移）⑤ 插入到位 |
| 动画要点 | 已排序区（绿色）逐步扩大，未排序区（灰色）逐个减少；元素后移用**连续箭头**展示 |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 2. 折半插入排序（Binary Insertion Sort）

| 项目 | 内容 |
|------|------|
| 可视化核心 | 在已有序区间用**折半查找**定位插入位置 |
| 关键帧 | ① 与直接插入排序相同 ② 增加：折半查找的过程——高亮 low、mid、high 三个指针 ③ 标注比较次数 |
| 动画要点 | 用不同颜色标注二分查找过程中每次比较的区间范围 |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 3. 希尔排序（Shell Sort）

| 项目 | 内容 |
|------|------|
| 可视化核心 | **缩小增量**——多趟插入排序，每趟增量逐渐减小 |
| 关键帧 | ① 展示初始增量 gap ② 对每个 gap，展示所有间隔为 gap 的元素分组 ③ 每分组内做插入排序 ④ 缩小 gap 重复 |
| 动画要点 | 用不同颜色标识不同 gap 值的元素组；gap 逐渐缩小，组数减少，每组变大 |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 4. 冒泡排序（Bubble Sort）

| 项目 | 内容 |
|------|------|
| 可视化核心 | **相邻两两比较 + 交换**，每趟将最大元素"冒泡"到队尾 |
| 关键帧 | ① 第 1 趟：从前往后扫描，比较相邻元素，大者右移 ② 高亮交换过程 ③ 第 1 趟结束后最大元素到达最右端 ④ 后续趟数减少比较范围 |
| 动画要点 | 大元素像气泡一样"浮"到右侧；用颜色渐变表示每趟扫描范围缩小；可展示优化版本（无交换则提前终止） |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 5. 快速排序（Quick Sort）⭐🔥🔥

| 项目 | 内容 |
|------|------|
| 可视化核心 | **分区操作**——以 pivot 为界，小于 pivot 的放左，大于 pivot 的放右 |
| 关键帧 | ① 选择 pivot（首元素/末元素/三数取中）② i 从左、j 从右向中间扫描 ③ 逆序则交换 ④ i=j 时 pivot 归位 ⑤ 左子区递归 ⑥ 右子区递归 |
| 动画要点 | **这是最高频可视化！** 必须展示：① 双指针 i、j 的移动过程 ② 每次交换的高亮 ③ pivot 归位 ④ 递归的树状结构展示（分治树） |
| 递归树 | 画一棵递归树，根为 pivot，左子树为左分区，右子树为右分区 |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 6. 简单选择排序（Selection Sort）

| 项目 | 内容 |
|------|------|
| 可视化核心 | **每趟选出最小元素**，放到已排序区的末尾 |
| 关键帧 | ① 扫描整个未排序区找最小 ② 用高亮记录 min 位置 ③ 与当前起始位置交换 ④ 已排序区扩大 1 |
| 动画要点 | 最小元素用特殊颜色标记；交换过程明确展示（与冒泡对比：冒泡是边比较边交换，选择是找到最小后才交换） |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 7. 堆排序（Heap Sort）⭐🔥🔥

| 项目 | 内容 |
|------|------|
| 可视化核心 | **建大根堆 → 反复删除堆顶**（堆顶与堆尾交换） |
| 关键帧 | ① 建堆过程：从最后一个非叶子节点开始自底向上 SiftDown ② 建堆完成后，堆顶是最大值 ③ 交换堆顶与堆尾 ④ 堆大小减 1 ⑤ 对堆顶 SiftDown ⑥ 重复③~⑤ |
| 动画要点 | **必须画完全二叉树结构展示堆**：① 建堆前 vs 建堆后 ② SiftDown 时沿着一条路径下沉的动画 ③ 每次交换后堆顶与堆尾互换 ④ 堆大小收缩 |
| 递归树/完全二叉树 | 建堆过程建议用完全二叉树图示，而非仅数组排列 |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 8. 归并排序（Merge Sort）⭐🔥

| 项目 | 内容 |
|------|------|
| 可视化核心 | **分解（对半分割）→ 合并（两个有序子序列归并为一个）** |
| 关键帧 | ① 分解：对半分割直到每个子序列长度为 1 ② 合并：从底向上两两合并 ③ 合并过程展示：双指针比较取小 |
| 动画要点 | **两阶段可视化**：① 分解阶段：自上而下的递归树（分裂）② 合并阶段：自底向上的合并过程（合并时用两个有序子序列归并到一个辅助数组） |
| 辅助数组 | 合并时必须展示辅助数组的空间占用（说明 $O(n)$ 空间复杂度） |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

### 9. 基数排序（Radix Sort）

| 项目 | 内容 |
|------|------|
| 可视化核心 | **按位分配 + 收集**（ LSD 或 MSD ） |
| 关键帧 | ① 确定最大位数 d ② 从最低位（个位）开始 ③ 按当前位分配到 10 个桶 ④ 按桶号收集 ⑤ 重复到最高位 |
| 动画要点 | 每个数位用 10 个链表桶展示分配过程；收集时将链表依次连接 |
| 关联文档 | [[数据结构与算法/算法/排序/排序算法]] |

## 🔍第二部分：查找算法可视化

### 1. 折半查找（Binary Search）⭐

| 项目 | 内容 |
|------|------|
| 可视化核心 | **每次取中间位置比较**，区间不断缩小一半 |
| 关键帧 | ① 展示 low、high、mid 三个指针 ② 每次比较后高亮 mid 位置 ③ 根据比较结果移动 low 或 high ④ 区间缩小 ⑤ 查找成功/失败 |
| 动画要点 | 已排除区间用灰色覆盖；mid 指针高亮移动；最终展示**判定树**——查找路径从根到目标节点 |
| 判定树 | 画出折半查找的判定树，每个节点为中间位置的元素，查找过程即为从根到目标的路径 |
| 关联文档 | [[数据结构与算法/算法/查找/查找算法]] |

### 2. 哈希查找（Hash Search）

| 项目 | 内容 |
|------|------|
| 可视化核心 | **哈希函数映射 + 冲突解决** |
| 关键帧 | ① 给出哈希函数 $H(key)$ ② 展示每个元素映射到的地址 ③ 展示冲突时的处理（线性探测：依次查找下一个地址；链地址：链表中追加） |
| 动画要点 | ① 插入时：元素 → 哈希函数 → 地址 ② 冲突时：线性探测画成向右的箭头链；链地址画成链表追加 |
| 关联文档 | [[数据结构与算法/算法/查找/查找算法]] |

### 3. 二叉排序树（BST）插入与删除

| 项目 | 内容 |
|------|------|
| 可视化核心 | **插入：从根比较，小的左走、大的右走；删除：三种情况处理** |
| 关键帧（插入） | ① 新节点从根比较 ② 沿路径向下 ③ 插入到正确位置的叶子节点 |
| 关键帧（删除） | ① 要删除节点是叶子：直接删除 ② 只有左/右孩子：用子树替代 ③ 左右子树都有：用直接前驱（左子树最大）或直接后继（右子树最小）替代 |
| 动画要点 | 插入时展示从根到插入位置的比较路径；删除时用动画展示替换关系 |
| 关联文档 | [[数据结构与算法/算法/查找/查找算法]] |

### 4. AVL 树平衡旋转

| 项目 | 内容 |
|------|------|
| 可视化核心 | **插入新节点后检查平衡因子，不平衡则旋转** |
| 旋转类型 | ① LL 型（右旋）② RR 型（左旋）③ LR 型（先左旋再右旋）④ RL 型（先右旋再左旋） |
| 动画要点 | 旋转前展示树结构 → 旋转过程动画 → 旋转后展示树结构；标注每个节点的平衡因子 |
| 关联文档 | [[数据结构与算法/算法/查找/查找算法]] |

### 2. BFS（广度优先搜索）⭐

| 项目 | 内容 |
|------|------|
| 可视化核心 | **层次遍历**——从源点出发，逐层扩展 |
| 关键帧 | ① 初始：源点入队 ② 出队 → 访问 → 将所有未访问邻接点入队 ③ 重复直到队空 |

### 3. DFS（深度优先搜索）⭐

| 项目 | 内容 |
|------|------|
| 可视化核心 | **递归深搜**——尽可能深地探索 |
| 关键帧 | ① 从源点出发 ② 访问 → 递归访问第一个未访问邻接点 ③ 回溯 → 回到上一层 ④ 继续访问下一个未访问邻接点 ⑤ 重复直到所有点访问完 |
| 动画要点 | ① 递归栈的变化过程 ② DFS 树 ③ 前向边/回边/交叉边的标注（有向图） |
| 关联文档 | [[数据结构与算法/算法/图/图算法]] |

### 4. 最小生成树——Prim 算法⭐🔥

| 项目 | 内容 |
|------|------|
| 可视化核心 | **从顶点出发**，逐步添加最小边 |
| 关键帧 | ① 选择一个起始顶点 ② 维护 lowcost 数组和 adjvex 数组 ③ 每趟选 lowcost 最小的顶点 ④ 添加到 U 集合 ⑤ 更新与 V-U 中顶点相连的最小边 |
| 动画要点 | ① 已选顶点（U 集合）用实心圆，未选（V-U）用空心圆 ② 已选边高亮 ③ 每趟选中的边用特殊颜色 ④ 最终展示 MST 的完整树形结构 |
| 关联文档 | [[数据结构与算法/算法/图/图算法]] |

### 5. 最小生成树——Kruskal 算法⭐🔥

| 项目 | 内容 |
|------|------|
| 可视化核心 | **从边出发**，按权值排序逐步添加不构成回路的边 |
| 关键帧 | ① 将所有边按权值从小到大排序 ② 依次检查每条边 ③ 若边的两个端点不在同一连通分量（并查集判断）则添加 ④ 重复直到添加了 n-1 条边 |
| 动画要点 | ① 边的排序列表 ② 用并查集展示连通分量的合并过程 ③ 添加的边逐条高亮 ④ 跳过构成回路的边（用红色标注） |
| 关联文档 | [[数据结构与算法/算法/图/图算法]] |

### 6. 最短路——Dijkstra 算法⭐🔥

| 项目 | 内容 |
|------|------|
| 可视化核心 | **贪心扩展**——从源点逐步确定到各顶点的最短路 |
| 关键帧 | ① 初始化 dist 数组（源点到各顶点的距离） ② 选 dist 最小的顶点 u 加入 S 集合 ③ 用 u 更新所有邻接顶点的 dist 值 ④ 重复直到所有顶点加入 S |
| 动画要点 | ① 已确定最短路的顶点（S 集合）用实心圆 ② 每次选中的顶点高亮 ③ dist 值更新时用箭头标注 ④ 最终画出最短路树 |
| 关联文档 | [[数据结构与算法/算法/图/图算法]] |

### 7. 最短路——Floyd 算法⭐

| 项目 | 内容 |
|------|------|
| 可视化核心 | **动态规划**——每次引入一个中间顶点 k，更新所有点对距离 |
| 关键帧 | ① 给出初始距离矩阵 ② k=1 时，所有点对尝试经顶点 1 中转 ③ k=2 时再尝试经顶点 2 中转 ④ ... ⑤ 直到 k=n |
| 动画要点 | 用矩阵展示每一步的变化：每次 k 循环后，矩阵中距离缩短的条目用不同颜色标注 |
| 关联文档 | [[数据结构与算法/算法/图/图算法]] |

### 8. 拓扑排序⭐

| 项目 | 内容 |
|------|------|
| 可视化核心 | **入度法**——每次选入度为 0 的顶点输出 |
| 关键帧 | ① 计算所有顶点的入度 ② 将所有入度为 0 的顶点入队 ③ 出队 → 输出 → 将其邻接点的入度减 1 ④ 若邻接点入度变 0 则入队 ⑤ 重复直到队空 |
| 动画要点 | ① 初始标注每个顶点的入度 ② 每次选出入度为 0 的顶点（高亮）③ 删除该顶点及其出边（用红色叉号）④ 展示输出序列 |
| 关联文档 | [[数据结构与算法/算法/图/图算法]] |
