# 存储器层次结构

## 📍知识定位

### 在408体系中的位置

存储器层次结构是计算机组成原理的核心模块之一，位于数据表示之后、指令系统和CPU设计之前。它从**硬件角度**系统地阐述了计算机存储系统是如何通过"多层次、分级缓存"的架构，在容量、速度、成本之间取得平衡的。这是理解现代计算机存储体系（从寄存器到外存）的总纲。

### 学习前置条件

- **数据表示**：理解二进制数据的存储形式、字节序
- 基本容量单位概念（Bit、Byte、KB、MB、GB）

### 学完之后支撑的知识点

- **Cache**：高速缓冲存储器的设计与映射机制
- **主存储器**：RAM/ROM的芯片扩展与编址
- **外存系统**：磁盘的组织方式与I/O联动
- **虚拟内存**：与操作系统的协作

## 📝核心概念与原理

### 一、存储器的分类

#### 1. 按存取方式分类 ⭐

| 分类 | 说明 | 示例 |
|------|------|------|
| **随机存取存储器（RAM）** | 任意访问，速度最快 | SRAM、DRAM |
| **顺序存取存储器（SAM）** | 必须按顺序访问 | 磁带 |
| **直接存取存储器（DAM）** | 直接定位到磁道/磁头，再顺序读取 | 磁盘 |

#### 2. 按物理材料分类 ⭐

| 分类 | 说明 | 特点 |
|------|------|------|
| **半导体存储器** | 用半导体芯片做存储介质 | 速度快、体积小、成本高 |
| **磁表面存储器** | 利用磁性材料表面的磁化方向存储 | 容量大、速度慢、成本低 |
| **磁芯存储器** | 利用磁环的磁化状态存储（已淘汰） | 曾用于早期计算机 |

#### 3. 按信息可读性分类 ⭐

| 分类 | 说明 | 特点 |
|------|------|------|
| **ROM（只读存储器）** | 只能读取，不能写入 | 断电后信息不丢失（非易失） |
| **RAM（随机存取存储器）** | 可读可写 | 断电后信息丢失（易失） |

> 常见ROM类型：MASK ROM（掩膜ROM）、PROM（可编程ROM）、EPROM（紫外线擦除可编程ROM）、EEPROM（电擦除可编程ROM）、Flash（闪存）。

### 二、存储器的层次结构 ⭐🔥

#### 1. 存储层次的整体模型

```
                  速度最快、容量最小、成本最高
                    │
                   寄存器（Register）
                    │
                   Cache L1
                    │
                   Cache L2
                    │
                   Cache L3
                    │
                   主存储器（Main Memory / RAM）
                    │
                   辅助存储器（Secondary Memory）
                    │
                   磁带 / 磁盘（外存）
                    │
                  云存储 / 网络存储
                  速度最慢、容量最大、成本最低
```

> **核心思想**：通过"缓存"技术，让程序大部分时间访问的是高速存储，少数时间访问低速大容量存储，从而在性能上接近最快存储，在成本上接近最慢存储。

> ⭐ **选择题必考**：存储层次的结构从上到下依次是：寄存器 → Cache → 主存 → 辅存。

#### 2. 局部性原理（Locality）⭐🔥

局部性原理是存储层次存在的**理论依据**。

**时间局部性（Temporal Locality）**：

> 如果一个存储位置被访问，那么在不久的将来它很可能再次被访问。

典型场景：
- 循环体中的指令和数据（反复访问）
- 被频繁调用的函数
- 累加器变量

**空间局部性（Spatial Locality）**：

> 如果一个存储位置被访问，那么在不久的将来它附近的位置也很可能被访问。

典型场景：
- 顺序执行的指令
- 数组/结构的顺序访问
- 线性表的遍历

> CSAPP强调：局部性原理是Cache、虚拟内存、预取机制等所有存储优化的理论基础。

> 🔥 **选择题/大题考点**：判断程序是否具有局部性。循环结构体现时间局部性；数组顺序访问体现空间局部性。

### 三、存储器的主要技术指标 ⭐

#### 1. 存储容量

```
存储容量 = 存储字数 × 字长（单位：字或字节）

例：一个存储器有 4096 个字，每个字 32 位（4 字节）
容量 = 4096 × 4 字节 = 16 KB
```

#### 2. 存储速度

| 指标 | 说明 | 典型值 |
|------|------|--------|
| **存储周期（Memory Cycle Time, Tm）** | 存储器进行一次读或写操作所需的全部时间 | DRAM约50-70ns |
| **存储时间（Memory Access Time, ta）** | 从读/写命令发出到数据被读出/写入所需的时间 | 略小于存储周期 |
| **存储器带宽（Memory Bandwidth）** | 单位时间内存储器存取的信息量 | MB/s ~ GB/s |

> ⭐ **选择题考点**：存储周期 ≥ 存储时间（存储周期包含存储时间 + 恢复时间）。

#### 3. 存储器的分类（按在计算机中的作用）⭐

| 类型 | 位置 | 作用 | 速度 | 容量 |
|------|------|------|------|------|
| 寄存器 | CPU内部 | 存放当前正在使用的数据/指令 | 最快 | 最小 |
| Cache | CPU与主存之间 | 存放近期频繁访问的数据/指令 | 很快 | 较小 |
| 主存 | 主板 | 存放正在运行的程序和即将运行的程序 | 较快 | 中等 |
| 辅存 | 外部 | 存放长期保存的数据和程序 | 较慢 | 很大 |

### 四、主存储器的结构与编址 ⭐🔥

#### 1. 存储器的组成

```
存储器 = 存储体 + 地址寄存器（MAR） + 数据寄存器（MDR） + 读写控制电路
```

- **存储体**：由大量存储单元组成，每个单元存放一个存储字
- **MAR（Memory Address Register）**：存放欲访问的存储单元地址，决定读写的"位置"
- **MDR（Memory Data Register）**：存放读写的数据，决定读写的"内容"

> MAR的位数 = 地址线数 = 可编址的最大存储单元数（以字节或字为单位）
> MDR的位数 = 数据总线宽度 = 存储字长

#### 2. 存储器的编址 ⭐

**字节编址（Byte Addressing）**：

> 每个字节有一个唯一的地址。现代计算机（如x86）采用字节编址。

```
地址：  0    1    2    3    4    5    6    7
数据：  B0   B1   B2   B3   B4   B5   B6   B7
```

**字编址（Word Addressing）**：

> 每个字有一个地址。假设字长32位（4字节），则每个地址对应4个字节。

```
字地址：  0    1    2    3
字内容： B0B1B2B3 B4B5B6B7 B8B9BAB...
```

> 字编址与字节编址的转换：
> - 字地址 → 字节地址 = 字地址 × 字长（字节数）
> - 字节地址 → 字地址 = 字节地址 / 字长（取整）
> - 字节地址 → 字节偏移 = 字节地址 % 字长

> ⭐ **选择题高频考点**：
> - 字编址时地址线数量减少（因为每个地址指向更多字节）
> - 字节编址时灵活性更高（可以访问字节、半字、字）

#### 3. 字扩展与位扩展 ⭐🔥

**位扩展（增加字长）**：

> 需要存储字的位数（字长）大于可用芯片的字长时，用多片并联。

```
目标： 256K × 32位
芯片： 64K × 8位
需要： 字数不变，字数扩展
      32/8 = 4片并联（4片×8位 = 32位）
      每组4片，共 256K/64K = 4组
      总计：4组 × 4片 = 16片
      用高位地址（A17~A16）做片选
```

**字扩展（增加存储字数）**：

> 需要的存储字数大于可用芯片的字数时，用多组串联。

```
目标： 512K × 16位
芯片： 128K × 16位
需要： 512K/128K = 4组串联（每组128K）
      每组16位已满足，每组1片
      总计：4片
      用高位地址（A18~A17）做片选
```

**位字同时扩展**：

> 当芯片的字长和字数都不足时，同时进行位扩展和字扩展。

```
目标： 1M × 32位
芯片： 256K × 8位
位扩展：32/8 = 4片并联
字扩展：1M/256K = 4组
      总计：4组 × 4片 = 16片
      用高位地址（A19~A18）做片选（2位，4组）
```

> 🔥 **大题必考**：存储器扩展设计的计算方法，包括：芯片片数计算、地址线分配、片选信号设计。

#### 4. 片选信号与地址译码 ⭐

**全译码（Full Decoding）**：

> 所有地址线都参与译码，每个芯片占用连续的地址空间，无地址重叠。

**部分译码（Partial Decoding）**：

> 部分地址线参与译码，某些地址线悬空，会产生地址重叠（多个地址映射到同一芯片单元）。

> ⭐ **选择题考点**：全译码无地址冗余，部分译码会产生地址重叠区。全译码更精确但译码器更复杂。

### 五、ROM与RAM的典型芯片 ⭐

#### 1. RAM芯片

| 类型 | 说明 | 特点 |
|------|------|------|
| **SRAM（静态RAM）** | 触发器存储，无需刷新 | 速度快、功耗大、成本高、容量小 |
| **DRAM（动态RAM）** | 电容存储，需定期刷新 | 速度慢、功耗小、成本低、容量大 |

> SRAM常用作Cache，DRAM常用作主存。

**DRAM的地址复用技术**：

> 为减少引脚数，DRAM将行地址和列地址分时传输。先传输行地址，再传输列地址。

#### 2. ROM芯片

| 类型 | 特点 | 擦写方式 |
|------|------|---------|
| MASK ROM | 出厂固化，最便宜 | 不可改 |
| PROM | 用户可编程一次 | 电/光编程，不可擦除 |
| EPROM | 可擦除可编程 | 紫外线擦除 |
| EEPROM | 可电擦除 | 按字节电擦除 |
| Flash | 电擦除，块擦除 | 按块擦除，速度快 |

> Flash分为NOR Flash和NAND Flash：
> - NOR：按字节访问，适合代码存储（如BIOS）
> - NAND：按块访问，适合大容量数据存储（如U盘、SSD）

> Cache-主存层次是存储层次的核心，解决CPU与主存之间速度不匹配的问题。详细内容见 [[计算机组成原理/Cache]]。

**核心概念概述**：

- Cache存放近期频繁访问的数据/指令副本
- 通过时间局部性和空间局部性原理高效工作
- 命中率是核心性能指标
- 映射方式：直接映射、全相联映射、组相联映射

### 七、磁盘存储器的结构 ⭐

#### 1. 磁盘的物理结构

```
磁盘 = 盘片（Platter）× N
磁头 = 盘片面数 × 2
      = 磁道数 × 每磁头磁头
磁道（Track） = 同心圆
扇区（Sector） = 磁道的一段弧（通常512字节/扇区）
柱面（Cylinder） = 不同盘片上半径相同的磁道集合
```

#### 2. 磁盘容量计算 ⭐🔥

```
磁盘容量 = 磁头数 × 磁道数/盘面 × 扇区数/磁道 × 每扇区字节数

例：双面（磁头数=2），每盘面1000磁道，每磁道100扇区，每扇区512字节
容量 = 2 × 1000 × 100 × 512 = 102,400,000 字节 ≈ 97.66 MB
```

#### 3. 磁盘访问时间 ⭐

```
平均存取时间 = 平均寻道时间 + 平均旋转延迟 + 传输时间

- 平均寻道时间：磁头移动到目标磁道所需时间（3~15ms）
- 平均旋转延迟：盘片旋转到目标扇区所需时间（通常旋转半圈的时间）
- 传输时间：读取/写入数据所需时间
```

> 平均旋转延迟 = 1 / (2 × 旋转速度)
> 例：7200 RPM → 旋转一圈 = 60/7200 = 8.33ms → 平均旋转延迟 = 4.17ms

#### 4. 磁盘调度算法 ⭐

**FCFS（先来先服务）**：
- 按请求顺序依次服务
- 简单但性能较差

**SSTF（最短寻道时间优先）**：
- 选择距离当前磁头最近的磁道
- 可能导致"饥饿"（远端磁道长期得不到服务）

**SCAN（电梯调度）**：
- 磁头沿一个方向移动，依次服务经过的磁道，到达尽头后反向
- 不会出现饥饿

**C-SCAN（循环SCAN）**：
- 单向服务，到尽头后快速返回起点
- 等待时间更均匀

> ⭐ **选择题考点**：
> - SSTF可能产生饥饿
> - SCAN性能好但两端磁道等待时间较长
> - C-SCAN保证最大等待时间一致

## ⚖️易混淆概念对比

### 存储器的分类对比

| 对比项 | ROM | RAM |
|--------|-----|-----|
| 读写能力 | 只读（部分可写） | 可读可写 |
| 断电保持 | 非易失（保持） | 易失（丢失） |
| 速度 | 较慢 | 较快 |
| 用途 | BIOS、固件、Bootloader | 运行中的程序和数据 |
| 典型芯片 | Flash、EEPROM | SRAM、DRAM |

### 字节编址与字编址对比

| 对比项 | 字节编址 | 字编址 |
|--------|---------|--------|
| 地址粒度 | 1字节 | 1个字（如4字节） |
| 地址线数量 | 较多 | 较少 |
| 灵活性 | 高（可访问字节/半字/字） | 较低（通常按字访问） |
| 典型系统 | x86（现代） | 部分DSP/嵌入式 |
| 地址转换 | 字节地址 = 字地址 × 字长 | 字地址 = 字节地址 / 字长 |

### SRAM与DRAM对比

| 对比项 | SRAM | DRAM |
|--------|------|------|
| 存储单元 | 触发器（6晶体管） | 电容+晶体管 |
| 是否需要刷新 | 不需要 | 需要定期刷新 |
| 速度 | 快（纳秒级） | 较慢（几十纳秒） |
| 容量 | 小 | 大 |
| 成本 | 高 | 低 |
| 功耗 | 大 | 小 |
| 用途 | Cache、寄存器 | 主存 |

### 直接映射、全相联映射、组相联映射对比

| 对比项 | 直接映射 | 全相联映射 | 组相联映射 |
|--------|---------|-----------|-----------|
| 规则 | 每个块只能放一个固定位置 | 可放Cache任意位置 | 先分组，组内全相联 |
| 灵活性 | 低 | 高 | 中等 |
| 命中率 | 较低（冲突淘汰多） | 高 | 中等偏高 |
| 硬件复杂度 | 简单（只需比较组号） | 复杂（需同时比较所有标记） | 中等 |
| 替换算法 | 唯一确定（强制替换） | LRU/FIFO等 | LRU/FIFO等 |

## ⚠️考试高频坑点

### 坑点1：存储周期与存储时间的区别

> 【教材原文】存储周期（Tm）是进行一次读/写操作所需的全部时间；存储时间（ta）是从发出命令到数据读出/写入的时间。
>
> 【考试考法】存储周期 ≥ 存储时间。存储周期 = 存储时间 + 恢复时间（DRAM刷新后需要恢复）。很多考生混淆这两个概念，选错"哪个更大"。

### 坑点2：位扩展与字扩展的区别

> 【考试考法】芯片的字长不够时，用位扩展（并联）；芯片的字数不够时，用字扩展（串联）。
>
> 关键判断：比较目标容量与芯片容量的字长（数据位）和字数（地址位）。

### 坑点3：字节编址与字编址的地址转换

> 【考试考法】字长32位（4字节），字节地址为0x1004，求对应的字地址和字节偏移。
> 字地址 = 0x1004 / 4 = 0x401
> 字节偏移 = 0x1004 % 4 = 0
>
> 注意：字节偏移 = 字节地址的低2位（因为32位 = 4字节 = 2^2）

### 坑点4：Cache命中率的计算

> 【考试考法】假设Cache访问时间为10ns，主存访问时间为100ns，Cache命中率为95%，求平均访问时间。
> ta = 0.95 × 10 + 0.05 × 100 = 9.5 + 5 = 14.5ns
>
> 注意：如果考虑"同时访问"模式（命中只访问Cache），则 ta = 命中×tc + 未命中×(tc+tm)
> 如果采用"先访问Cache，未命中再访问主存"模式，则需加上Cache访问时间。

### 坑点5：磁盘平均旋转延迟的计算

> 【考试考法】磁盘转速为7200RPM，求平均旋转延迟。
> 旋转一圈时间 = 60秒 / 7200 = 0.00833秒 = 8.33ms
> 平均旋转延迟 = 8.33 / 2 = 4.17ms
>
> 注意：平均旋转延迟是旋转**半圈**的时间，不是整圈。

### 坑点6：部分译码与全译码的地址重叠

> 【考试考法】目标存储器16KB，用8KB芯片（13根地址线），系统地址线16根。若部分译码，有多少地址重叠？
> 16KB需要14根地址线（2^14=16384），8KB需要13根。系统有16根地址线（64KB范围）。
> 全译码：每个8KB芯片只占用一个8KB范围。
> 部分译码：悬空的地址线会产生4个8KB范围的映射（2^(16-13)=2^3=4个重叠区）。
