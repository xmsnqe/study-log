# 主存储器

## 📍知识定位

### 在408体系中的位置

主存储器（Main Memory）是计算机硬件系统的核心部件之一，负责存放CPU需要立即处理的程序和数据。在408计算机组成原理的知识体系中，主存储器处于**存储层次结构的中间层**——向上与Cache连接（Cache直接服务于CPU），向下与外存连接（外存作为后备存储）。主存储器的原理涉及存储器的物理实现（DRAM/SRAM）、组织结构（芯片→存储体→存储器）、读写流程以及存储器的扩展方法，是408考试中**选择题和大题均会覆盖的必考模块**。

### 学习前置条件

- **数据表示**：理解二进制地址的位级表示、字节序（大端/小端）
- **计算机组成概述**：了解冯·诺依曼体系结构、存储器在计算机中的位置
- **总线**：理解地址总线、数据总线、控制总线的传输机制

### 学完之后支撑的知识点

- **存储器层次结构**：主存是Cache和虚拟内存的直接对象
- **Cache**：Cache中存储的是主存数据的副本
- **CPU数据通路**：CPU通过地址总线和数据总线与主存交互
- **操作系统内存管理**：主存的物理地址空间、内存分配与回收

## 📝核心概念与原理

### 一、存储器的基本概念 ⭐

#### 1. 存储器的分类

```
存储器层次结构
┌──────────────────────────────────────────────┐
│  寄存器（Register）          最快、最小、最贵  │  CPU内部
│  ├─────────────────────────────────────────┤  │
│  Cache（L1/L2/L3）           较快、较小、较贵  │  CPU内部/主板
│  ├─────────────────────────────────────────┤  │
│  主存储器（Main Memory）       中等速度、大容量  │  内存条
│  ├─────────────────────────────────────────┤  │
│  辅助存储器（外存）              慢速、超大容量  │  硬盘/SSD
│  └─────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

主存储器（主存/Memory/RAM）在存储层次中位于Cache之下、外存之上：

| 分类 | 代表 | 速度 | 容量 | 价格 | 特点 |
|------|------|------|------|------|------|
| **RAM（随机存取存储器）** | DRAM、SRAM | 快 | 中等 | 较高 | 可读写、掉电丢失 |
| **ROM（只读存储器）** | PROM、EPROM、EEPROM、Flash | 较慢 | 较小 | 较低 | 只读（或限写）、掉电不丢失 |

> ⭐ **选择题考点**：
> - 主存属于**RAM（随机存取）**类型，而非"只按地址顺序存取"
> - 主存是**易失性存储器**（Volatile），断电后数据丢失
> - SRAM用作Cache，DRAM用作主存（因为SRAM成本高、集成度低）

#### 2. 存储器的性能指标 ⭐

| 指标 | 公式/说明 | 说明 |
|------|----------|------|
| **存储容量** | 字数 × 字长 | 如 8GB = 2³⁰ 字节 |
| **存储速度** | 存取时间（Access Time）| 从读/写命令发出到数据到位的时间 |
| **存储器带宽** | 数据传送率 | 单位时间内传输的数据量，如 GB/s |
| **存取周期（τ）** | τ = ta + tc | ta为存取时间，tc为恢复时间 |

> 存取周期 τ > 存取时间 ta，因为存储器在一次存取后需要恢复时间。

> ⭐ **选择题考点**：存储器带宽的计算。若存储字长为32位（4字节），存储器周期为60ns，则最大带宽 = 4B / 60ns ≈ 66.7 GB/s。

### 二、存储器的组织结构 ⭐🔥

从单个存储芯片到完整的存储器系统，需要经历"芯片→存储体→存储器"的组织过程。

#### 1. 存储芯片的基本结构

```
                        ┌──────────────────┐
                        │   读写控制电路    │
                        │  （读/写驱动器）   │
                        └────────┬─────────┘
                                 │
                    ┌────────────┼────────────┐
                    │            │             │
              ┌─────┴────┐ ┌────┴─────┐ ┌────┴─────┐
              │  存储矩阵  │ │  地址译码 │ │  数据I/O │
              │ (Storage  │ │  (Decoder)│ │  缓冲器  │
              │  Array)   │ │           │ │ (Buffer) │
              └───────────┘ └───────────┘ └──────────┘

           外部接口：
           - 地址总线 A₀~A(n-1)：n位地址 → 2ⁿ 个存储单元
           - 数据总线 D₀~D(m-1)：m位数据 → m位字长
           - 读/写控制线：R/W（读/写选择）、CS（片选）
```

**关键概念**：

- **存储体（Storage Array）**：由大量存储单元组成的矩阵，每个存储单元存储一个二进制位（DRAM为电容电荷）或一个字（ROM为触发器阵列）
- **地址译码器**：将n位地址译码为 2ⁿ 条选通线，选择唯一的存储单元
- **读写电路**：控制读/写操作，包括读放大器（增强信号）和写驱动器

> ⭐ **选择题考点**：
> - n位地址线 → 2ⁿ 个存储单元
> - m位数据线 → 字长为m位
> - 存储芯片容量 = 2ⁿ × m 位
> - 例：6264芯片，地址线13根（A₀~A₁₂），数据线8根（D₀~D₇）→ 容量 = 2¹³ × 8位 = 8K × 8位 = 8KB

#### 2. 存储芯片→存储体→存储器的组织

**从芯片到存储体（Bank）**：

```
单个芯片：  2ⁿ × m 位
N个芯片：   通过位扩展或字扩展组成存储体

存储体（Bank）：
- 位扩展：增加字长（数据线并联扩展）
- 字扩展：增加存储单元数量（地址线扩展，片选控制）
- 位-字扩展：同时扩展字长和字数
```

**例1：位扩展（增加字长）**

用 2K×4位的芯片组成 2K×8位的存储器：

```
需要芯片数 = 2K×8位 / 2K×4位 = 2片

连接方式：
- 地址线 A₀~A₁₀ 并联（2K = 2¹¹）
- 两片的数据线分开：一片接 D₀~D₃，另一片接 D₄~D₇
- 两片共用片选信号
```

**例2：字扩展（增加容量）**

用 1K×8位的芯片组成 8K×8位的存储器：

```
需要芯片数 = 8K×8位 / 1K×8位 = 8片

连接方式：
- 每片数据线 D₀~D₇ 并联
- 低10位地址线 A₀~A₉ 并联到所有芯片（1K = 2¹⁰）
- 高3位地址线 A₁₀~A₁₂ 经3-8译码器产生 8个片选信号
  A₁₂A₁₁A₁₀ = 000 → 片选0（0K~1K-1）
  A₁₂A₁₁A₁₀ = 001 → 片选1（1K~2K-1）
  ...
  A₁₂A₁₁A₁₀ = 111 → 片选7（7K~8K-1）
```

> 3-8译码器（如74LS138）的输入为 A₁₂、A₁₁、A₁₀，输出 Y₀~Y₇ 分别接 8片芯片的片选端。

**例3：位-字扩展（同时扩展）**

用 1K×4位的芯片组成 4K×8位的存储器：

```
需要芯片数 = (4K×8位) / (1K×4位) = 8片

分两步：
第一步（位扩展）：每组2片组成 1K×8位
第二步（字扩展）：4组共8片，地址线用 A₀~A₁₁（4K=2¹²），
                 高2位 A₁₂、A₁₁ 经2-4译码器作片选（4组）
```

> 🔥 **大题必考**：存储芯片扩展方案的设计与连接图绘制。给定目标存储器容量和规格，计算所需芯片数，画出地址线和数据线的连接方式，并说明译码器的使用。

### 三、DRAM与SRAM的原理与对比 ⭐🔥

#### 1. SRAM（Static RAM，静态随机存取存储器）

**存储原理**：

> SRAM使用**触发器（Flip-Flop）**存储数据。每个存储单元由6个晶体管（6T）构成一个SRAM单元。只要保持电源，数据就不会丢失。

```
SRAM单元（6T触发器结构）：
       两个交叉耦合的反相器形成双稳态存储单元
       Q和Q'两个节点分别存储1和0
       需要2个访问晶体管连接到位线

       写入：通过位线（Bit Line）和反位线写入数据
       读出：通过位线读出Q或Q'的状态
```

**特点**：

| 特性 | SRAM |
|------|------|
| 存储单元结构 | 6晶体管（6T）触发器 |
| 是否需要刷新 | 不需要（静态） |
| 速度 | 快（几纳秒） |
| 集成度 | 低（单元面积大） |
| 功耗 | 较高（静态功耗） |
| 成本 | 高（每比特价格高） |
| 应用 | Cache、寄存器文件 |

#### 2. DRAM（Dynamic RAM，动态随机存取存储器）

**存储原理**：

> DRAM使用**电容**存储数据。电容带电表示1，不带电表示0。由于电容存在漏电，需要定期**刷新**（Refresh）。

```
DRAM单元（1T1C结构）：
       一个晶体管 + 一个电容

       写入：打开晶体管，对电容充电（1）或放电（0）
       读出：读取电容上的电荷 → 信号弱 → 需要读放大器
       刷新：定期读取并重写（破坏性读出后的重建）
```

**DRAM的组织结构**：

```
DRAM芯片内部：存储矩阵（行×列）

以 64M×1bit DRAM 为例：
┌─────────────────────────────┐
│  存储矩阵 65536行 × 65536列  │  共 2²⁶ × 2²⁶ = 2⁵² bit
├─────────────────────────────┤
│  行地址选通（RAS）→ 选通行   │
│  列地址选通（CAS）→ 选中列   │
└─────────────────────────────┘

DRAM采用"行-列"地址分时复用：
- 先发送行地址（RAS下降沿锁存）
- 再发送列地址（CAS下降沿锁存）
- 优点：减少地址线数量
  例如 65536 = 2¹⁶，若分开送需16+16=32根地址线
  分时复用只需16根地址线
```

> ⭐ **选择题高频考点**：
> - DRAM需要**定期刷新**，SRAM不需要
> - DRAM刷新方式：集中刷新、分散刷新、异步刷新
> - 刷新周期通常≤2ms（即2ms内必须对所有行刷新一次）
> - DRAM地址线复用：减少引脚数

**DRAM的刷新机制**：

```
以 4096行 DRAM 为例，刷新周期 2ms：

方法一：集中刷新
- 所有4096行在2ms内一次性刷新
- 刷新期间（死区）不能进行读写操作
- 死区时间 = 4096 × 刷新周期（如100ns）≈ 409.6μs
- 死区占比 = 409.6μs / 2000μs ≈ 20.5%

方法二：分散刷新
- 每行刷新间隔 = 2ms / 4096 ≈ 0.49μs
- 每个存储周期后插入一个刷新周期
- 无死区，但每个周期延长

方法三：异步刷新（推荐）
- 每行在2ms内刷新一次，不必集中
- 合理分配刷新间隔，减少死区影响
```

> 例：某DRAM芯片容量为1M×1位，存储循环周期为2ms，刷新行数为8192行。若采用集中刷新，刷新死区为 8192 × 100ns = 819.2μs。

#### 3. SRAM vs DRAM 综合对比 ⭐

| 对比项 | SRAM | DRAM |
|--------|------|------|
| 存储原理 | 触发器（6T） | 电容（1T1C） |
| 刷新 | 不需要 | 需要（≤2ms） |
| 速度 | 快（1~10ns） | 较慢（50~70ns） |
| 集成度 | 低（每个单元6T） | 高（每个单元1T1C） |
| 功耗 | 较高（静态功耗大） | 较低（动态功耗为主） |
| 成本 | 高 | 低 |
| 应用 | L1/L2/L3 Cache | 主存储器 |
| 位成本 | 高 | 低 |

> ⭐ **选择题必考点**：
> - Cache用SRAM，主存用DRAM（速度/成本权衡）
> - DRAM的刷新是必考概念，不刷新数据会丢失
> - DRAM地址线复用是常见考题

### 四、主存与CPU的连接 ⭐🔥

#### 1. 连接的基本要素

```
CPU                          存储器系统
┌──────────┐              ┌──────────────┐
│ 地址总线  │◄───────►    │  地址译码    │
│ A₀~A(n-1)│             │  存储芯片组    │
├──────────┤              ├──────────────┤
│ 数据总线  │◄───────►    │  数据缓冲器    │
│ D₀~D(m-1)│             └──────────────┘
├──────────┐
│ 控制总线  │──►  R/W（读/写选择）
│           │──►  CS（片选，经译码产生）
│           │──►  MREQ（访存请求）
└──────────┘
```

**关键连接点**：

1. **地址线连接**：CPU地址线直接连接到存储芯片的地址输入端（可能需要译码扩展）
2. **数据线连接**：CPU数据总线与存储芯片的数据线对接，注意字长匹配
3. **控制线连接**：
   - R/W：读/写控制
   - MREQ：访存请求信号（有效时CPU才访问存储器）
   - CS（Chip Select）：片选信号，由地址译码产生
4. **ROM与RAM的分配**：通常ROM位于地址空间底部（存放BIOS/启动代码），RAM位于地址空间上部

#### 2. 存储器地址空间分配

```
典型的32位地址空间布局（CSAPP视角）：

┌──────────────────┐  ← 最高地址 2³²-1
│       ...        │
├──────────────────┤
│   用户栈         │  向下增长
├──────────────────┤
│   共享库         │
├──────────────────┤
│   堆             │  向上增长
├──────────────────┤
│     ...          │  空闲
├──────────────────┤
│   数据段         │  全局变量、静态变量
├──────────────────┤
│   BSS段          │  未初始化全局变量
├──────────────────┤
│   文本段         │  程序代码（只读）
├──────────────────┤
│       ...        │
└──────────────────┘  ← 最低地址 0
```

> 操作系统中的内存管理模块负责这些地址空间的分配。详见 [[进程管理/内存管理]] 和 [[进程管理/内存分配与回收]]。

#### 3. 典型连接图绘制要点（大题）

```
例：用 2K×8位 SRAM 和 8K×8位 DRAM 组成 64K×16位的存储器。

步骤1：确定容量
- 目标：64K × 16位
- SRAM容量：2K × 8位 → 用作字长扩展
- DRAM容量：8K × 8位 → 用作字长扩展

步骤2：计算芯片数
- 字扩展：64K / (需要确定SRAM和DRAM分别占多少空间)
- 位扩展：16位 / 8位 = 2片一组

步骤3：地址译码设计
- 64K = 2¹⁶ → 需要16根地址线
- 根据SRAM和DRAM的容量分配，计算各部分的地址范围
- 用译码器产生片选信号

步骤4：画出连接图
- 标注地址线连接
- 标注数据线连接（两片一组组成16位）
- 标注控制线连接
```

> 408考试中，存储器与CPU连接图的绘制属于**大题常见题型**。重点掌握：
> - 芯片数量的计算
> - 地址范围的划分
> - 译码器的使用（2-4、3-8译码器）
> - 连接图的正确画法

### 五、存储器带宽与性能 ⭐

#### 1. 带宽的定义与计算

```
存储器带宽 = 单位时间内可以读/写的数据量

计算方法：
- 若存储器的存储字长为 W 字节，存取周期为 τ 秒
  则 带宽 = W / τ （字节/秒）

- 若存储器有 m 个存储体，每个存储体的存取周期为 τ
  则 多体交叉存储器的带宽可以大幅提升（见下文）
```

> 例：某存储器的字长为32位（4字节），存取周期为60ns。
> 带宽 = 4B / 60ns = 4 / (60 × 10⁻⁹) ≈ 66.7 MB/s

#### 2. 多体交叉存储器（低位交叉编址）⭐🔥

**基本概念**：

> 多体交叉存储器将存储器分为多个独立的存储体（Bank），每个存储体可以独立工作。通过**低位交叉编址**，实现**流水线式存取**，显著提高带宽。

```
4体交叉存储器示意图：

         体0    体1    体2    体3
      ┌─────┬─────┬─────┬─────┐
地址   0     4     8     12   ...
         4     4     4     4
      └─────┴─────┴─────┴─────┘

低位交叉编址：
- 偶数地址 → 体0、体2、体4...
- 奇数地址 → 体1、体3、体5...
- 或者说：地址 mod 体数 = 目标体号
```

**流水线式存取原理**：

```
单体存储器（无交叉）：
  读取数据0 → 等待τ → 读取数据1 → 等待τ → 读取数据2...
  每次读取间隔 = τ

4体交叉存储器（低位交叉）：
  体0读数据0
         启动体1读数据1（等待θ）
               启动体2读数据2（等待θ）
                    启动体3读数据3（等待θ）
                          启动体0读数据4（等待θ）

  每次读取间隔 = θ（启动间隔），而非τ

其中：θ = τ / m （m为存储体数）

理想情况下，4体交叉的带宽是单体存储器的4倍。
```

**多体交叉存储器的性能分析**：

```
设存储体数 = m，存取周期 = τ，启动间隔 = θ

理想带宽：
  带宽_理想 = m × W / τ

实际情况下（连续的连续地址访问）：
  若 θ < τ/m，即启动间隔 < τ/m，可以实现流水线式并行存取
  理想带宽 = W/θ

  如果 θ = τ/m：
  理想情况：每个周期都能从不同体读取数据
  实际带宽 ≈ W/θ = m × W/τ

非理想情况（不连续的地址访问）：
  如果访问地址跨越不同的体，可能产生冲突
  当 m 个访问同时指向同一体时，需要排队等待
```

> 例：4体交叉存储器，存取周期 τ = 100ns，启动间隔 θ = 20ns。
> 理想带宽 = 4 × 4B / 100ns = 160 MB/s
> 实际带宽（连续访问）= 4B / 20ns = 200 MB/s
> 
> 注意：启动间隔 θ 必须满足 θ ≤ τ/m 才能实现真正的流水线并行。如果 θ > τ/m，则无法实现完全重叠。

> 例：设4体交叉存储器，τ=12ns，θ=3ns。能否达到理想带宽？
> τ/m = 12/4 = 3ns = θ → 刚好满足，可以达到理想带宽。

> 🔥 **大题必考**：多体交叉存储器的性能分析、带宽计算、启动间隔的计算。

#### 3. 高位交叉 vs 低位交叉

| 对比项 | 低位交叉（交叉编址） | 高位交叉（并行编址） |
|--------|-------------------|-------------------|
| 地址分配 | 地址 mod m = 体号 | 地址 / (容量/m) = 体号 |
| 工作方式 | 流水线式（交错存取） | 并行独立 |
| 带宽提升 | 显著（连续访问时） | 无提升（各体独立） |
| 适用场景 | 连续数据访问 | 独立数据访问 |
| 实际应用 | 主流（CPU缓存行连续访问） | 少见 |

> ⭐ **选择题考点**：低位交叉编址可以实现流水线存取，提高带宽；高位交叉编址各体独立工作，不提高带宽。

### 六、ROM与其他类型存储器 ⭐

#### 1. ROM的分类

| 类型 | 全称 | 特点 | 应用 |
|------|------|------|------|
| **PROM** | Programmable ROM | 一次性可编程 | 早期固件 |
| **EPROM** | Erasable PROM | 紫外线擦除 | 可重复编程 |
| **EEPROM** | Electrically Erasable PROM | 电擦除，字节级 | BIOS（现代）、配置存储 |
| **Flash** | 闪存 | 块擦除，电擦除 | SSD、U盘、嵌入式存储 |

#### 2. Flash存储器的特点 ⭐

```
Flash分为两类：
- NOR Flash：随机访问，适合代码执行（XIP）
- NAND Flash：串行访问，适合大容量数据存储

NAND Flash的特点：
- 高集成度、大容量
- 顺序读写速度快
- 需要坏块管理、磨损均衡等机制
- 是现代SSD的核心存储介质
```

> ⭐ **选择题考点**：
> - Flash属于非易失性存储器（断电数据不丢失）
> - NAND Flash用于SSD，NOR Flash用于嵌入式系统
> - EEPROM可以按字节擦写，Flash按块擦写

## ⚖️易混淆概念对比

### SRAM vs DRAM

| 对比项 | SRAM | DRAM |
|--------|------|------|
| 存储介质 | 触发器（6晶体管） | 电容（1晶体管+1电容） |
| 是否需要刷新 | 不需要 | 需要（2ms内刷新全部行） |
| 速度 | 快（1~10ns） | 较慢（50~70ns） |
| 集成度 | 低（单元面积大） | 高（单元面积小） |
| 功耗 | 静态功耗大 | 动态功耗为主 |
| 价格 | 昂贵 | 便宜 |
| 主要用途 | Cache、寄存器文件 | 主存储器 |
| 掉电后数据 | 丢失 | 丢失 |

### 位扩展 vs 字扩展

| 对比项 | 位扩展 | 字扩展 |
|--------|--------|--------|
| 目的 | 增加存储器的字长 | 增加存储单元的数量 |
| 实现方式 | 多个芯片的数据线并联扩展 | 多个芯片的地址空间并联扩展 |
| 地址线 | 所有芯片的地址线并联 | 低地址线并联，高地址线经译码 |
| 数据线 | 各芯片数据线分配不同位 | 所有芯片数据线并联 |
| 片选 | 所有芯片共用同一片选 | 各芯片有不同片选（由译码器产生） |
| 示例 | 4片1K×4位 → 1K×16位 | 4片1K×8位 → 4K×8位 |

### 低位交叉 vs 高位交叉

| 对比项 | 低位交叉编址 | 高位交叉编址 |
|--------|-----------|-----------|
| 地址分配 | 地址 mod m = 体号 | 地址 / (每体容量) = 体号 |
| 连续地址分布 | 分布在不同体 | 分布在同一体内 |
| 存取方式 | 流水线式交错存取 | 并行独立存取 |
| 带宽提升 | 显著提高（连续访问） | 不提高带宽 |
| 适用场景 | 连续数据流访问 | 随机独立访问 |

### 集中刷新 vs 分散刷新

| 对比项 | 集中刷新 | 分散刷新 |
|--------|---------|---------|
| 刷新时机 | 所有行一次性刷新 | 每行间隔刷新 |
| 死区时间 | 有（全部刷新时间累加） | 无 |
| CPU可用性 | 刷新期间不能访问 | 始终可用（周期略延长） |
| 实现难度 | 简单 | 复杂 |
| 适用场景 | 对实时性要求不高的系统 | 对实时性要求高的系统 |

## ⚠️考试高频坑点

### 坑点1：芯片容量的计算

> 【坑点】地址线和数据线直接决定芯片容量。
> - n根地址线 → 2ⁿ 个地址
> - m根数据线 → m位字长
> - 芯片容量 = 2ⁿ × m 位
>
> 【考试考法】给出地址线数和数据线数，求芯片容量。
> 例：14根地址线，8根数据线 → 2¹⁴ × 8位 = 16K × 8位 = 16KB。

### 坑点2：存储扩展的芯片数计算

> 【坑点】位扩展时芯片数 = 目标字长 / 芯片字长；字扩展时芯片数 = 目标字数 / 芯片字数。
> 位-字扩展时，先确定位扩展组数，再确定字扩展组数。
>
> 【考试考法】用 2K×4位芯片组成 8K×8位存储器。
> 位扩展：8位/4位 = 2片一组
> 字扩展：8K/2K = 4组
> 总芯片数 = 2 × 4 = 8片

### 坑点3：DRAM刷新死区计算

> 【坑点】集中刷新时，死区时间 = 刷新行数 × 每次刷新时间。
> 注意：刷新行数 = 存储矩阵的行数（如4096行），不是总存储单元数。
>
> 【考试考法】某DRAM芯片有4096行，存储周期100ns，刷新周期2ms。
> 集中刷新死区 = 4096 × 100ns = 409.6μs。
> 死区占比 = 409.6μs / 2000μs ≈ 20.5%。

### 坑点4：多体交叉存储器的启动间隔

> 【坑点】多体交叉存储器的启动间隔 θ = τ/m 时达到理想带宽。
> 如果 θ > τ/m，则无法实现完全流水线。
> 如果 θ < τ/m，则有多余的空闲时间。
>
> 【考试考法】4体交叉，τ=80ns。θ应≤20ns才能实现理想带宽。

### 坑点5：大端小端与地址

> 【坑点】大端模式（Big-Endian）：高字节存放在低地址。
> 小端模式（Little-Endian）：低字节存放在低地址。
> x86架构采用小端模式，ARM可配置。
>
> 【考试考法】32位整数 0x12345678 存放在地址 0x1000 开始的位置。
> 小端：0x1000→0x78, 0x1001→0x56, 0x1002→0x34, 0x1003→0x12
> 大端：0x1000→0x12, 0x1001→0x34, 0x1002→0x56, 0x1003→0x78

### 坑点6：存取周期 vs 存取时间

> 【坑点】存取周期 τ = 存取时间 ta + 恢复时间 tc。
> 存储器在一次存取后需要恢复时间才能进行下一次存取。
> 带宽计算使用存取周期 τ，而非存取时间 ta。
